# 导航与定轨

## 研究背景

地月空间距离地球远、信号弱、动力学复杂，对导航与定轨技术提出了全新挑战。

## 研究内容

- GNSS 弱信号导航
- 脉冲星导航
- 星间测距与定轨
- 自主导航算法
