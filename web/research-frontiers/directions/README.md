# 地月空间研究方向与前沿热点

地月空间广袤的物理尺度、复杂的多体引力摄动以及日趋密集的工程任务，催生了一系列极具挑战性的前沿科研方向。从深空弱引力场下的低能轨道综合优化，到跨越数十万公里尺度的广域非合作目标感知，再到地月战略轨道资源的博弈与治理，学术界与工程界正在展开多维度的系统性探索。

本子栏目汇聚当前最具代表性的核心研究方向。

## 核心前沿领域

| 研究方向 | 核心科学与工程问题 | 典型关键技术 | 专题入口 |
| :--- | :--- | :--- | :--- |
| **轨道设计与优化** | 非线性三体多脉冲与连续微推力转移、不变流形拼接、多重引力辅助、共振跳跃 | 伪弧长延拓、多重打靶法、伪谱轨迹优化、引力走廊拓扑搜索 | [进入专题](/research-frontiers/directions/orbit-design/) |
| **空间态势感知 (SSA)** | 超远距离弱小目标观测、非开普勒轨道初轨确定、多源异构传感器协同、空间碰撞预警 | 光学/雷达联合测控、轨道不确定性非高斯传播、可及域与占领区分析 | [进入专题](/research-frontiers/directions/ssa/) |
| **编队飞行与分布式系统** | 旋转三体非线性相对动力学、虚拟望远镜长基线重构、自主协同与构型维持 | 相对运动状态转移张量、分布式一致性控制、非共面构型安全重构 | [进入专题](/research-frontiers/directions/formation-flying/) |
| **空间安全与规则治理** | 地月战略咽喉轨道（如 L1/L2 平动点、NRHO、DRO）资源博弈、碰撞规避与外空法治框架 | 轨道博弈与追逃微分对策、轨道资源占用评估、地月交通管理规则 | [进入专题](/research-frontiers/directions/security-governance/) |

## 发展趋势展望

1. **从单一轨道设计迈向地月空间基础设施网络**：研究焦点正从单任务点对点轨道转移，拓展至覆盖地月全域的通信中继、导航授时（PNT）及空间交通管理星座一体化网络。
2. **人工智能与天体力学机理的深度融合**：利用强化学习与图神经网络加速超大规模发射窗口搜索与自主星上实时制导，克服传统数值迭代在极端非线性条件下的收敛瓶颈。
3. **协同博弈与自主韧性系统**：面向复杂非合作博弈环境，突破高自主性轨道重构与分布式分布式感知决策关键技术。
