# 地月空间科学研究前沿

随着全球探月工程从早期的单一飞掠与采样探测，迈向常态化驻留、地月基础设施建设与空间资源利用的新阶段，地月空间已成为国际深空探测与宇航科学竞争与合作的最前沿阵地。

本栏目系统梳理地月空间的核心学术前沿、科研阵地、学术交流平台与重大工程计划，为研究人员与工程技术团队提供全面的研究导引与全局视野。
