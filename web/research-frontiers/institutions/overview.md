# 国内外地月空间研究组织总览

随着阿尔忒弥斯计划与国际月球科研站各自推进，地月空间正在从单次任务的目的地变成需要持续驻留与运营的基础设施区域。围绕这一区域开展工作的组织，国内已经形成高校、院所与集团并行的梯队，国外则是政府机构、高校与商业公司三层叠加。

本页把这些组织放在一起做一次归纳：每个组织给出定位与代表动作，事实性论断附引用；有单页的机构直接链接过去，暂未建单页的组织给出官方入口。本页将按波次持续充实，后续为更多组织补齐文献支撑并增建单页。

## 国内组织

### 高校

- **[哈尔滨工业大学](/research-frontiers/institutions/hit/)**：航天特色鲜明，是国内少有的把研制能力真正送上月球轨道的高校，龙江二号与天都二号两次任务使其具备完整的月球轨道工程能力。轨道设计与自主导航等基础方向积累深厚，低能转移轨道设计即其代表性成果之一 \cite{ZhangHanQingDiYueSanTiWenTiXiaL1DiQiuDiNengZhuanYiGuiDaoSheJi2011}。
- **[西北工业大学](/research-frontiers/institutions/npu/)**：党朝辉、韩鸿宇团队将博弈论方法引入地月空间非合作航天器巡检，建立了可变时长回合制的检查与反检查轨道博弈框架 \cite{hanGameTheoreticManeuveringStrategies2026}；低能转移与 DRO 动力学方向也有一批代表性成果。
- **[清华大学](/research-frontiers/institutions/thu/)**：宝音贺西团队面向地月航班化运输需求，研究 DRO 航班化往返转移的多脉冲轨迹优化 \cite{BaoYinHeXiDiYueKongJianDROHangBanHuaWangFanZhuanYiDuoMaiChongGuiJiYouHua2025}。
- **[航天工程大学](/research-frontiers/institutions/seu/)**：面向地月空间感知任务，研制了基于容器云与微服务架构的智能仿真系统 \cite{HuJiaXinMianXiangDiYueKongJianGanZhiRenWuSheJiYuFenXiDeZhiNengFangZhenXiTongJiaGouYuShiXian2025}，并持续投入天基态势感知系统与共振轨道结合的应用评估 \cite{WanGangTianJiTaiShiGanZhiXiTongYuGongZhenGuiDaoYingYong2026}。
- **[航天东方红卫星有限公司](/research-frontiers/institutions/dfhscl/)**：将小卫星研制能力与地月空间感知任务结合，参与了地月共线平动点轨道参数表征与目标编目、地月空间感知仿真系统研制等工作 \cite{qiaoOrbitalParameterCharacterization2025,HuJiaXinMianXiangDiYueKongJianGanZhiRenWuSheJiYuFenXiDeZhiNengFangZhenXiTongJiaGouYuShiXian2025}。
- **[国防科技大学](https://www.nudt.edu.cn/)**：地月空间轨道动力学与任务规划方向活跃，地月 L1 点低能转移轨道设计与优化是其代表性方向之一 \cite{QiaoChenYuanDiYueL1DianDiNengZhuanYiGuiDaoSheJiYuYouHua2024}。
- **[北京理工大学](https://www.bit.edu.cn/)**：深空探测轨道设计方向持续投入，低能量逃逸与捕获轨道设计研究是其代表性成果 \cite{WangYaMinShenKongTanCeDiNengLiangTaoYiYuBuHuoGuiDaoSheJiYanJiu2015}。
- **[北京航空航天大学](https://www.buaa.edu.cn/)**：深空轨道设计方向成果扎实，月地转移轨道快速设计方法为其代表性工作之一 \cite{ZhengAiWuYueDiZhuanYiGuiDaoKuaiSuSheJiFangFa2014}。

### 院所与集团

- **中国科学院**：国家天文台承担探月工程地面应用系统，上海天文台以 VLBI 测定轨见长，发展了用于地月空间的加权全频谱信号合成技术 \cite{LiZhiHuiYongYuDiYueKongJianVLBIDeJiaQuanQuanPinPuXinHaoHeChengJiShu2023}；国家空间科学中心牵头空间科学系列任务，是月球与深空科学产出的重要来源。
- **中国航天科技集团**：探月工程的工程总体与主要研制力量，第五研究院、第八研究院分别承担月球探测器平台与配套系统研制，嫦娥五号任务的月地转移轨道设计与实践是该链条的代表成果 \cite{MengZhanFengChangEWuHaoRenWuYueDiZhuanYiGuiDaoSheJiYuShiJian2021}，覆盖从地月转移到月面采样的完整工程链条。
- **深空探测实验室**：又称天都实验室，2022 年成立于合肥，面向国际月球科研站论证与先导试验，天都一号、天都二号试验星是其地月通导技术验证的载体，地月空间导航的技术现状与发展脉络也已有系统梳理 \cite{ShangGuanYongDiYueKongJianDaoHangXianZhuangYuJiShuFaZhanYanJiu2026}。

## 国外组织

### 政府机构

- **NASA**：以阿尔忒弥斯计划重返月球并建设 Gateway 空间站，NRHO 部署与月面着陆体系是当前地月基建的主线之一，详见[阿尔忒弥斯计划](/research-frontiers/directions/security-governance/orbital-game/artemis/)页面。下属 JPL 维护的行星历表是全球深空任务设计的基础设施，DE421 历表至今仍是大量地月任务轨道设计的基础参考 \cite{williamsDE421LunarOrbit2008}，国内对 JPL 行星历表发展与精度的系统比较也以此类产品为基准 \cite{LiuWanYiJPLXingXingLiBiaoDeFaZhanJiBiJiao2022}。
- **ESA**：提出 Moon Village 倡议并推进 Moonlight 月球通信导航星座构想；与 JAXA 联合实施的 BepiColombo 任务中，欧洲团队对无线电科学与加速度计数据的处理分析体现了其深空测量与导航的技术底座 \cite{vecchioFirstAnalysisBepicolombo2024}。
- **JAXA**：SLIM 精准着陆验证器实现日本首次月面着陆 \cite{sakaiMoonLandingResultsSlim2025}；后续与印度和美国在月球极区探测与载人月球车上均有合作布局。
- **KARI**：以 Danuri 绕月探测器切入月球探测，正在推进自身登陆月面与载人月球路线图。
- **DARPA**：以项目制快速迭代航天技术，低轨的黑杰克星座是这一模式的典型 \cite{LiFeiFeiHeiJieKeXiangMuDongXiangJiYingYongQianJingFenXi2020}；同一思路已延伸到地月空间，Oracle 计划瞄准地月空间态势感知。
- **DLR 与 CNES**：德国与法国的航天机构，分别在深空机器人操作与行星导航通信方向保持投入，是欧洲参与月球活动的另一条主线。

### 高校

- **[Purdue University](https://www.purdue.edu/)**：NRHO 理论的奠基地，Kathleen Howell 团队的工作直接支撑了 Gateway 轨道选型；Zimovan 对近直线晕轨道特性与设计策略的系统刻画是该方向的代表性学位论文 \cite{zimovanCharacteristicsDesignStrategies2017}。
- **[University of Colorado Boulder](https://www.colorado.edu/)**：其航天动力学研究中心提出并验证了 LiAISON 地月空间导航体制，为载人月球任务提供了免测控依赖的自主导航思路 \cite{leonardSupportingCrewedMissions2015}。

### 商业公司

- **SpaceX** 以 Starship 载人月面着陆系统承担阿尔忒弥斯登月任务；**Blue Origin** 以 Blue Moon 着陆器家族切入货运与载人月球运输；**Astrobotic** 等公司在 NASA 的 CLPS 框架下提供商业月面递送服务；**ispace** 以 HAKUTO-R 系列推进商业月球着陆。商业力量的共同点是先以运输与递送服务切入，再向月面基础设施延伸。

## 小结

国内外格局可以概括为：国内以高校、院所、集团梯队推进，高校提供轨道与导航等理论方法，院所与集团承担工程总体；国外则是机构、高校、商业三层叠加，机构定标准与任务框架，高校输出基础理论，商业公司从运输服务切入基础设施。本页作为 institutions 栏目的总览入口，后续波次将为院所与集团补齐在库文献支撑，为国外主要机构增建单页，并扩展更多商业公司条目。
