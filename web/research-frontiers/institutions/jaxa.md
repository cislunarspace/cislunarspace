# JAXA

JAXA 即日本宇宙航空研究开发机构，是日本航空航天活动的核心机构，在阿尔忒弥斯计划中以 SLIM 月面精准着陆验证与 Gateway 后勤补给研究承担日方贡献，同时在轨道碎片环境评估方向保持长期积累。

## 月面精准着陆

SLIM 是日本首个实现月面着陆的精准着陆验证器。Sakai 等报告了 SLIM 月面着陆操作的完整结果，从着陆方案设计到实际着陆性能给出系统评估，为后续月面任务提供了轻量化高精度着陆的实现路径 \cite{sakaiMoonLandingResultsSlim2025}。

## Gateway 后勤补给

向月球 Gateway 空间站提供后勤补给是日本参与阿尔忒弥斯计划的候选贡献方向之一。JAXA 正在研制作为 H-II 转移飞行器后继型号的无人航天器 HTV-X，并研究其面向 Gateway 补给任务的增强构型。Nakamura 等针对运行于 L2 南族近直线晕轨道的 Gateway 提出交会轨迹设计方案，覆盖地球至 NRHO 转移、交会对接与 NRHO 内近距离操作各阶段，并以蒙特卡洛仿真评估各阶段方案的鲁棒性 \cite{nakamuraRendezvousTrajectoryDesign2023}。

## 深空合作与轨道环境评估

在深空探测方向，JAXA 与 ESA 联合实施 BepiColombo 水星探测任务，研究团队对任务巡航期间第二次金星飞掠与前两次水星飞掠的无线电跟踪测量与加速度计数据开展联合分析，体现了日本在深空测量领域的国际协作能力 \cite{vecchioFirstAnalysisBepicolombo2024}。在空间活动可持续方向，九州大学与 JAXA 联合开发的 NEODEEM 轨道碎片环境演化模型为评估航天任务对轨道环境的累积影响提供了量化工具，Harada 等据此建立碎片指数评价准则，并以失控废弃的大规模星座任务为对象比较不同指数与演化模型评估结果的相关性，这类方法将为日益拥挤的地月空间交通管理提供评估基础 \cite{haradaEstablishmentDebrisIndex2024}。
