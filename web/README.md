# 地月空间入门指南

从近地轨道到三十八万公里之外的月球，航天器的飞行规律发生了根本变化。地球引力不再独占主导，月球引力与太阳引力相互交织，使空间轨道呈现出多体动力学的丰富形态。

无论是探月工程、载人登月，还是未来的深空物资中转，理解地月空间的力学环境、轨道族特性与工程工具都是基础。本站系统梳理地月空间的核心概念、计算方法与前沿动态，帮助读者建立清晰连贯的专业认知。
