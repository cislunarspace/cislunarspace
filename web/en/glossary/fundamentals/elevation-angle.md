# Elevation angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle between the line-of-sight vector and a reference plane (such as the xy-plane). In optical angle measurement models, computed from the z-axis coordinate difference and the line-of-sight distance between target and observer.

## Application Value

俯仰角是描述航天器姿态的关键参数之一，姿态控制设计师根据俯仰角反馈信息调整推力方向，实现精确的姿态稳定和控制。
