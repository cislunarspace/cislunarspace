# Primary-Centered Rotating Reference Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A rotating reference frame centered on one of the primary bodies in a two-body system. Unit vectors are defined by the line connecting the two primaries and the system's angular velocity direction, used for analyzing spacecraft motion in the three-body problem.

## Application Value

This concept is applied in analysis and design, with important implications for mission performance.
