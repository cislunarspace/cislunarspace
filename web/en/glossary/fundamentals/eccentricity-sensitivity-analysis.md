# Eccentricity Sensitivity Analysis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that treats eccentricity as an augmented state variable and uses second-order STT to evaluate the validity of the CR3BP approximation in the elliptical restricted three-body problem (ER3BP). Results show that for relative motion near Sun-Earth Halo orbits, the CR3BP model's optimal control cost error is within 1%, validating the use of the low-fidelity model for comparative analysis.

## Application Value

This concept has practical applications in cislunar space science and engineering. Related research supports the planning, implementation, and operations of cislunar missions, forming an integral part of the knowledge system in this field.
