# Four-Spacecraft Separation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In a lunar sampling and return mission, the sequential separation of the orbiter, lander, ascent module, and return capsule in lunar orbit. After separation, the lander-ascent combination performs orbit lowering and powered descent, while the orbiter-return combination waits in lunar orbit.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
