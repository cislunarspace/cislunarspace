# LME2000 Reference Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Selenocentric equatorial inertial reference frame referred to the lunar mean equator at J2000 epoch. Final conditions on the selenocentric segment are calculated in this reference frame.

## Application Value

LME2000 Reference Frame is an important concept in cislunar space research with broad applications.
