# Lion-Handelsman gradients

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Gradient expressions for the cost with respect to impulse times and positions, derived by Lion and Handelsman (1968). For terminal impulse time: ∂J/∂t_o = -Δv_o ṗ_o^T p_o. For midcourse impulse position: ∂J/∂r_m = (ṗ_m^+ - ṗ_m^-). For midcourse impulse time: ∂J/∂t_m = -(H_m^+ - H_m^-). These form the basis for nonlinear programming iteration.

## Application Value

Lion-Handelsman gradients form the basis for primer vector theory and nonlinear programming iteration in optimal impulsive orbit transfer design.
