# L2 Norm Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An algebraic smoothing function of the form S/(S^2 + rho)^0.5 that approximates the sign function as rho approaches zero. Computationally efficient but less accurate than the error function approach.

## Application Value

L2 Norm Function provides theoretical support for fundamental research in cislunar space.
