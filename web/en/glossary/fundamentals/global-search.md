# Global Search

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A strategy for systematically searching for optimal solutions across the entire admissible space of initial conditions or costates, as opposed to local optimization from a single initial guess. Global search can discover multiple solution families and the Pareto front, but requires dimension reduction techniques to manage computational cost.

## Application Value

In spacecraft control system design, this method can be used to develop attitude control laws or guidance laws, achieving precise control of spacecraft attitude and orbit. In operational missions, controllers based on this method improve attitude stability and trajectory tracking accuracy.
