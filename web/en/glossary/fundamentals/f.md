# Geometric Argument of Periapsis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle in the orbital plane measuring the spacecraft's current position, measured from periapsis along the direction of motion to the current radius vector. In unified orbital elements, using this angle instead of mean anomaly makes the position definition valid for hyperbolic orbits, though the integration step size is constrained near periapsis.

## Application Value

This concept has important application value in cislunar space research and mission design.
