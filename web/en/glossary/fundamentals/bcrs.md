# Barycentric Celestial Reference System, BCRS

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A relativistic space-time reference frame centered at the solar system barycenter. Its metric tensor is defined by IAU resolutions, using TCB or TDB as the time coordinate. BCRS is more appropriate than GCRS for high-precision cislunar orbit determination and inter-satellite one-way link data processing.

## Application Value

This concept has important application value in cislunar space research and mission design.
