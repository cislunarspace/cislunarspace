# Velocity-Normal-Binormal Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A local coordinate frame where the v-axis is aligned with the spacecraft velocity vector, the n-axis is in the direction of the angular momentum vector, and the b-axis completes the right-handed orthonormal set, used to describe thrust vector direction.

## Application Value

Based on its definition, a local coordinate frame where the v-axis is aligned with the spacecraft velocity vector, the n-axis is in the direction of the angular momentum vector, and the b-axis completes the right-handed ortho.
