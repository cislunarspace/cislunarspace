# IAU Standards of Fundamental Astronomy (SOFA)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The authoritative software library maintained by IAU providing standard algorithms for reference frame conversions, time scale transformations, and other fundamental astronomical calculations. The paper uses SOFA for computing TDB-TT differences at Earth's surface with sub-nanosecond precision.

## Application Value

This concept serves as the foundation for cislunar space coordinate systems and reference frame definitions, providing the baseline for orbital mechanics and navigation calculations.
