# Geocentric Rotating Polar Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A polar coordinate representation within the geocentric rotating frame, describing spacecraft state with radial distance r, polar angle θ, radial velocity v_r, and transverse velocity v_θ. Suitable for describing planar trans-lunar trajectory dynamics.

## Application Value

地心旋转极坐标系是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，地心旋转极坐标系的准确计算和分析对于任务成功至关重要 掌握地心旋转极坐标系的概念有助于工程师进行轨道设计和任务规划 地心旋转极坐标系为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
