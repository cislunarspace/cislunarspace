# Gaussian Mixture Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A probabilistic density model that represents data as a weighted sum of multiple Gaussian distributions. In cislunar orbit determination, it represents multimodal probability distributions of orbital states, enabling sustained tracking even when measurement data is partially missing.

## Application Value

高斯混合模型是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，高斯混合模型的准确计算和分析对于任务成功至关重要 掌握高斯混合模型的概念有助于工程师进行轨道设计和任务规划 高斯混合模型为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
