# Post-Newtonian Parameter, gamma

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A dimensionless parameter in post-Newtonian approximation characterizing the curvature of space, predicted to be unity in general relativity. It appears in the GCRS-BCRS coordinate transformation formulas and is key to determining gravitational field effects on coordinate conversion.

## Application Value

在航天器动力学建模中，需要准确描述引力场、摄动力和坐标系变换。该概念是进行轨道力学分析、姿态控制和任务设计的基础。
