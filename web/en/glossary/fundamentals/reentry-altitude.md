# Reentry Altitude

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The reference altitude for atmospheric reentry, typically set at 120 km as a constraint in free-return trajectory design. This altitude marks where atmospheric drag begins to significantly affect the vehicle's motion.


## Application Value

This orbital design method can be applied to transfer trajectory design, orbit keeping, and mission planning in cislunar space missions, improving spacecraft performance and mission flexibility.
