# Variable Structure Sliding Mode Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A robust nonlinear control method that drives system states to a designed switching surface (sliding surface). Once on the surface, system dynamics depend only on the surface design, making the closed-loop system invariant to parameter perturbations and external disturbances.

## Application Value

This control method provides invariance to parameter perturbations and external disturbances, making it suitable for spacecraft orbit maintenance and attitude control. The sliding surface design drives system states rapidly to desired trajectories with strong robustness in nonlinear and uncertain environments.
