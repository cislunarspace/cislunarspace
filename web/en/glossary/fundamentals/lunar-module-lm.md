# Lunar Module (LM)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The part of a manned lunar lander responsible for lunar surface approach, hovering hazard avoidance, and final landing. It flies independently after separation from the propulsion module, equipped with multiple main engines and attitude thrusters. After landing, it also serves as the ascent vehicle for astronauts to return to lunar orbit.

## Application Value

This concept has application value in cislunar space fundamental research, providing theoretical support for orbital mechanics and mission planning.
