# International Geomagnetic Reference Field

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The worldwide standard model describing Earth's main magnetic field and its secular variation, updated at five-year intervals.

## Application Value

International Geomagnetic Reference Field is valuable for dynamics modeling and analysis in cislunar space research.
