# Precession-Nutation Matrix

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Rotation matrix M(t) describing the directional changes of Earth's spin axis due to precession and nutation, used for transforming between the geocentric celestial and Earth-fixed coordinate systems. It is a key step in the coordinate transformation for computing Earth's J₂ perturbation. In force model simplification, this matrix can be neglected since Earth's J₂ perturbation is small, saving computation time.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
