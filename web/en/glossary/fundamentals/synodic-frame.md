# Synodic Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The rotating reference frame commonly used in the circular restricted three-body problem. Origin at the barycenter of the two primaries, x-axis pointing from the larger to the smaller primary, z-axis along the system angular momentum, co-rotating with the primary line. In this frame the two primaries and all five libration points are stationary, providing the standard framework for studying orbital dynamics near libration points.

## Application Value

会合坐标系是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，会合坐标系的准确计算和分析对于任务成功至关重要 掌握会合坐标系的概念有助于工程师进行轨道设计和任务规划 会合坐标系为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
