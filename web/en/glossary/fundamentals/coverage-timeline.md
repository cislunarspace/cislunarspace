# Coverage Timeline

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A non-negative integer vector describing the number of constellation satellites that can view a target point at each time step. Obtained by circular convolution of the accessibility profile and the constellation pattern vector.

## Application Value

在航天器系统设计和任务分析中，该概念用于描述航天器的运动特性或任务模式，为任务方案论证和系统设计提供理论基础.
