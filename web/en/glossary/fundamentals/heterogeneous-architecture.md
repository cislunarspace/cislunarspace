# Heterogeneous Architecture

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A constellation architecture that assigns power-intensive tasks to fewer satellites, reducing overall power consumption but introducing complexity to power calculations.

## Application Value

在航天器动力学建模中，需要准确描述引力场、摄动力和坐标系变换。该概念是进行轨道力学分析、姿态控制和任务设计的基础。
