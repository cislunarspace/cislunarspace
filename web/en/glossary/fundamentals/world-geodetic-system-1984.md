# World Geodetic System 1984

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The standard geodetic reference ellipsoid model for geodesy and satellite navigation, defining Earth's mean equatorial radius, flattening, and other parameters. Also the reference system used by GPS.

## Application Value

世界大地测量系统1984是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，世界大地测量系统1984的准确计算和分析对于任务成功至关重要 掌握世界大地测量系统1984的概念有助于工程师进行轨道设计和任务规划 世界大地测量系统1984为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
