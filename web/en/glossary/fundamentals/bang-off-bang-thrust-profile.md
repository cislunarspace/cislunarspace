# Bang-off-Bang Thrust Profile

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The characteristic optimal thrust profile for minimum-fuel problems where the engine operates at either maximum thrust or zero thrust, with no intermediate throttling. This structure arises inherently from the Pontryagin Minimum Principle.

## Application Value

Bang-off-Bang推力剖面是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，Bang-off-Bang推力剖面的准确计算和分析对于任务成功至关重要 掌握Bang-off-Bang推力剖面的概念有助于工程师进行轨道设计和任务规划 Bang-off-Bang推力剖面为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
