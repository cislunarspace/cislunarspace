# Primer vector

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The vector p(t) = -λ_v(t) defined by Lawden, where λ_v is the velocity adjoint vector. It determines the optimal thrust direction (impulses are aligned with p) and magnitude (continuous thrust direction matches p). The name originates from Lawden's artillery experience: p=1 signals rocket ignition, analogous to a primer charge.

## Application Value

在低推力轨道优化中，该推进方式可通过长时间持续加速实现低能量转移，比高推力系统更具燃料经济性。
