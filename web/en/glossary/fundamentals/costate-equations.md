# Costate Equations

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A system of first-order ordinary differential equations for the costate variables, derived from the Pontryagin Maximum Principle. They describe how costates evolve over time and, coupled with the state equations, form a two-point boundary value problem. Extreme sensitivity to initial values is the main numerical difficulty of indirect methods.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
