# Osculating Orbital Elements

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The six Keplerian orbital elements of the ellipse a spacecraft would follow at any instant if all perturbations were frozen. As perturbations evolve, the trace of osculating elements on Poincaré sections serves as a key tool for analyzing transfer trajectory evolution.

## Application Value

该方法在轨道转移设计中被用于分析转移通道和能量最优轨迹，为低能量转移方案提供理论支撑。
