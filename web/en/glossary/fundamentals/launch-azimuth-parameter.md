# Launch Azimuth Parameter

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A design variable describing the angle between the initial parking orbit plane and the Earth-Moon orbital plane in the Earth-centered rotating frame.

## Application Value

The Launch Azimuth Parameter describes the angle between the initial parking orbit plane and the Earth-Moon orbital plane in the Earth-centered rotating frame. It is a key design variable for translunar injection trajectory design.
