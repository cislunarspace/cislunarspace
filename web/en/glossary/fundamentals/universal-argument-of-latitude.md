# Universal Argument of Latitude

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angular parameter in unified orbital elements that defines the spacecraft's position, combining RAAN, argument of periapsis, and true anomaly into a single quantity (u=Ω+ω+f). It is well-defined for any conic section regardless of eccentricity, enabling a unified description of an object's position on both elliptic and hyperbolic orbits.

## Application Value

通用近点角是适用于任意离心率轨道的近点角参数，是轨道力学计算的基本参数。
