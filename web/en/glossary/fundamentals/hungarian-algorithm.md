# Hungarian Algorithm

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A combinatorial optimization algorithm that solves the assignment problem on bipartite graphs in polynomial time. In multi-object tracking, it takes the cost matrix as input and assigns each detection to a predicted target (or marks it as new) while minimizing total association cost.

## Application Value

在航天器动力学建模中，需要准确描述引力场、摄动力和坐标系变换。该概念是进行轨道力学分析、姿态控制和任务设计的基础。
