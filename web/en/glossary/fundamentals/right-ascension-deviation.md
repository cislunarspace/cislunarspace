# Right Ascension Deviation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The difference in right ascension between the spacecraft and the target body in the geocentric equatorial inertial frame. Used as an encounter condition in the first search layer to ensure the trajectory targets the Moon.

## Application Value

赤经偏差是实际位置与预期位置的赤经差异，导航系统设计师用它修正轨道确定误差。
