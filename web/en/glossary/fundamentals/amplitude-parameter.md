# Amplitude Parameter

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A parameter describing the size of a distant retrograde orbit in the rotating frame, defined as the absolute difference between the initial x-position and the x-coordinate of the Earth-Moon L1 point. Used to numerically compute DROs with a given Jacobi value or amplitude.

## Application Value

振幅参数描述平动点轨道的大小，是平动点轨道分类和选型的重要参数。
