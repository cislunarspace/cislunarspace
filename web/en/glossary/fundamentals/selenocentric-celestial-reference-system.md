# Selenocentric Celestial Reference System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An inertial reference frame centered at the Moon's mass center with axes parallel to the International Celestial Reference System. Used to describe lunar orbital motion and celestial body positions from ephemeris models.


## Application Value

This orbital design method can be applied to transfer trajectory design, orbit keeping, and mission planning in cislunar space missions, improving spacecraft performance and mission flexibility.
