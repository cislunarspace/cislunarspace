# Parabolic Anomaly

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An auxiliary angle for describing position in a parabolic orbit, defined as B = tan(ν/2), where ν is the true anomaly. Parabolic orbits have zero mechanical energy, with mean motion np = 2√(μ/p³).

## Application Value

Parabolic Anomaly is a fundamental parameter in spacecraft design with significant importance for orbital calculations and mission planning. Accurate understanding and application of this parameter improves the precision and reliability of mission design.
