# Confluent Hypergeometric Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Special function obtained by the confluence of two regular singular points in Gauss's equation; its series converges for all x and has broad applications in astrodynamics.


## Application Value

This dynamic method or concept has significant application value in cislunar space mission analysis, helping to understand and optimize spacecraft motion characteristics.
