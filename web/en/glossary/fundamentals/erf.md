# Error Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A special mathematical function erf(x) = (1/sqrt(pi)) * integral(e^(-t^2)) dt. The paper finds that using erf as the smoothing function halves computation time and reduces terminal rendezvous error by an order of magnitude compared to tanh and L2 alternatives.

## Application Value

The error function is important in smoothing transitions and boundary layer handling, offering more efficient numerical computation than alternatives like tanh, significantly reducing computation time in trajectory optimization.
