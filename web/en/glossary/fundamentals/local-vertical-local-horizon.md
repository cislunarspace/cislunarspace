# Local Vertical Local Horizon

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A local reference frame defined with respect to the target spacecraft, with R-bar pointing to the primary body, H-bar perpendicular to the orbital plane, and V-bar completing the right-handed system.

## Application Value

The LVLH frame is fundamental for relative motion description in rendezvous and proximity operations, providing an intuitive reference for spacecraft formation flying and orbital rendezvous.
