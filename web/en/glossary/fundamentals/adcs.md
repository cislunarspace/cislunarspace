# Attitude Determination and Control System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Attitude subsystem without orbit control capability, used for satellites without a propulsion subsystem.

## Application Value

Attitude Determination and Control System is a fundamental parameter in spacecraft design with significant importance for orbital calculations and mission planning. Accurate understanding and application of this parameter improves the precision and reliability of mission design.
