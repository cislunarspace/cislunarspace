# Error Hyper-Ellipsoid

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A geometric object describing the uncertainty of spacecraft orbital state. The covariance matrix of initial position and velocity errors defines a six-dimensional ellipsoid, which is linearly mapped by the state transition matrix to a terminal error hyper-ellipsoid with altered shape and size. The principal axes and semi-axis lengths are determined by the eigenvectors and eigenvalues of the CGT.
