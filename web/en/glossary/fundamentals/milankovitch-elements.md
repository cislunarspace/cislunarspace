# Milankovitch Elements

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of orbital elements composed of the eccentricity vector and angular momentum vector, totaling 5 independent variables that require one additional angular variable (such as mean anomaly or true longitude). This vectorial parametrization describes orbital shape and spatial orientation, with applications in asteroid orbit research and celestial mechanics.
