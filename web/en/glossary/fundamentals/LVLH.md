# LVLH Frame / Local-Vertical-Local-Horizontal Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Reference frame centered on the target's center of gravity with x-axis along the target's velocity direction and z-axis pointing from target to the primary body.

## Application Value

A target-centered reference frame with the r-axis pointing to the primary body, h-axis parallel to orbital angular momentum, the standard framework for describing relative orbital motion.
