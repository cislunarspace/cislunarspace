# EME2000 Reference Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Earth-centered equatorial inertial reference frame referred to the Earth mean equator at J2000 epoch. All boundary conditions on the geocentric segment are calculated in this reference frame by default.

## Application Value

EME2000 Reference Frame is an important concept in cislunar space research with broad applications.
