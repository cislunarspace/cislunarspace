# Improved Bi-Circular Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A dynamical approximation model adapted from Koon's bi-circular model, using the Earth-Moon barycenter as the origin of the Earth-Moon synodic frame. It decomposes the Sun-Earth-Moon four-body motion into two coupled CR3BP systems: the Sun with the Earth-Moon barycenter forms the Sun-Earth CR3BP, and the Earth with the Moon forms the Earth-Moon CR3BP. The initial state is determined by the initial phase angle. It improves modeling accuracy while maintaining computational efficiency compared to direct four-body numerical integration.

## Application Value

This concept has important application value in cislunar space research and mission design.
