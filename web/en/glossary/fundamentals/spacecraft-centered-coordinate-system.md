# Spacecraft-Centered Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A local coordinate system centered at the spacecraft's current position, using the velocity direction and its perpendicular as basis vectors. Used to decompose impulsive maneuvers into along-track and normal components for convenient description and optimization of maneuver direction.
