# Monopropellant Propulsion System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A propulsion system that uses a single chemical propellant (such as hydrazine), decomposed by a catalyst to produce hot gases and generate thrust. Compared to bipropellant systems, it is simpler and more reliable, suitable for small-to-medium thrust orbital maneuvers and attitude control. The Chang'e-4 relay satellite uses a monopropellant system with twelve 5 N and four 1 N thrusters, carrying about 400 kg of hydrazine propellant.

## Application Value

This concept is fundamental to understanding cislunar space dynamics and plays an important role in orbital mechanics modeling and mission analysis.
