# Priority Comparison Matrix

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A core tool in the Analytic Hierarchy Process (AHP) that determines weights through pairwise comparison of criteria importance. The element at row i, column j indicates the priority of criterion i relative to criterion j, with larger values meaning higher priority. The paper uses this matrix to weight relay communication and navigation performance indices.

## Application Value

The AHP priority comparison matrix determines weights through pairwise criterion comparison, applied to relay communication and navigation performance evaluation.
