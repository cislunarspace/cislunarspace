# Image Trajectory Theorem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A symmetry property of the CRTBP proved by Miele (1960): if (x, y, z, xdot, ydot, zdot, t) is a solution, then (x, -y, z, -xdot, ydot, -zdot, -t) is also a solution. Earth-moon and moon-Earth transfers are mirror images, eliminating the need to compute them separately.

## Application Value

该基础概念是理解地月空间系统行为的出发点。
