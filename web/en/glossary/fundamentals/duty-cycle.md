# Duty Cycle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The ratio of engine active time to total flight time. A duty cycle of 1 indicates full-thrust flight (time-optimal), while near 0 indicates mostly coasting (fuel-optimal). Used as a truncation criterion to detect cost plateaus in trajectory databases.


## Application Value

This orbital design method can be applied to transfer trajectory design, orbit keeping, and mission planning in cislunar space missions, improving spacecraft performance and mission flexibility.
