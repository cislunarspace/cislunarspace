# Adaptive Grid Subdivision

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set-oriented numerical method that starts from an initial rectangle containing a target set and iteratively halves the radius along each coordinate direction, generating progressively finer grid families. After each subdivision step, only cells intersecting the target set are retained. Accuracy can be set independently in each dimension, making it applicable to invariant set computation in varying dimensions.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
