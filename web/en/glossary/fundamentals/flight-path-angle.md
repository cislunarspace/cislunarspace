# Flight Path Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle between the spacecraft velocity vector and the local horizontal plane. In trans-lunar trajectory design, the flight path angle at lunar arrival is an important constraint parameter that determines the spacecraft's approach geometry to the Moon (flyby or orbital insertion). A zero flight path angle means the velocity lies in the local horizontal plane; positive indicates an upward inclination and negative a downward one.

## Application Value

在航天器动力学建模中，需要准确描述引力场、摄动力和坐标系变换。该概念是进行轨道力学分析、姿态控制和任务设计的基础。
