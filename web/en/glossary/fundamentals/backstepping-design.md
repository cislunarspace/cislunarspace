# Backstepping Design

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A recursive nonlinear control design method that decomposes a high-order nonlinear system into a chain of subsystems. A Lyapunov function and virtual control are designed for each subsystem sequentially, stepping back from the last subsystem to the first to complete the full control law.

## Application Value

反演设计是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，反演设计的准确计算和分析对于任务成功至关重要 掌握反演设计的概念有助于工程师进行轨道设计和任务规划 反演设计为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
