# Geocentric Rotating Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A rotating reference frame with Earth's center as origin, the Earth-Moon line as x-axis, and the Moon's orbital angular momentum direction as z-axis. Unlike the Earth-Moon barycentric rotating frame, its origin is fixed at Earth's center, enabling direct analysis of control variables versus transfer time for two-impulse trans-lunar trajectories.

## Application Value

在进行轨道转移设计时，This概念有助于评估转移代价和飞行时间，为任务方案比选provides定量依据。结合全局搜索算法，可找到多族解和帕累托前沿，指导轨道设计决策。
