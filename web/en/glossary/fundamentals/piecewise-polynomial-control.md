# Piecewise Polynomial Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A control parameterization method that represents the continuous control function as piecewise polynomials over the time interval, with polynomial coefficients as optimization variables. This projects the infinite-dimensional control function space onto a finite-dimensional parameter space, enabling solution by nonlinear programming algorithms.

## Application Value

在轨道控制律设计中，该方法通过优化推力方向和大小实现燃料消耗最小化，是深空任务的核心技术。
