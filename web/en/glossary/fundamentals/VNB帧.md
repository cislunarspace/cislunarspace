# Velocity-Normal-Binormal Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A local coordinate frame where the v-axis is aligned with the spacecraft velocity vector, the n-axis is in the direction of the angular momentum vector, and the b-axis completes the right-handed orthonormal set, used to describe thrust vector direction.

## Application Value

A local coordinate frame with the velocity direction as the principal axis, suitable for describing thrust vector direction and relative motion analysis, widely used in orbital maneuvers and rendezvous and docking.
