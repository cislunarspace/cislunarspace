# Triple-Junction Gallium Arsenide Solar Array

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A solar cell cascading three layers of gallium arsenide (GaAs) semiconductor materials with different bandgaps, each absorbing a different portion of the solar spectrum, achieving photoelectric conversion efficiency exceeding 30%. Compared to conventional silicon solar cells, it is lighter and more radiation-resistant, representing the mainstream power solution for current deep space exploration spacecraft. The Chang'e-4 relay satellite uses this type of solar array paired with lithium-ion battery packs.
