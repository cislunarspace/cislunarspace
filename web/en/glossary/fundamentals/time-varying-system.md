# Time-Varying System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A linear system whose system matrices A(t), B(t), C(t) vary with time. Under the CR3BP framework, the coefficient matrices of the relative motion equations depend on the chief spacecraft's instantaneous position in the rotating frame, making the system inherently time-varying. Distinguished from linear time-invariant systems by the loss of time-translation invariance in the superposition principle, which increases both analytical and control design complexity.
