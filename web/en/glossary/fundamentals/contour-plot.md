# Contour Plot

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A graphical representation showing the distribution of a bivariate function over a two-dimensional plane using contour lines. In this paper, it is used to display the spatial distribution of the c* value to determine the reality of the angular rate expression root and the extent of the feasible trajectory region.

## Application Value

轮廓图以等值线形式展示二元function分布, used for judge角velocity表达式根 of 实数性和轨迹可行性region. is orbitdesign中 of 常用可视化工具.
