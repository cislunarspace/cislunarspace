# Lightweight Fully-Connected Neural Network

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A compact fully-connected network architecture designed for limited onboard computational resources. The paper employs a 17-40-25-10-3 four-hidden-layer structure with approximately 1,368 total parameters, using Sigmoid activation and Bayesian regularization backpropagation. It achieves impulse proportionality coefficient prediction accuracy (relative error below 3%) while keeping the parameter count within deployable onboard limits.

## Application Value

The Lightweight Fully-Connected Neural Network employs a compact architecture with approximately 1,368 parameters, using Sigmoid activation and Bayesian regularization backpropagation. It achieves impulse proportionality coefficient prediction accuracy (relative error below 3%) while remaining deployable on onboard systems.
