# Variable-Order Adams Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A numerical ODE integration method that dynamically adjusts polynomial order to balance accuracy and efficiency. The DIVA integrator used in this study belongs to this class, with a tolerance of 1e-12, suitable for long-duration high-precision propagation in ephemeris models.
