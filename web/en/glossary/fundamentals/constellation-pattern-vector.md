# Constellation Pattern Vector

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A binary vector describing the time delays (phase offsets) of multiple satellites on the same orbit relative to a seed satellite. Positions with value 1 correspond to a satellite's phase offset time step.

## Application Value

在轨道设计和转移轨道优化中，该方法用于确定最优转移时机和轨道形状，以最小化燃料消耗或飞行时间. 通过数值仿真和迭代优化，可获得满足任务约束的可行轨道方案.
