## Definition

Impulse generated per unit weight of propellant; fundamental metric for propulsion system efficiency.

## Application Value

Specific Impulse, Isp is a fundamental parameter in spacecraft design with significant importance for orbital calculations and mission planning. Accurate understanding and application of this parameter improves the precision and reliability of mission design.
