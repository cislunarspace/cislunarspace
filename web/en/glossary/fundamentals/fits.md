# Flexible Image Transport System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The standard data exchange format in astronomy, supporting storage and transmission of images, spectra, and tabular data. Files contain header information describing observation conditions (telescope parameters, exposure time, coordinate system) and scientific data arrays. It is the universal input format for astronomical image processing.

## Application Value

This term has significant practical applications in cislunar mission planning and execution.
