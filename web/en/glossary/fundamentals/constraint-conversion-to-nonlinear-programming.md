# Constraint Conversion to Nonlinear Programming

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A modeling approach that converts differential equation constraints, boundary conditions, and terminal constraints of trans-lunar trajectory design into a nonlinear programming problem, solvable by algorithms such as SNOPT.

## Application Value

在进行轨道转移设计时，This概念有助于评估转移代价和飞行时间，为任务方案比选provides定量依据。结合全局搜索算法，可找到多族解和帕累托前沿，指导轨道设计决策。
