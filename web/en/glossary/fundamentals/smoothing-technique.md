# Smoothing Technique

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique that approximates the discontinuous sign function in the switching function with differentiable parameterized functions, enabling indirect methods to solve minimum-fuel problems by smoothing the bang-off-bang control profile.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
