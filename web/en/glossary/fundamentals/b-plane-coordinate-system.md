# B-Plane Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A reference frame for collision probability analysis, centered on the secondary target at closest approach. Its axes are defined by the cross product of velocities, the relative velocity direction, and the perpendicular to that plane, projecting 3D uncertainty onto a 2D collision analysis surface.

## Application Value

B平面坐标系是以目标天体为原点的坐标系统，常用于描述飞越探测器的飞越参数。
