# Generalized Rodrigues Parameters

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A non-singular attitude error parameter, related to modified Rodrigues parameters and Gibbs vector

## Application Value

GRP provides non-singular attitude representation for wide-angle maneuvers, avoiding singularities inherent in Euler angles and offering computational advantages in attitude estimation.
