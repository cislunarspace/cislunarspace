# Mid-course Correction (TCM)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Orbital correction maneuvers performed during Earth-Moon transfer. Planning variables are the three-component velocity increments in the inertial frame, targeting the first perilune time, orbital inclination, and perilune altitude, with joint planning across subsequent LOI, orbit lowering, and powered descent phases.

## Application Value

在设计地月转移方案时，利用该轨道特性可降低任务总速度增量需求。中途修正用于消除轨道偏差，是保证按时到达目标的关键环节。
