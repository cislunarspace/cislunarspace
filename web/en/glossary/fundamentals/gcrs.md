# Geocentric Celestial Reference System, GCRS

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A relativistic space reference frame centered at the Earth's center of mass, with spatial axes aligned with BCRS per IAU resolution (no rotation). Widely adopted for near-Earth high-precision applications. The study demonstrates that GCRS suffices for decimeter-level orbit determination accuracy in cislunar space.

## Application Value

This concept has important application value in cislunar space research and mission design.
