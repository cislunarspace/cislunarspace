# Feature Pyramid Network, FPN

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A multi-scale feature extraction architecture that combines feature maps of different resolutions through bottom-up and top-down pathways, enabling neural networks to detect both large and small objects. Used together with ResNet in space object detection.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
