# State Equation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A first-order differential equation system describing system dynamics using a state vector, in the form dx/dt = A(t)x + Bu, y = Cx. Converting second-order equations of motion into first-order state equations is the standard step in modern control theory, enabling the direct application of optimal control, state feedback, and state estimation methods.

## Application Value

在航天器姿态和轨道控制中，该方法用于实现高精度跟踪和稳定保持. 通过设计合适的控制律，可以有效抑制外部扰动的影响，保证航天器在复杂动力学环境中的可靠运行.
