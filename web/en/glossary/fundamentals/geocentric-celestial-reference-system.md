# Geocentric Celestial Reference System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A reference system with its origin at Earth's center. Current Earth satellite ephemerides are described in this frame with time arguments being geocentric coordinate time (TCG) or Earth dynamic time (TDB). When Earth satellites establish inter-satellite links with cislunar spacecraft, coordinate transformation between GCRS and BCRS is required.
