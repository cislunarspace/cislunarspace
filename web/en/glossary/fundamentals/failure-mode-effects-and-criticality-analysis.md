# Failure Mode Effects and Criticality Analysis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An inductive bottom-up failure analysis method used to evaluate potential effects of each failure mode on the system and identify critical items.

## Application Value

在轨道动力学数值仿真中，该方法用于提高计算精度和效率. 通过合理的离散化策略，可以在保证数值稳定性的同时大幅减少计算量.
