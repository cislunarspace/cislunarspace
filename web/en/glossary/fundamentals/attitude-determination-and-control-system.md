# Attitude Determination and Control System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Attitude subsystem without orbit control capability, used for satellites without a propulsion subsystem.

## Application Value

In orbital mechanics analysis and mission design, this concept provides theoretical basis for orbit characteristic evaluation and scheme comparison, helping to optimize orbit design parameters and improve mission economy.
