# Boundary Value Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In solving differential equations, a problem where variable values at the boundaries of the domain (rather than initial values) are known, and the distribution of variables within the domain is to be determined. Contrasted with initial value problems. The core innovation of this paper is converting debris cloud evolution from a Monte Carlo initial value problem into a cislunar space boundary value problem: given debris departure position r1 and arrival position r2, solve for the required transfer velocity, thereby directly obtaining debris probability density at specific locations.

## Application Value

This concept has important application value in cislunar space research and mission design.
