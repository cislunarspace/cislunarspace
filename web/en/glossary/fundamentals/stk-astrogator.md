# STK Astrogator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

General-purpose orbit and mission analysis software developed by AGI. This paper uses STK Astrogator for orbit propagation analysis, calculating orbital evolution under multi-body gravitational effects at any specified time given initial orbital elements and maneuver application.
