# Scheduled Takeoff

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An orbital control approach that launches the ascent module from the lunar surface at a scheduled time, ensuring the injection orbit plane is virtually coplanar with the orbiter's orbit. Used jointly with scheduled and pinpoint landing to reduce fuel consumption for orbital plane correction during remote guidance.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
