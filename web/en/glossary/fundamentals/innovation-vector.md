# Innovation Vector

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The difference between the actual measurement and the predicted measurement in a filter. It reflects new information contained in the measurement and serves as the core indicator for adaptive filters to assess system health.

## Application Value

Innovation Vector provides theoretical support for fundamental research in cislunar space.
