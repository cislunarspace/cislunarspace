# Reconstructed Harmonic Balance Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A numerical method for solving periodic orbits of nonlinear dynamical systems, using harmonic expansion and reconstruction techniques to obtain highly accurate periodic solutions and generate a richer set of DRO families than traditional differential correction methods.

## Application Value

This concept is applicable in cislunar space mission design, orbit optimization, and trajectory planning for spacecraft transfers and maneuver strategies.
