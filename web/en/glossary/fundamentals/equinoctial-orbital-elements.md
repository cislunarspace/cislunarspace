# Equinoctial Orbital Elements

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A class of nonsingular orbital elements that replaces conventional elements with P1=e sin(ω̄), P2=e cos(ω̄), Q1=tan(i/2) sin Ω, Q2=tan(i/2) cos Ω, and mean longitude λ, avoiding singularities for circular orbits or zero inclination.

## Application Value

在春分点轨道根数的设计与分析中，可用于优化转移方案，减少燃料消耗 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
