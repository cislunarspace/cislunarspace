# Pseudo-orbital Elements

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Camera attitude parameters analogous to orbital elements in the two-body problem (i, Omega, theta). Though no longer describing motion in the three-body problem, they describe spacecraft attitude at a given timestep.

## Application Value

准轨道根数是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，准轨道根数的准确计算和分析对于任务成功至关重要 掌握准轨道根数的概念有助于工程师进行轨道设计和任务规划 准轨道根数为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
