# Universal Gravitational Constant

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The proportionality constant in Newton's law of gravitation, value 6.6742×10⁻¹¹ m³/(kg·s²).

## Application Value

Universal Gravitational Constant is a fundamental parameter in spacecraft design with significant importance for orbital calculations and mission planning. Accurate understanding and application of this parameter improves the precision and reliability of mission design.
