# DE421 Ephemeris

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A high-precision solar system ephemeris published by the Jet Propulsion Laboratory (JPL), catalog number 421. It provides position and velocity data for the Sun, Moon, and major planets, widely used for N-body perturbation calculations in precision orbit determination for deep space missions. Later versions include DE430, DE440, etc.
