# Ascending Node

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The point where a celestial body crosses a reference plane (such as the ecliptic or lunar orbital plane) from south to north.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
