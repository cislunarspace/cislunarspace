# Piecewise Linear Interpolation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A numerical method that uses linear functions to interpolate between adjacent known data points. In this paper, grid points that did not converge during Eulerian grid computation are assigned debris probability density values using two-dimensional piecewise linear interpolation, to complete the density distribution map across the entire grid region.

## Application Value

Piecewise Linear Interpolation uses linear functions to interpolate between adjacent known data points. In debris probability density computation, it completes the density distribution map across the entire grid region for unconverged grid points.
