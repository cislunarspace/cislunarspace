# Propulsion Module, PM

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The part of a manned lunar lander responsible for the main braking phase flight. Equipped with one main engine and thrust vector control, it serves as the primary deceleration power source from the powered descent initiation point to the separation coast phase.

## Application Value

The propulsion module serves as the primary deceleration power source for crewed lunar landers, equipped with thrust vector control for precise descent trajectory control. During powered descent, the module's performance directly determines landing accuracy and mission safety.
