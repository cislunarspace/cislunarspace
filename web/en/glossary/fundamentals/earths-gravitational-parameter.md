# Earth's Gravitational Parameter

> Author: [Tianjiang Says](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Earth's gravitational parameter, value 398600 km³/s². It is the product of the gravitational constant G and Earth's mass M, representing the strength of Earth's gravitational field in orbital mechanics calculations.

## Application Value

Accurate characterization of gravitational fields is fundamental to spacecraft dynamics modeling, perturbation analysis, and coordinate system transformations. This parameter serves as a foundational element in orbital mechanics analysis, attitude control, and mission design for cislunar operations.
