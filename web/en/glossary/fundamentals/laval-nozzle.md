# Laval Nozzle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Convergent-divergent supersonic nozzle that accelerates subsonic flow to supersonic velocities

## Application Value

The Laval Nozzle is a key component that accelerates subsonic flow to supersonic velocities. Rocket engine designers use its principles to design nozzle shapes, achieving efficient thrust output and forming the theoretical basis for deep space explorer propulsion system design.
