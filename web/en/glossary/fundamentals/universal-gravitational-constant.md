# Universal Gravitational Constant

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The proportionality constant in Newton's law of gravitation, value 6.6742×10⁻¹¹ m³/(kg·s²).

## Application Value

In orbital mechanics analysis, this perturbation factor is one of the main sources of orbit prediction error. Accurate modeling of this effect helps improve orbit prediction accuracy and supports applications such as orbit maintenance and collision early warning.
