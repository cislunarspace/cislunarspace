# Zero-Velocity Curve

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In the restricted circular three-body problem, the equipotential contour where velocity is zero, determined by the Jacobi constant. It partitions the configuration space in the rotating frame into allowed and forbidden regions for motion, serving as a fundamental tool for analyzing possible spacecraft trajectories. Topological changes in the zero-velocity curve as the Jacobi constant varies govern the connectivity and isolation of accessible motion regions.

## Application Value

Based on its definition, in the restricted circular three-body problem, the equipotential contour where velocity is zero, determined by the jacobi constant. it partitions the configuration space in the rotating frame into all.
