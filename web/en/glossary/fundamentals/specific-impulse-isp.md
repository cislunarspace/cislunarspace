# Specific Impulse, Isp (Isp)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Impulse generated per unit weight of propellant; fundamental metric for propulsion system efficiency.

## Application Value

推进系统参数直接影响航天器的机动能力和任务持续时间。比冲是衡量推进剂效率的关键指标，影响任务推进剂需求量。
