# Dynamic Reference Catalog

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An interactive trajectory design tool for the Earth-Moon system. Unlike a static database, it computes periodic orbit family parameters (size, period, Jacobi constant, stability index, transfer cost, time-of-flight, station-keeping cost, etc.) on demand, enabling users to filter, compare, and export candidate orbits as a rapid decision framework for preliminary mission design.

## Application Value

During the orbit design phase, this orbit type can be used to build a candidate orbit pool for constellation deployment and mission orbit selection. During operations, its characteristics inform station-keeping strategy design, reducing propellant consumption. In transfer trajectory planning, its stable manifold structure guides the search for low-energy transfer corridors.
