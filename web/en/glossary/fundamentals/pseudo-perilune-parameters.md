# Pseudo Perilune Parameters

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of four design variables for preliminary free-return trajectory design, comprising pseudo perilune longitude, pseudo perilune latitude, perilune velocity azimuth angle, and perilune orbital eccentricity. Given the perilune time and altitude, these four parameters fully determine the initial state of the lunar-centered orbit segment, from which the complete free-return trajectory is propagated via the multi-conic method. Using pseudo parameters rather than direct position and velocity as design variables facilitates converting reentry constraints into constraints on perilune parameters.
