# Gramian matrix condition number

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The ratio of the maximum to minimum eigenvalues of the Gramian matrix. A large condition number means measurement outputs from small changes in one estimated state can mask changes in another state. Generally, values below 10^16 indicate adequate observability.
