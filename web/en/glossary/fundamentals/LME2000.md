# LME2000 Reference Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Selenocentric equatorial inertial reference frame referred to the lunar mean equator at J2000 epoch. Final conditions on the selenocentric segment are calculated in this reference frame.

## Application Value

An inertial coordinate frame with Moon's center of mass as origin and Moon's equatorial plane as reference, the standard reference frame for describing lunar probe orbits.
