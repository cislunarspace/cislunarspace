# h-e Space Analysis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method using scaled angular momentum and eccentricity vectors to rapidly estimate the delta-V cost between two orbits. The Cartesian distance in h-e space approximates transfer cost, enabling fast pre-filtering of candidate injection points before detailed optimization.


## Application Value

This control method can be applied to spacecraft attitude stabilization, orbit keeping, and maneuver trajectory optimization in cislunar space missions, improving mission execution flexibility and reliability.
