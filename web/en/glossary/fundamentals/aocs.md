# Attitude and Orbit Control System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The subsystem performing attitude estimation, guidance, and control when orbit guidance is not performed on board, typical for LEO, MEO, and GEO missions.

## Application Value

Attitude and Orbit Control System is a fundamental parameter in spacecraft design with significant importance for orbital calculations and mission planning. Accurate understanding and application of this parameter improves the precision and reliability of mission design.
