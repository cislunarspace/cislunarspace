# Eigenvector

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A fundamental linear algebra concept. In libration point orbit dynamics, eigenvectors of the monodromy matrix indicate the initial perturbation direction of invariant manifolds.

## Application Value

在轨道力学分析和任务设计中，This概念为轨道特性评估和方案比选provides理论依据，有助于优化轨道设计参数，提高任务经济性。
