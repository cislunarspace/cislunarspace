# Reference Ellipsoid

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Rotational ellipsoid used to approximate Earth's shape, with parameters (semi-major axis, flattening, etc.) internationally agreed upon, serving as the basis for geodesy and cartography.

## Application Value

在态势感知系统中，该观测方法为低轨空间目标监视提供技术手段，是空间交通管理的数据来源。
