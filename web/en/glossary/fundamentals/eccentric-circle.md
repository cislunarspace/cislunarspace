# Eccentric Circle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Model in ancient Greek astronomy describing planetary motion where the Earth is not at the center and the planet moves uniformly on an eccentric circle.

## Application Value

The eccentric circle model represents the earliest attempt to explain planetary apparent motion irregularities using geometric methods in history. Although modern celestial mechanics has replaced it with Kepler's laws and elliptical orbits, the core concept of the eccentric circle model — using an eccentric point as reference to describe periodic motion — still profoundly influences teaching and understanding of orbital mechanics. In engineering applications, when satellite orbit eccentricity is small, eccentric circles can approximate its motion; this approximation is highly practical for qualitative analysis and rapid estimation scenarios. Studying the eccentric circle model also helps understand the evolution of the epicycle-deferent system and how ancient astronomers progressively approached true planetary motion laws.
