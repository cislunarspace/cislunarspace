# Rapid Engine Fault Diagnosis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The technology for autonomous detection and handling of lunar module orbit-control engine faults within hundreds of milliseconds. During lunar ascent, a single engine fault causes the opposing engine to produce disturbance torques far exceeding attitude control capability, potentially causing immediate tip-over. The fault engine and its opposite must be rapidly shut down, with heterogeneous sensing systems (exhaust temperature, engine mount strain, etc.) for reliable diagnosis.

## Application Value

This concept is applied in analysis and design, with important implications for mission performance.
