# LVLH Frame / Local-Vertical-Local-Horizontal Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A non-inertial reference frame with origin at the chief satellite's center of mass: the X-axis aligns with the chief's position vector, the Z-axis aligns with the chief's orbital angular momentum, and the Y-axis completes the right-handed frame. Used to describe the deputy's relative motion with respect to the chief.
