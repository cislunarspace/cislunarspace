# Flight Path Angle, FPA

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle between the velocity vector and the local horizontal plane. For lunar landing, the FPA determines trajectory steepness: a vertical impact is 90 deg while a grazing approach is near 0 deg. It directly affects thermal protection and guidance requirements.
