# Reentry Flight Path Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle between the vehicle's velocity vector and the local horizontal plane during atmospheric reentry. Free-return trajectory design requires satisfying a reentry flight path angle constraint (e.g., -6 degrees) to ensure proper atmospheric entry trajectory.

## Application Value

在轨道力学分析和任务设计中，This概念为轨道特性评估和方案比选provides理论依据，有助于优化轨道设计参数，提高任务经济性。
