# Concurrent Design (CD)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Multi-disciplinary team simultaneously designing system parts in parallel to detect interface conflicts early.

## Application Value

Concurrent design breaks away from traditional sequential design by enabling multiple subsystem teams (orbit, structure, thermal control, communication, attitude control, etc.) to work simultaneously, detecting and resolving interface conflicts early through shared design models and data. Cislunar mission design involves multidisciplinary coupling, and adopting concurrent design methods can significantly shorten the design iteration cycle and reduce late-stage modification costs. In practice, concurrent design typically relies on a unified design database and parameter management tools to ensure all teams use consistent design parameters and versions.
