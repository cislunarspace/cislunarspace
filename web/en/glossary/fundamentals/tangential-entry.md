# Tangential Entry

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An orbital entry mode where the velocity vector is perpendicular to the position vector upon reaching the target orbit. Mathematically expressed as r·v = 0. Tangential entry maximizes orbital capture efficiency and represents the ideal condition for the terminal maneuver in two-impulse transfers.

## Application Value

在轨道设计和转移轨道优化中，该方法用于确定最优转移时机和轨道形状，以最小化燃料消耗或飞行时间. 通过数值仿真和迭代优化，可获得满足任务约束的可行轨道方案.
