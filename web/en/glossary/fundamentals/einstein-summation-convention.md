# Einstein Summation Convention

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A notational convention in tensor analysis that omits the summation symbol: when the same index appears as both superscript and subscript, summation over all components of that index is implied. Used in high-order state transition tensor expressions to concisely describe multi-dimensional partial derivative expansions.

## Application Value

在航天器动力学建模中，需要准确描述引力场、摄动力和坐标系变换。该概念是进行轨道力学分析、姿态控制和任务设计的基础。
