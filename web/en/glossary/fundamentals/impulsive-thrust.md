# Impulsive Thrust

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An orbital maneuver model where the velocity change is assumed to occur instantaneously. Valid when the thrust duration is much shorter than the orbital period.

## Application Value

在航天器动力学建模中，需要准确描述引力场、摄动力和坐标系变换。该概念是进行轨道力学分析、姿态控制和任务设计的基础。
