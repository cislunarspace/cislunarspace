# Horizontal Flight Path Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle between the velocity vector and the local horizontal plane. In orbital mechanics, a zero horizontal flight path angle indicates the velocity is parallel to the local horizontal (as in a circular orbit), and a positive value indicates motion away from the central body. In this paper, it describes the velocity direction characteristics at maneuver points of the three-impulse orbit, serving as a key geometric parameter for analyzing out-of-plane maneuver impulse components.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
