# Global Analysis of Invariant Objects

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set-oriented software package for analyzing the global structure of dynamical systems. It uses an adaptive grid subdivision tree structure and supports covering approximations of invariant sets, manifold computation, and global transfer search. This paper uses its box covering functionality to systematically detect invariant manifold intersections on Poincare sections.

## Application Value

This method studies chaotic characteristics of dynamical systems through global invariant set analysis.
