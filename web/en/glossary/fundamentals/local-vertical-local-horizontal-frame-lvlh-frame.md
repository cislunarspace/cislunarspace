# Local Vertical Local Horizontal Frame, LVLH Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A target-centered reference frame where the r-axis points toward the primary body (Moon), the h-axis is parallel to the orbital angular momentum, and the θ-axis completes the right-hand triad, used for relative orbit motion description.
