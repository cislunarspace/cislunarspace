# Differential Evolution

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A population-based stochastic global optimization algorithm in the evolutionary computation family. It iteratively searches for the global optimum in continuous spaces through mutation, crossover, and selection operations. Mutation uses difference vectors between population members to generate new candidates, making it efficient and simple to implement for continuous parameter optimization. The paper uses DE to search for globally optimal exponential sinusoid trajectories for Earth-Mars low-thrust transfers.
