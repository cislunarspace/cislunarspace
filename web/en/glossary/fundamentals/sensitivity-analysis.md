# Sensitivity Analysis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Analysis of how the optimal solution changes with problem parameters. In optimal control, first-order sensitivities are obtained directly from Lagrange multipliers associated with parameter constraints, without re-solving the optimization. For the Genesis mission, sensitivity analysis revealed the near-linear relationship between optimal fuel cost and launch velocity error or TCM1 delay.


## Application Value

In a linear quadratic optimal control framework, selecting appropriate weight matrices Q and R achieves a balance between tracking accuracy and control energy consumption, making it suitable for real-time control in cislunar orbit keeping.
