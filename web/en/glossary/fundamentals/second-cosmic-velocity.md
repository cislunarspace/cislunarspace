# Second Cosmic Velocity

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Minimum velocity for an object to escape Earth's gravitational field from its surface, approximately 11.18 km/s

## Application Value

第二宇宙速度是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，第二宇宙速度的准确计算和分析对于任务成功至关重要 掌握第二宇宙速度的概念有助于工程师进行轨道设计和任务规划 第二宇宙速度为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
