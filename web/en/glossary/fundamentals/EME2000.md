# EME2000 Reference Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Earth-centered equatorial inertial reference frame referred to the Earth mean equator at J2000 epoch. All boundary conditions on the geocentric segment are calculated in this reference frame by default.

## Application Value

An inertial coordinate frame with Earth's center of mass as origin and Earth's equatorial plane as reference, the standard reference frame for describing Earth satellite orbits.
