# Hidden-Genes Genetic Algorithm

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A multi-objective optimization algorithm developed by Visonneau et al. for cislunar SSA architecture design. By introducing a hidden-genes mechanism in chromosomes, it allows orbit family diversity (e.g., Halo, L1/L2 orbits) and phase coordination, generating Pareto-optimal solutions with limiting magnitude improvements exceeding 50%.

## Application Value

Algorithms are central to navigation, control, and orbit computation; efficient and reliable algorithms are critical to mission success.
