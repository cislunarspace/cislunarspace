# Parabolic Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A conic orbit with eccentricity e=1, representing the critical case between ellipse and hyperbola. The spacecraft reaches exactly escape speed and follows an open parabolic trajectory. The traditional semi-major axis diverges at e=1; unified elements avoid this singularity by using the semi-latus rectum p=2r_p.

## Application Value

This concept is applicable in cislunar space mission design, orbit optimization, and trajectory planning for spacecraft transfers and maneuver strategies.
