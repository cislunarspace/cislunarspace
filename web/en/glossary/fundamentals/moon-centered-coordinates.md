# Moon-centered Coordinates

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An inertial reference frame with origin at the Moon's center of mass and fixed axes orientation.

## Application Value

月心坐标是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，月心坐标的准确计算和分析对于任务成功至关重要 掌握月心坐标的概念有助于工程师进行轨道设计和任务规划 月心坐标为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
