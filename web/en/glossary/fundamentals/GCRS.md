# Geocentric Celestial Reference System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A space-time reference system with its origin at the Earth's center, which can be transformed to BCRS via Lorentz transformation.

## Application Value

This reference frame has fundamental applications in cislunar orbital calculations and observation data processing.
