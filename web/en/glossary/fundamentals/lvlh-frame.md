# LVLH frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A local position frame centered on the chief spacecraft, with x-axis along the position vector of chief spacecraft, z-axis along orbit normal, and y-axis completing right-handed system. Used to describe relative motion of spacecraft formations.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
