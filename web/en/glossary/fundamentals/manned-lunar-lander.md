# Manned Lunar Lander

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A spacecraft designed to safely deliver astronauts to the lunar surface, consisting of a propulsion module and a lunar module. The propulsion module performs main braking with a main engine and thrust vector control, while the lunar module completes approach, hovering, and final landing with multiple main engines and attitude thrusters.

## Application Value

为航天器的精确控制提供理论依据，确保任务执行的可靠性 在任务规划阶段用于评估不同推进方案的优劣。
