# Two-Body Conic Patching Assumption

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An approximation that models multi-body trajectories as patched conic segments, each dominated by a central body. Used for rapid initial guess estimation, it is a common technique to reduce problem complexity in trajectory design.

## Application Value

二体圆锥曲线拼接假设是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，二体圆锥曲线拼接假设的准确计算和分析对于任务成功至关重要 掌握二体圆锥曲线拼接假设的概念有助于工程师进行轨道设计和任务规划 二体圆锥曲线拼接假设为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
