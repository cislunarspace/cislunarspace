# Lunar Equatorial Plane

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The plane passing through the Moon's center perpendicular to the lunar rotation axis, serving as the common reference plane for both the lunar body-fixed frame and the lunar inertial frame. The lunar equatorial plane is inclined approximately 1°32' relative to the ecliptic, so the Sun's lunar sub-satellite point latitude varies within a narrow range. In the paper, the coordinate transformations from the orbital frame to the inertial frame and from the inertial frame to the body-fixed frame all use the lunar equatorial plane as the reference plane.

## Application Value

The lunar equatorial plane is a foundational concept in cislunar space research, laying the groundwork for understanding more complex spacecraft dynamics problems. In engineering practice, accurate computation and analysis of the lunar equatorial plane are critical to mission success. A solid grasp of this concept helps engineers carry out orbit design and mission planning. It provides a basic frame of reference for the study of spacecraft orbital mechanics and paves the way for advanced concepts.
