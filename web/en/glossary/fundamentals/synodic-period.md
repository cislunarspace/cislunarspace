# Synodic Period

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The time for the Sun-Earth-Moon system to return to the same relative configuration, approximately 29.5 days. In cislunar SDA, it serves as the natural timescale for evaluating target tracking uptime. All simulations in this paper span a full synodic period.

## Application Value

This术语在地月空间任务的设计、分析和控制中具有important应用价值，为相关技术领域的研究和工程实践provides理论支撑。
