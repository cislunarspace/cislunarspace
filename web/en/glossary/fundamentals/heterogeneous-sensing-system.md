# Heterogeneous Sensing System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A fault diagnosis system that directly determines engine operating status through multiple physical quantities (such as engine exhaust temperature, engine mount strain, etc.). Cross-validation among heterogeneous information sources enables fast and reliable diagnosis, avoiding false alarms from single sensors.

## Application Value

This concept is essential for understanding motion characteristics in spacecraft dynamics analysis and design, and plays a vital role in mission success.
