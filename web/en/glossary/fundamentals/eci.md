# Earth-Centered Inertial (ECI) frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An inertial coordinate frame with origin at the Earth's center, z-axis pointing to the celestial north pole, and x-axis toward the vernal equinox. It does not rotate with the Earth and serves as the fundamental reference frame for deep space orbit dynamics and determination.

## Application Value

The Earth-Centered Inertial frame is the reference frame for Earth satellite navigation.
