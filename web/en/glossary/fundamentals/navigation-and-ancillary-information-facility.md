# Navigation and Ancillary Information Facility

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A NASA Jet Propulsion Laboratory service providing high-precision ephemeris and ancillary information data for planetary bodies, used to obtain positions of celestial bodies at arbitrary epochs.

## Application Value

NAIF SPICE provides high-precision ephemeris data for planetary bodies, enabling accurate position and velocity determination at arbitrary epochs for mission analysis.
