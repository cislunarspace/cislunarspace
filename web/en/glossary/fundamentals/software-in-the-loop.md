# Software-in-the-Loop

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A verification method where target software runs on a host computer while interfacing with real-time physical models. An important step in the V&V process.

## Application Value

In orbital dynamics numerical simulation, this method is used to improve computational accuracy and efficiency. Through reasonable discretization strategies, computational load can be significantly reduced while maintaining numerical stability.
