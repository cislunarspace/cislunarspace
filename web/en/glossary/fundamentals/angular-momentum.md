# Angular Momentum

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angular momentum of a particle about a point equals the cross product of the position vector and linear momentum.

## Application Value

角动量是描述刚体旋转状态的物理量，姿态控制设计师利用角动量守恒原理设计姿态机动策略。
