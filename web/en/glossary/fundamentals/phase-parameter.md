# Phase Parameter

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A parameter describing the position of a point on a DRO within its orbital period, corresponding to the orbit state at time t. Together with the amplitude parameter, it uniquely determines the state of any point on the DRO in the rotating frame.

Based on its definition, a parameter describing the position of a point on a dro within its orbital period, corresponding to the orbit state at time t. together with the amplitude parameter, it uniquely determines the state o.
