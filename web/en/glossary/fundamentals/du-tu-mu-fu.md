# CRTBP Nondimensional Units

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of nondimensional units defined in the circular restricted three-body problem (CRTBP) to eliminate numerical scale disparities. The distance unit (DU) equals the primary separation R, the time unit (TU) equals the inverse angular velocity ω⁻¹, the mass unit (MU) equals the initial spacecraft mass m₀, and the force unit (FU) = MU·DU/TU². Under this normalization the CRTBP equations depend only on the mass ratio μ, unifying the numerical scale and improving optimization convergence.

## Application Value

The CRTBP无量纲单位 concept provides technical support and analytical methods for cislunar space research and lunar exploration missions.
