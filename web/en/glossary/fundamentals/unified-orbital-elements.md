# Unified Orbital Elements
> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of orbital elements (p, ξ, η, h, k, u) applicable to any conic section (e ≥ 0). Uses semi-latus rectum p instead of semi-major axis a to avoid the parabolic singularity, and true anomaly f instead of mean anomaly M to be defined for hyperbolic orbits. The definitions of ξ, η, h, k are the same as the second type singularity-free elements. Singularity occurs only at i = 180°. In cislunar orbit prediction, this set offers computational efficiency advantages over Cartesian coordinates when eccentricity is moderate and the singularity is not approached.

## Application Value

The Unified Orbital Elements plays a significant role in cislunar space mission design, analysis, and control. In orbital design, it can be leveraged for transfer trajectory optimization; in navigation and control, it improves mission execution precision and reliability; in system analysis, it facilitates deeper understanding of complex multi-body dynamical behavior, guiding mission planning and risk assessment.
