# Barycentric Celestial Reference System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A space-time reference system with its origin at the solar system barycenter, used to describe spacecraft position and velocity in cislunar inter-satellite link data processing.

## Application Value

This reference frame has fundamental applications in cislunar orbital calculations and observation data processing.
