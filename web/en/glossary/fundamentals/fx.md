# Hypergeometric Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Special functions defined by series, generalizing many classical functions; used in astrodynamics for Gaussian solutions to Lambert's problem and continued fraction expansions.

## Application Value

Hypergeometric Function is a fundamental parameter in spacecraft design with significant importance for orbital calculations and mission planning. Accurate understanding and application of this parameter improves the precision and reliability of mission design.
