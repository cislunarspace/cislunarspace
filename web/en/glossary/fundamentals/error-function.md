# Error Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A special mathematical function erf(x) = (1/sqrt(pi)) * integral(e^(-t^2)) dt. The paper finds that using erf as the smoothing function halves computation time and reduces terminal rendezvous error by an order of magnitude compared to tanh and L2 alternatives.

## Application Value

This concept is fundamental to understanding cislunar space dynamics and plays an important role in orbital mechanics modeling and mission analysis.
