# Pareto Solution

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of non-dominated solutions in multi-objective optimization where improving one objective necessarily degrades another. The Pareto solution set in low-thrust trajectory design provides trade-off options between time of flight and propellant mass.

## Application Value

在帕累托解的设计与分析中，可用于优化转移方案，减少燃料消耗 结合数值优化算法，可实现高性能的轨迹规划 在任务规划阶段用于评估不同推进方案的优劣。
