# Fundamental Katalog 5

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The classic star catalog published in 1979, forming the basis of the IAU-76/FK5 J2000 reference system. Has been replaced by ICRF.

## Application Value

FK5星表是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，FK5星表的准确计算和分析对于任务成功至关重要 掌握FK5星表的概念有助于工程师进行轨道设计和任务规划 FK5星表为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
