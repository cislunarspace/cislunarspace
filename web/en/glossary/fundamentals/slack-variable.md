# Slack Variable

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An auxiliary variable introduced in nonlinear programming to convert inequality constraints into equality constraints. In multiple shooting, a slack variable transforms the positivity constraint T>0 on flight time into T-β²=0.

## Application Value

Slack variables transform inequality constraints into equality constraints in nonlinear programming, enabling efficient solution of trajectory optimization problems.
