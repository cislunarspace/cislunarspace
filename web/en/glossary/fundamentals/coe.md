# Classical Orbit Elements

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of six parameters describing orbital state, including semi-major axis, eccentricity, inclination, right ascension of ascending node, argument of periapse, and true anomaly.

## Application Value

This term has significant practical applications in cislunar mission planning and execution.
