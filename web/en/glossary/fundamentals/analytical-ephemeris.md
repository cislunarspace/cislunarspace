# Analytical Ephemeris

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Approximate method for computing celestial body positions using analytical formulas (typically trigonometric series or polynomial expansions of Keplerian elements). It is fast and requires minimal data storage, but has limited precision. For collinear libration point orbit prediction in the Earth-Moon system, the low accuracy of analytical ephemerides can cause qualitative errors in prediction results.

## Application Value

分析历表是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，分析历表的准确计算和分析对于任务成功至关重要 掌握分析历表的概念有助于工程师进行轨道设计和任务规划 分析历表为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
