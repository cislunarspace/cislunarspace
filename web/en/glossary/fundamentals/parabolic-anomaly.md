# Parabolic Anomaly

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An auxiliary angle for describing position in a parabolic orbit, defined as B = tan(ν/2), where ν is the true anomaly. Parabolic orbits have zero mechanical energy, with mean motion np = 2√(μ/p³).

## Application Value

在航天器动力学建模中，需要准确描述引力场、摄动力和坐标系变换。该概念是进行轨道力学分析、姿态控制和任务设计的基础。
