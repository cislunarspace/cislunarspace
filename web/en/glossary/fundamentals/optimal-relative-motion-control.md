# Optimal Relative Motion Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The problem of controlling a deputy satellite's relative state transfer with respect to a chief satellite under three-body dynamics. Given initial relative state delta_x_0 and final relative state delta_x_f near a reference orbit, the optimal initial costates delta_lambda_0 are solved via variational equations. The method enables approximate solution of any relative optimal control problem with arbitrary boundary conditions in O(m*n^3) operations.

## Application Value

This concept is used in orbital analysis and has significant impact on mission design.
