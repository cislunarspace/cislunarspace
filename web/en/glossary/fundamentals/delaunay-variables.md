# Delaunay Variables

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of conjugate variables for integrable systems, composed of action-angle variables. Separable in elliptic orbit restricted three-body problems but not applicable in Earth-Moon systems.
