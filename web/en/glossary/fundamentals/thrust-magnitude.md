# Thrust Magnitude

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The magnitude of the thrust vector, measured in newtons. Electric propulsion engines typically produce millinewton-level thrust (0.15-0.3 N in this study), far less than chemical rockets. Thrust magnitude and specific impulse jointly define the performance envelope of a propulsion system.

## Application Value

Thrust Magnitude provides theoretical support for fundamental research in cislunar space.
