# Sliding Surface

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A pre-designed hypersurface in state space used in sliding mode control. The control law drives system states onto this surface, after which the system slides along it. The resulting dynamics depend only on the surface geometry, providing robustness to model uncertainties and external disturbances.


## Application Value

滑模控制对模型不确定性和外部干扰具有天然的鲁棒性，在地月空间轨道保持中能够有效应对动力学模型偏差和外部摄动。
