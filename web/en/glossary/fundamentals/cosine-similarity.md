# Cosine Similarity

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A similarity metric that measures the cosine of the angle between two vectors, ranging from [-1, 1]. In DeepSORT, it compares appearance feature vectors of targets; values closer to 1 indicate more similar appearances, helping determine whether detections in different frames belong to the same target.

## Application Value

在航天器动力学建模中，需要准确描述引力场、摄动力和坐标系变换。该概念是进行轨道力学分析、姿态控制和任务设计的基础。
