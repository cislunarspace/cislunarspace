# Augmented State Vector

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A composite vector z = [x^T, lambda^T, J]^T that combines states, costates, and the performance metric into a single augmented dynamical system. Variational equations applied to this system yield STM and STT that simultaneously describe sensitivities of states, costates, and energy cost. Physical parameters such as eccentricity can be included as state variables with zero time derivatives.
