# Lagrange Interpolation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A polynomial interpolation method. It constructs a degree-n polynomial from function values at n+1 nodes that passes through all nodes exactly. In the Gauss pseudospectral method, Lagrange interpolation polynomials approximate state variables using the initial state and states at LG collocation points, with derivatives obtained by differentiating the polynomial to convert differential equations into algebraic constraints.
