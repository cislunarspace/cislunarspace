# Time-Invariant Transformation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A mathematical transformation that converts a linear time-periodic system into a linear time-invariant system. The method augments all discrete state and control variables within one period into a single vector, using the state transition matrix of the uncontrolled dynamics to construct the transformation matrix. The resulting time-invariant state matrix is the cumulative transition matrix over one period, and the input matrix consists of impulse responses at each instant within the period. After this transformation, the paper applies classical pole placement theorems to design feedback gains.

## Application Value

The Time-Invariant Transformation converts a linear time-periodic system into a linear time-invariant system. After this transformation, classical pole placement theorems can be applied to design feedback gains, simplifying control system design for libration point orbits.
