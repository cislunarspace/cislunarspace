# Coordinate Transformation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The process of converting coordinates of the same event between different space-time reference frames. The transformation between GCRS and BCRS includes scale factor corrections, external gravitational potential effects, and Lorentz contraction terms, truncated to c^{-2} order for cislunar high-precision applications.

## Application Value

Coordinate transformation between reference frames includes scale factor corrections and Lorentz contraction terms truncated to c^{-2} order for cislunar high-precision applications.
