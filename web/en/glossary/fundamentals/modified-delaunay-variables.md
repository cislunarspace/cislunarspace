# Modified Delaunay Variables

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of canonical variables redefined from standard Delaunay variables to avoid singularities when eccentricity approaches zero. Defined as Λ = L, P = L - G, Q = G - H, with corresponding angle variables λ, p, q. Modified Delaunay variables are particularly useful for analyzing mean motion resonances of low-eccentricity orbits and serve as the foundation for deriving MMR normal Hamiltonians.

## Application Value

This concept plays a key role in trajectory transfer design, helping evaluate transfer costs and flight time to provide quantitative basis for mission trade studies. Combined with global search algorithms, multiple solution families and Pareto frontiers can be identified to guide orbital design decisions.
