# Remote Guidance Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Orbital control performed by the ascent module after lunar takeoff and before rendezvous and docking. By adjusting takeoff time and azimuth, the injection orbit plane achieves virtual coplanarity with the orbiter-return combination, reducing fuel consumption for orbital plane correction during remote guidance.

## Application Value

该基础概念是理解地月空间系统行为的出发点。
