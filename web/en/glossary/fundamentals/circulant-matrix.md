# Circulant Matrix

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A square matrix where each column is obtained by cyclically shifting the previous column by one position. In constellation optimization, the cyclic shifts of the accessibility profile are arranged into a matrix so that coverage timeline computation becomes a matrix-vector multiplication, facilitating ILP constraint construction.

## Application Value

结合数值优化算法，可实现高性能的轨迹规划 用于描述误差传播和灵敏度分析。
