# Rotating Spherical Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A coordinate frame in the rotating reference system based on the Earth-moon line, describing spacecraft position with radial distance r, longitude angle theta, and latitude angle phi. Well-suited for multi-revolution spiral trajectories but suffers from a numerical singularity as latitude approaches 90 degrees.

## Application Value

The three components of this coordinate system (radial distance, longitude angle, latitude angle) intuitively describe multi-revolution spiral trajectory characteristics, making it suitable for analyzing low-thrust orbit design. However, numerical singularities occur when the latitude approaches 90 degrees.
