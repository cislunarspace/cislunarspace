# Gravity Field Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A mathematical model describing a celestial body's non-spherical gravity field using spherical harmonic expansion. The paper uses the WGS84 8×8 model for both parking orbit and cislunar transfer phases.

## Application Value

在引力场模型的设计与分析中，可用于优化转移方案，减少燃料消耗 用于分析航天器在复杂引力场中的运动特性。
