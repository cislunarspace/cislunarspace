# Sidereal Time

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A time system with stars as reference, equal to Earth's rotation period.

## Application Value

恒星时是地月空间研究的基础概念，为理解更复杂的航天器动力学问题提供了理论支撑 在实际工程应用中，恒星时的准确计算和分析对于任务成功至关重要 掌握恒星时的概念有助于工程师进行轨道设计和任务规划 恒星时为航天器轨道力学研究提供了基本框架，是进一步学习高级概念的基础
