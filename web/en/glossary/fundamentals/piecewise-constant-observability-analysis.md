# Piecewise Constant Observability Analysis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that approximates a nonlinear time-varying system as a linear time-invariant system within short time intervals, then evaluates observability degree by computing the condition number of the observability matrix segment by segment. It is applicable to high-dimensional cislunar navigation systems.

## Application Value

在编目系统中，该技术可提高对空间目标的探测、跟踪和编目能力。
