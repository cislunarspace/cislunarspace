# Hill Region Configuration

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In the CRTBP, the values of the Jacobi constant at the five libration points divide the Hill regions into five configurations, each admitting different transport possibilities. Lower C values permit larger accessible regions in configuration space, governing whether a spacecraft can transit between the Earth and Moon realms.
