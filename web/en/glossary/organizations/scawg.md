# Space Communication Architecture Working Group

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A dedicated NASA working group established for the return-to-the-Moon programme, aiming to improve lunar surface coverage and navigation accuracy. It designed various communication and navigation constellation schemes for different mission requirements.

## Application Value

The 空间通信架构工作组 concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
