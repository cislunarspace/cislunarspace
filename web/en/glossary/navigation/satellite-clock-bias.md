# Satellite Clock Bias

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The deviation between the atomic clock onboard a navigation satellite and the standard time. Satellite clock bias is one of the main error sources in GNSS positioning, and high-precision orbit determination requires accurate estimation and correction of clock bias information.

## Application Value

在航天器导航和定位中，该方法用于从传感器数据中提取有效信息，实现自主定轨和轨道预报. 支持地月空间探测任务的实时导航需求.
