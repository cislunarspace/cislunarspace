# Cycle Slip Detection

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Techniques for detecting interruptions in integer cycle counting of carrier phase observations. Common cycle slip detection methods include TECR method, MW method, and double-difference observation detection methods. Cycle slips seriously affect orbit determination accuracy and must be accurately detected and repaired.
