# State Noise Compensation Matrix

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

State Noise Compensation Matrix; a noise matrix in the Extended Kalman Filter used to compensate for unmodeled dynamic errors, diagonal matrix whose elements depend on the magnitude of unmodeled errors, used to prevent the state covariance matrix from collapsing too rapidly.
