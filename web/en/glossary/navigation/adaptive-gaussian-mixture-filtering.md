# Adaptive Gaussian Mixture Filtering

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A cislunar maneuvering target tracking method proposed by Iannamorelli et al. Combining jump Markov system modeling with cluster merging algorithms, it adaptively estimates target states and maneuver parameters under multi-sensor observation, achieving false detection rates below 5% on Artemis-I-type trajectories.

## Application Value

为航天器的精确控制提供理论依据，确保任务执行的可靠性 为目标跟踪和状态估计提供关键技术支撑 为状态估计提供概率框架，提高跟踪精度。
