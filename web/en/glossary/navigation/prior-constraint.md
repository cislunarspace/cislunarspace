# Prior constraint

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Using previous orbit determination results as pseudo-measurements and applying weighted constraints in relative orbit determination to prevent divergence. Constraint tightness depends on the accuracy of the prior orbit; tight constraints for high accuracy, loose constraints for low accuracy.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
