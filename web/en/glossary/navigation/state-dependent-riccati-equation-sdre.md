# State-Dependent Riccati Equation, SDRE

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A nonlinear control design method that parameterizes the nonlinear system in real-time as a state-dependent linear form, then solves the algebraic Riccati equation for feedback gains. Used here for closed-loop guidance during final approach.

## Application Value

This concept is relevant to analysis and design in cislunar space applications.
