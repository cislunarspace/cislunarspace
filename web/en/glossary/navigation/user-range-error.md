# User Range Error

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The equivalent ranging error incorporating satellite clock bias, atmospheric delay, multipath effects, and other error sources. Navigation positioning error equals the geometric dilution of precision (GDOP) multiplied by the URE.

## Application Value

In navigation system design, this technology can be used to achieve autonomous spacecraft navigation and positioning, reducing dependence on ground tracking and control. By optimizing observation geometry and algorithm accuracy, navigation positioning accuracy and reliability can be improved.
