# Perturbed-Laplace Method, PL Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An initial orbit determination method derived similarly to conventional Laplace's method but incorporating lunar gravitational perturbations; transforms the IOD problem into solving a 28th-order polynomial equation in range, yielding up to four solutions.

## Application Value

The 扰动拉普拉斯方法 concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
