# Number of Visible Satellites

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The number of navigation satellites observable by a receiver at a given time. In cislunar space, the visible satellite count is significantly lower than in ground or low-Earth-orbit environments, sometimes dropping below 4, which is the primary constraint on GNSS service availability.


## Application Value

可见星数统计是评估导航星座覆盖性能的重要指标，影响地月空间导航系统的可用性和精度。
