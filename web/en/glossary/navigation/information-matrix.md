# Information Matrix

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In linked autonomous orbit determination, the matrix Lambda = H^T W H formed by the observation matrix H and weight matrix W. Its positive definiteness determines whether the orbit determination system is fully observable, and its condition number serves as a quantitative measure of observability.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
