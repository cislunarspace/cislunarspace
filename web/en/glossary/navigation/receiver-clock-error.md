# Receiver Clock Error

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The bias between the receiver's internal clock and the navigation system time reference. In GNSS positioning, it is estimated as an additional unknown parameter, which degrades DOP. It can be pre-eliminated through clock error decoupling.

## Application Value

This concept is essential for understanding motion characteristics in mission planning and analysis, and plays a vital role in mission success.
