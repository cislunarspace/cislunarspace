# Differential Correction

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A numerical method for transitioning transfer orbits from a lower-fidelity model (e.g., CR3BP) to a high-fidelity ephemeris model. The process discretizes the transfer into nodes and iteratively corrects for position and velocity continuity, using the lower-fidelity solution as the initial guess.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
