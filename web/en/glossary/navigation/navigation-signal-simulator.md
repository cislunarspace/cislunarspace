# Navigation Signal Simulator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Equipment that generates navigation signals based on configured satellite orbits, clock errors, and error models, used to reproduce satellite navigation signals for specific scenarios in a laboratory environment, supporting semi-physical simulation tests of navigation receivers.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
