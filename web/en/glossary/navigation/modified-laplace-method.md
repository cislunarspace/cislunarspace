# Modified Laplace Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An IOD technique that expresses the target position vector using f and g series combined with the modified Laplace method, capable of resolving the coplanar problem with at least four observations.

## Application Value

改进拉普拉斯方法用于初轨确定，通过观测数据估计航天器初始轨道根数，是轨道确定的基础算法。
