# Network Orbit Determination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A processing method that jointly estimates the orbital states and clock states of all satellites in the entire constellation using inter-satellite ranging data among all satellites within the constellation.
