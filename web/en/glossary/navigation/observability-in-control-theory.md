# Observability (in control theory)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A fundamental property of a control system indicating whether the system state can be uniquely determined from available observations. In linked autonomous orbit determination, full observability requires the observation matrix to be full rank and the information matrix to be positive definite. Distinct from observability degree, which quantifies how well the state can be determined.

## Application Value

In spacecraft attitude and orbit control, this property enables high-precision tracking and stable maintenance. By designing appropriate control laws, external disturbances can be effectively suppressed, ensuring reliable spacecraft operation in complex dynamical environments.
