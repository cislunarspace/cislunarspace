# Position Dilution of Precision

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A dimensionless metric quantifying how reference-point geometry amplifies ranging errors into position errors. Lower PDOP indicates more favorable geometry. For four CubeSats evenly distributed along a halo orbit (90-degree phase separation), the minimum PDOP is approximately 8.8.

## Application Value

Position Dilution of Precision has important applications in cislunar space navigation and orbit determination systems.
