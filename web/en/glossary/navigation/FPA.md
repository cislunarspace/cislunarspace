# Entry Flight Path Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Angle between velocity vector and local horizontal; critical navigation parameter for crewed spacecraft return.

## Application Value

The angle between the velocity vector and local horizontal plane at atmospheric entry, a key parameter affecting landing accuracy and heat flux density.
