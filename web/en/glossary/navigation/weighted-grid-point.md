# Weighted Grid Point

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Grid points assigned different weights according to service priority. In multi-objective optimization, by increasing weights for critical regions (e.g., setting the Earth-Moon transfer critical region weight to 10 while other regions default to 1), the optimization results are ensured to prioritize the service quality needs of high-priority regions.

## Application Value

Weighted Grid Point has important applications in cislunar space navigation and orbit determination systems.
