# GNSS broadcast ephemeris

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Ephemeris data broadcast in real-time by GNSS satellites via navigation signals. Combined with code pseudo-range measurements, enables real-time LEO orbit determination with position accuracy of approximately 10 m. Less accurate than precise ephemeris but available in real-time.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
