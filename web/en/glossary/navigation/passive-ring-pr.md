# Passive Ring, PR

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A docking mechanism ring mounted on the target spacecraft (e.g., Gateway) that does not actively control attitude. The chaser vehicle's Active Ring must align with the Passive Ring to complete docking. It is a standardized docking interface component defined by IDSS.


## Application Value

This control method can be applied to spacecraft attitude stabilization, orbit keeping, and maneuver trajectory optimization in cislunar space missions, improving mission execution flexibility and reliability.
