# Keep Out Sphere, KOS

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The innermost safety sphere centered on the target with radius typically 200 m, which the chaser must never enter to avoid collision.

## Application Value

The three-dimensional version of keep-out zones, a common representation for formation flying safety constraints.
