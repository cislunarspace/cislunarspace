# Microwave Ranging and Velocity Radar

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An active sensor that measures the range and radial velocity from a vehicle to the lunar surface by transmitting and receiving microwave signals. It provides range and velocity measurements to the navigation system during powered descent as a key data source for integrated navigation.

## Application Value

在态势感知系统中，该观测方法为低轨空间目标监视提供技术手段，是空间交通管理的数据来源。
