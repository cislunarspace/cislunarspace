# Equal Phase Difference Deployment

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A constellation design method in which satellites on the same benchmark orbit are uniformly distributed at equal phase angle intervals (360°/N), maintaining a regular geometric configuration and balanced coverage performance.
