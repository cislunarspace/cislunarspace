# Highly Observable Link

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In a multi-spacecraft ISL combination, a link that provides abundant observable information, characterized by a small DAGDOP value and rapidly changing geometric configuration between the linked spacecraft, effectively improving convergence speed and steady-state accuracy of orbit determination.

## Application Value

强可观测链路的扰动比值大，LiAISON导航的可观测性好，设计师在编队构型设计中优先选择能产生强可观测链路的构型。
