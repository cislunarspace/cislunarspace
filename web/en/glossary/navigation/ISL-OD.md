# ISL-based Orbit Determination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An autonomous navigation method that performs orbit determination solely based on inter-satellite link (ISL) observation data. Under the dual-one-way ranging (DOWR) mode, satellite state and clock error calculations can be decoupled through combined observations, enabling fully autonomous orbit determination without relying on ground stations.

## Application Value

Using inter-satellite link ranging data to aid orbit determination, reducing dependence on ground stations, an emerging technology for distributed spacecraft navigation.
