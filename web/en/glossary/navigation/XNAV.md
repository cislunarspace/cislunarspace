# X-ray Pulsar Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Navigation method using stable X-ray pulse signals from pulsars for spacecraft position and velocity determination.

## Application Value

Autonomous navigation technology using pulsar X-ray signals, independent of ground stations, suitable for deep space and cislunar autonomous missions.
