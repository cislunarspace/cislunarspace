# Station Horizon Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A coordinate system centered at the station with the local horizontal plane as reference.

## Application Value

The station horizon coordinate system provides the fundamental reference frame for ground stations to track and communicate with spacecraft. Since this coordinate system is based on the local horizon, elevation and azimuth angles obtained by the station can directly drive antenna pointing mechanisms to achieve precise spacecraft pointing. In deep space missions, angle measurements using the station horizon coordinate system are essential inputs for orbit determination; combined with range measurements, they enable precise positioning of spacecraft. This coordinate system also describes station visibility, determining whether a spacecraft is above the horizon and within communicable elevation range at any given time.
