# Batch Processing Estimation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An orbit determination method that uses all observation data within an arc to simultaneously estimate all desired parameters (such as initial orbit states and range biases). Compared with sequential estimation, batch processing better utilizes the overall geometric properties of the observation data.

## Application Value

在航天器导航和定位中，该方法用于从传感器数据中提取有效信息，实现自主定轨和轨道预报. 支持地月空间探测任务的实时导航需求.
