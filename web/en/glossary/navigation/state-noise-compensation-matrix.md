# State Noise Compensation Matrix (Qc)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A noise matrix in the Extended Kalman Filter used to compensate for unmodeled dynamic errors, diagonal matrix whose elements depend on the magnitude of unmodeled errors, used to prevent the state covariance matrix from collapsing too rapidly.

## Application Value

This term has important application value in the design, analysis, and control of cislunar space missions, providing theoretical support for research and engineering practice in related technical fields.
