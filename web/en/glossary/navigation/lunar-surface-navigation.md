# Lunar Surface Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Using near-lunar satellites to provide real-time, high-precision navigation and positioning for lunar surface operations including roving, landing, and ascent. It is an essential infrastructure for sustained, high-tempo human exploration, requiring high quadruple coverage rate and navigation accuracy from the constellation.

## Application Value

Navigation system design and implementation must account for observation geometry, error propagation, and signal transmission delay. This concept supports positioning accuracy evaluation, navigation filter design, and constellation optimization.
