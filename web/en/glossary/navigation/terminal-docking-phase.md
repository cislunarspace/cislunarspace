# Terminal Docking Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The final phase where the chaser spacecraft executes 6-DOF relative motion control using GPM-PPC to perform high-precision docking maneuvers within a 10 km proximity to the target space station.


## Application Value

This control method can be applied to spacecraft attitude stabilization, orbit keeping, and maneuver trajectory optimization in cislunar space missions, improving mission execution flexibility and reliability.
