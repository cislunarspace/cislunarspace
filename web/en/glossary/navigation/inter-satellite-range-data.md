# Inter-Satellite Range Data

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Distance measurements between navigation satellites obtained via radio signals. In a cislunar navigation constellation, inter-satellite range data serves as the sole observation, and its accuracy directly determines the quality of orbit determination and navigation services.
