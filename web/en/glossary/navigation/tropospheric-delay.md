# Tropospheric Delay

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The additional delay caused by changes in atmospheric refractive index as a radio signal passes through the troposphere. Tropospheric delay is frequency-independent (non-dispersive) and depends mainly on atmospheric temperature, humidity, and pressure. It is an error source that must be corrected in satellite-to-ground ranging.

## Application Value

对流层延迟是电磁波穿过大气层时产生的传播延迟，导航系统设计师建立对流层延迟模型修正测距观测量，提高定轨精度。
