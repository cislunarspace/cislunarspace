# Barycentric Rotating Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A reference frame centered at the Sun-Earth barycenter that co-rotates with the Sun-Earth line. The x-axis always points from Sun to Earth, z-axis along the ecliptic normal, y-axis by right-hand rule. In this frame, the Halo orbit spacecraft position is on the order of 10^6 km, two orders of magnitude smaller than in the inertial frame, yielding significantly better navigation filter accuracy. The paper recommends using the barycentric rotating frame for libration point orbit navigation, consistent with the frame choice used for orbit design.

## Application Value

This concept is applied in analysis and design, with important implications for mission performance.
