# Pinpoint Landing

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Landing accuracy within 100 meters; key enabling technology for future extreme terrain exploration, significantly reducing ground traverse distance requirements.

## Application Value

高精度着陆技术可减少月面机动距离需求，支持极端地形探测。
