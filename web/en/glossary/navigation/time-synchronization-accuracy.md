# Time Synchronization Accuracy

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Time Synchronization Accuracy; the precision of time alignment between satellites achieved through ranging signals; this paper shows that a DRO-based LiAISON system can achieve time synchronization accuracy better than 100 nanoseconds.

## Application Value

在导航系统设计中，This技术可used forachieves航天器自主导航定位，减少对地面测控的依赖。through优化观测几何和算法精度，可提高导航定位的准确性和可靠性。
