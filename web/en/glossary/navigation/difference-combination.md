# Difference Combination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A data processing mode for dual one-way ranging. By differencing the one-way range measurements from two satellites at the same coordinate-time epoch, and after removing geometric and ionospheric delays using predicted orbit information, the physical clock bias between the two satellites can be extracted. Difference combination is the fundamental method for inter-satellite clock bias estimation.

## Application Value

在轨道设计和转移轨道优化中，该方法用于确定最优转移时机和轨道形状，以最小化燃料消耗或飞行时间. 通过数值仿真和迭代优化，可获得满足任务约束的可行轨道方案.
