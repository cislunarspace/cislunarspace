# Main Lobe Signal

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The signal transmitted in the main beam direction of a GNSS satellite antenna, carrying the highest power, primarily used for navigation by ground and near-Earth users. In cislunar space, main lobe signal proportion drops rapidly as the spacecraft rises above the GNSS constellation, becoming negligible above 6000 km altitude.

## Application Value

主瓣信号技术为地月空间航天器提供精确的定位能力，是实现自主导航的关键技术之一 在实际任务中，利用主瓣信号可以有效提高定轨精度，降低对地面测控系统的依赖 主瓣信号的研究对于构建地月空间导航基础设施具有重要意义 通过主瓣信号，航天器能够在复杂的空间环境中实现精确自主定位，支撑月球及更远深空的探测任务
