# Time of Arrival

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Time when pulsar X-ray pulse arrives at spacecraft; core measurement for pulsar navigation.

## Application Value

Signal arrival time, a fundamental measurement for multi-station positioning and timing navigation, also an important parameter for deep space tracking.
