# Light-Time Iteration

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A numerical method for computing the geometric signal propagation distance. Because a propagation delay exists between signal transmission and reception epochs, iteration is required: initially assume the transmission epoch equals the reception epoch, compute the signal travel distance, then update the transmission epoch using that distance, and repeat until convergence. The iteration also accounts for gravitational light deflection.
