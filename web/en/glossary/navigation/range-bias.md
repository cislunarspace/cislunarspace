# Range Bias

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The systematic distance measurement error in inter-satellite ranging systems. In this paper's simulations, a system bias of 10m is assumed, and the range bias is simultaneously estimated during orbit determination, achieving self-calibration of the bias.

## Application Value

在态势感知系统中，该观测方法为低轨空间目标监视提供技术手段，是空间交通管理的数据来源。
