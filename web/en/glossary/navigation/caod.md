# Combined Autonomous Orbit Determination, CAOD

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Autonomous orbit determination between a lunar satellite and a probe on a special orbit (CLP orbit or DRO), using inter-satellite range data to provide an absolute reference orientation for the lunar satellite.

## Application Value

The 组合自主定轨 concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
