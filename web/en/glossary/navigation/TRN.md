# Terrain Relative Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Autonomous navigation method by matching optical images with known terrain features.

## Application Value

Navigation technology using terrain feature matching for relative positioning, providing precise position information in GPS-denied environments for landing.
