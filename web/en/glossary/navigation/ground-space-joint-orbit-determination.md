# Ground-Space Joint Orbit Determination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method of precise navigation satellite orbit determination by jointly using ground tracking station observation data and inter-satellite link measurement data. It can improve orbit determination accuracy and reliability, and is one of the key technologies for achieving high-precision orbit determination in the BeiDou Phase II system.

## Application Value

星地联合定轨技术为地月空间航天器提供精确的定位能力，是实现自主导航的关键技术之一 在实际任务中，利用星地联合定轨可以有效提高定轨精度，降低对地面测控系统的依赖 星地联合定轨的研究对于构建地月空间导航基础设施具有重要意义 通过星地联合定轨，航天器能够在复杂的空间环境中实现精确自主定位，支撑月球及更远深空的探测任务
