# Track-to-Track Fusion

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A distributed estimation architecture that fuses track estimates generated independently by multiple sensors

## Application Value

Track-to-Track Fusion is a core technology in spacecraft navigation systems, important for improving positioning accuracy and mission safety. It is widely used in autonomous navigation and rendezvous and docking missions.
