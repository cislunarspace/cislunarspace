# Communication

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An integrated service capability combining communication, navigation, and timing functions. In cislunar space, CNT multi-function integration is a key development trend for navigation constellations, providing data communication, positioning/navigation, and high-precision time synchronization simultaneously through the same constellation or inter-satellite links, reducing redundant system construction and improving overall system efficiency.

## Application Value

在组合导航系统中，该方法能够提高定轨精度和收敛速度，增强导航系统的鲁棒性，适用于地月空间的自主导航任务。
