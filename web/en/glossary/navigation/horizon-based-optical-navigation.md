# Horizon-Based Optical Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A type of optical navigation that identifies celestial body horizons in images, extracts horizon vectors, and uses Cholesky factorization with least squares to solve for the body center direction, yielding the spacecraft's 3D position relative to the body. The Christian-Robinson algorithm is a representative non-iterative implementation.
