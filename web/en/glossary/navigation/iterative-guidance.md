# Iterative Guidance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Guidance method that iteratively solves optimal control problems during flight, approaching optimal solutions by continuously updating co-state variable estimates.

## Application Value

该制导方法在交会对接和着陆过程中用于实时轨迹优化。
