# Earth-Moon Barycenter Rotating Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A reference frame centered at the Earth-Moon barycenter, co-rotating with the Earth-Moon line. The x-axis points from Earth to Moon, the z-axis aligns with the system's angular velocity, and the y-axis completes the right-handed system. In this frame, Earth, Moon, and Lagrange points are stationary, making it the standard framework for Earth-Moon orbital dynamics.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
