# Prior Orbit Constraint

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Constraints imposed on orbit determination estimation using known information about satellite orbital parameters. Adding prior information as a weight matrix to the normal equation can mitigate rank deficiency, but accumulated systematic errors limit the timeliness of navigation accuracy.


## Application Value

This orbital design method can be applied to transfer trajectory design, orbit keeping, and mission planning in cislunar space missions, improving spacecraft performance and mission flexibility.
