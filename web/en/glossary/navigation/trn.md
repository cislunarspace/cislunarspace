# Terrain Relative Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Autonomous navigation method by matching optical images with known terrain features.

## Application Value

Terrain Relative Navigation has significant application value in cislunar space missions, primarily used for autonomous positioning and orbit control of spacecraft.
