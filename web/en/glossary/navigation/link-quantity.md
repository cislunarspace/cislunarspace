# Link Quantity

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The total number of inter-satellite links between the core spacecraft and auxiliary spacecraft in an ISL-based autonomous navigation system. Increasing link quantity accelerates orbit determination convergence but exhibits diminishing marginal returns; adding a weakly observable link to a highly observable system may degrade final accuracy.

## Application Value

链路数量技术为地月空间航天器提供精确的定位能力，是实现自主导航的关键技术之一 在实际任务中，利用链路数量可以有效提高定轨精度，降低对地面测控系统的依赖 链路数量的研究对于构建地月空间导航基础设施具有重要意义 通过链路数量，航天器能够在复杂的空间环境中实现精确自主定位，支撑月球及更远深空的探测任务
