# X-ray Pulsar Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Navigation method using stable X-ray pulse signals from pulsars for spacecraft position and velocity determination.

## Application Value

X-ray Pulsar Navigation has significant application value in cislunar space missions, primarily used for autonomous positioning and orbit control of spacecraft.
