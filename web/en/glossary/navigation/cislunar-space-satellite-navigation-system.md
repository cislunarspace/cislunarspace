# Cislunar Space Satellite Navigation System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Navigation infrastructure deployed in cislunar space to provide spatiotemporal references for lunar exploration. A typical configuration places navigation satellites near Lagrange points (L1, L3, L4, L5) and in DROs, using inter-satellite links for autonomous orbit determination independent of ground tracking.

## Application Value

地月空间卫星导航系统技术为地月空间航天器提供精确的定位能力，是实现自主导航的关键技术之一 在实际任务中，利用地月空间卫星导航系统可以有效提高定轨精度，降低对地面测控系统的依赖 地月空间卫星导航系统的研究对于构建地月空间导航基础设施具有重要意义 通过地月空间卫星导航系统，航天器能够在复杂的空间环境中实现精确自主定位，支撑月球及更远深空的探测任务
