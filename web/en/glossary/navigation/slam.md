# Simultaneous Localization and Mapping

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Technique where a robot simultaneously estimates its position and constructs an environmental map in an unknown environment

## Application Value

Simultaneous Localization and Mapping is a core technology in spacecraft navigation systems, important for improving positioning accuracy and mission safety. It is widely used in autonomous navigation and rendezvous and docking missions.
