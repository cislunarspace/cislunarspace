# Angles-Only Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Navigation method using only relative angle measurements to target for state estimation

## Application Value

This navigation method reduces spacecraft mass and complexity by using only relative angle measurements to the target, though it requires longer observation arcs for adequate state estimation accuracy.
