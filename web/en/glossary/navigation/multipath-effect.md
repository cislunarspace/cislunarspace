# Multipath Effect

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Signal propagation via multiple paths to the receiver; terrain reflections in the lunar environment can cause multipath effects, degrading inter-satellite link ranging accuracy.
