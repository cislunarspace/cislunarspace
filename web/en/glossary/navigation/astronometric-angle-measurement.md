# Astronometric Angle Measurement

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A measurement technique that uses the angular separation between a celestial object and background stars to determine spacecraft orientation. The paper extends this to measure the spacecraft-1-to-spacecraft-2-to-star angle, which simultaneously encodes state information from both spacecraft and reduces system complexity.

## Application Value

Inter-satellite measurement uses links between spacecraft for navigation, providing independent navigation capability.
