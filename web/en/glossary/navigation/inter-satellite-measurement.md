# Inter-satellite measurement

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Relative measurements between satellites, including three basic types: ranging, angle measurement, and velocity measurement. Common means include lidar, radio, and optical cameras. These measurements feature strong signals, high accuracy, and high autonomy, significantly reducing ground tracking burden.

## Application Value

Inter-satellite measurement uses links between spacecraft for navigation, providing independent navigation capability.
