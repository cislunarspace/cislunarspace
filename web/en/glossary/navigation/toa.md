# Time of Arrival

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Time when pulsar X-ray pulse arrives at spacecraft; core measurement for pulsar navigation.

## Application Value

Time of Arrival has significant application value in cislunar space missions, primarily used for autonomous positioning and orbit control of spacecraft.
