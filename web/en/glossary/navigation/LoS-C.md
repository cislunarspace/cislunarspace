# Line-of-Sight Corridor, LoS-C

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A geometric strategy to define hold point positions, where the chaser always approaches the target along the docking port direction within the field of view of rendezvous sensors modeled by a cone.

## Application Value

The line-of-sight corridor defines the observation channel from observation station to target, a reference for space awareness and communication link design.
