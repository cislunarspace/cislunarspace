# Clock Bias Estimation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The process of extracting inter-satellite relative clock bias from observation data. Typically uses the difference combination of dual one-way ranging, after removing geometric and ionospheric delays, to obtain the physical clock bias. The results can be used for inter-satellite time synchronization and navigation filtering.


## Application Value

双频量测可有效消除电离层折射延迟，是地基和天基导航系统实现高精度定位的关键技术。
