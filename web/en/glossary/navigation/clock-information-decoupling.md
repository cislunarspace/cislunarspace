# Clock Information Decoupling

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that obtains the receiver clock error via inter-satellite time synchronization links and treats it as a known value in the observation equations, thereby removing the clock error from the estimated parameters. This reduces the number of unknowns per epoch and significantly improves PDOP and positioning/orbit determination accuracy.

## Application Value

Clock Information Decoupling has important applications in cislunar space navigation and orbit determination systems.
