# Active Safety

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A safety strategy that detects potential collisions and executes collision avoidance manoeuvres via the chaser propulsion system. Less conservative than passive safety and better suited for close-range terminal phase, but requires functioning GNC and risks plume impingement.

## Application Value

Navigation system design and implementation must account for observation geometry, error propagation, and signal transmission delay. This concept supports positioning accuracy evaluation, navigation filter design, and constellation optimization.
