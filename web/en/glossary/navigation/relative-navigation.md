# Relative Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Technology for determining relative position and velocity between two spacecraft

## Application Value

Relative navigation enables rendezvous and docking by providing real-time relative position and velocity between spacecraft, critical for automated proximity operations.
