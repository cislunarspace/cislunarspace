# Cislunar GNSS Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technical approach that uses existing GNSS signals to provide positioning, navigation, and timing services for cislunar space users. Extending GNSS from near-Earth to cislunar space faces challenges including poor constellation geometry, long signal transmission distances, and weak received power, requiring augmentation constellations or high-sensitivity reception.

## Application Value

Navigation system design and implementation must account for observation geometry, error propagation, and signal transmission delay. This concept supports positioning accuracy evaluation, navigation filter design, and constellation optimization.
