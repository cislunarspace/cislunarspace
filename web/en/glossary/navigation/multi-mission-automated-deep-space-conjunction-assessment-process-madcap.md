# Multi-mission Automated Deep-space Conjunction Assessment Process (MADCAP)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An automated conjunction assessment process developed by NASA for deep space missions, prompted by a close approach event between NASA's Mars Odyssey and ESA's Mars Express in Mars orbit. It systematizes monitoring and evaluation of collision risks between deep space missions.

## Application Value

This concept has application value in cislunar space navigation and orbit determination, improving the precision and reliability of mission execution.
