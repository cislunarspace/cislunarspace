# Relative Orbit Determination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The process of estimating the relative orbital parameters of a target using a sequence of position estimates and orbital dynamics models (e.g., Hill's equations).

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
