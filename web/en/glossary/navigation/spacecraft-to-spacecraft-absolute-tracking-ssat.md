# Spacecraft-to-Spacecraft Absolute Tracking (SSAT)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A navigation method that estimates the absolute state of multiple spacecraft using relative measurements, where both observer and target are estimated simultaneously without relying on external orbit determination.

## Application Value

Inter-satellite link technology forms the foundation for achieving autonomous navigation and constellation coordination in cislunar space.
