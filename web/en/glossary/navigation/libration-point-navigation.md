# Libration Point Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A navigation method that achieves absolute positioning through inter-satellite links by utilizing gravitational asymmetry near the L1 and L2 libration points of the Earth-Moon system.

## Application Value

Libration point navigation achieves absolute positioning through inter-satellite links by exploiting L1/L2 gravitational asymmetry, and is an important mode of autonomous navigation in cislunar space.
