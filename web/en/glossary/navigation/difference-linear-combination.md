# Difference Linear Combination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In dual one-way ranging, the operation of halving the difference of code pseudo-ranges from two opposite links. This combination eliminates most geometric distance and preserves inter-satellite relative clock offset, drift, and frequency drift, used specifically for relative clock parameter estimation in time synchronization.

## Application Value

该方法可用于提高地月空间导航精度和任务安全性。
