# Vision-Based Relative Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Using only optical cameras to capture target images, estimating the chaser's relative position and attitude through feature point extraction and filtering.


## Application Value

该设备在地月空间任务中用于完成特定的观测、推进或通信功能，是任务成功的关键组成部分。
