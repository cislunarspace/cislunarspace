# Batch Processing Orbit Determination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An orbit determination method that ingests all accumulated observations over a time span at once and jointly solves for orbital parameters and other estimated quantities using weighted least squares or similar techniques. Unlike sequential (point-by-point) estimation, batch processing is suited for post-event precision orbit determination and exploits redundant observations to improve solution accuracy and reliability.


## Application Value

This orbital design method can be applied to transfer trajectory design, orbit keeping, and mission planning in cislunar space missions, improving spacecraft performance and mission flexibility.
