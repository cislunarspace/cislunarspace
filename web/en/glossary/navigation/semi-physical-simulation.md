# Semi-Physical Simulation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A test method in which real hardware is integrated into a simulation system in a laboratory environment, with navigation signal simulators generating theoretical signals that are received and processed by actual receivers. It combines the advantages of mathematical simulation and physical testing.
