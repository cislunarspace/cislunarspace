# Rank Deficiency Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In SST autonomous orbit determination, the state transition matrices of conventional two-body orbit constellations cause multi-collinearity among columns of the extended coefficient matrix H, rendering the normal matrix rank-deficient. This manifests as the absolute orientation parameters of the constellation being unobservable from the measurements alone.

## Application Value

在设计地月转移方案时，利用该轨道特性可降低任务总速度增量需求。在编目系统中，该技术可提高对空间目标的探测、跟踪和编目能力。精密定轨是实现地月空间导航的基础，决定了轨道预报精度。
