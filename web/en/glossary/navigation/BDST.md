# Beidou System Time, BDST

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The high-precision time reference of the Beidou satellite navigation system, used for external traceability and calibration of the CSNS constellation internal time.

## Application Value

The time reference of China's autonomous BeiDou satellite navigation system, the reference time for BeiDou navigation and positioning.
