# Receiver Antenna Gain

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The amplification capability of a receiver antenna in the direction of signal incidence, which is a function of the incidence angle. Cislunar GNSS receivers are typically modeled as zero-gain omnidirectional antennas; directional antennas can improve signal reception in practice.

## Application Value

接收天线增益技术为地月空间航天器提供精确的定位能力，是实现自主导航的关键技术之一 在实际任务中，利用接收天线增益可以有效提高定轨精度，降低对地面测控系统的依赖 接收天线增益的研究对于构建地月空间导航基础设施具有重要意义 通过接收天线增益，航天器能够在复杂的空间环境中实现精确自主定位，支撑月球及更远深空的探测任务
