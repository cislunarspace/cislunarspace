# Crosscovariance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Covariance matrix describing the correlation between two track estimates, a key quantity in track-to-track fusion

## Application Value

Crosscovariance is a key quantity in track-to-track fusion, describing the correlation between two track estimates for optimal combination of navigation solutions.
