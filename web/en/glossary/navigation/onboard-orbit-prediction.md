# Onboard Orbit Prediction

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Process in which a probe predicts its future orbital states using onboard computers, based on an initial state vector and a force model. Compared with ground-based prediction, onboard prediction is constrained by limited computation and storage resources, requiring force model simplification.

## Application Value

This concept is applied in analysis and design, with important implications for mission performance.
