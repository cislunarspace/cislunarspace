# Equivalent System Noise Temperature

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The thermal noise temperature equivalent of all noise sources in the receiving system, referred to the antenna input. It is a key parameter for calculating carrier-to-noise ratio, set to 290 K in the paper's simulations.

## Application Value

ESNT at 290 K is a key parameter for link budget calculation and carrier-to-noise ratio analysis in cislunar navigation and communication systems.
