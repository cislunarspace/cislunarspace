# Infrared Earth Sensor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A sensor that detects the Earth's direction using the infrared radiation characteristics of the Earth's atmosphere. By measuring the boundary of Earth's infrared radiation (the horizon), it determines the direction vector of the Earth's center relative to the spacecraft body frame. In the paper, the infrared Earth sensor precision is set to 0.01 degrees (1 sigma) for measuring the near-celestial-body direction in libration point celestial navigation.
