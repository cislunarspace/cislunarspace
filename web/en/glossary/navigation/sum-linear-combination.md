# Sum Linear Combination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In dual one-way ranging, the operation of averaging the code pseudo-ranges from two opposite links. This combination is dominated by geometric distance information and contains the total equipment delay plus small clock variation terms, used for position and equipment delay estimation in orbit determination.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
