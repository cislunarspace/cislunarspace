# BeiDou Augmentation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Using precise ranging links from BDS GEO/IGSO satellites to augment the cislunar hybrid constellation's observability and positioning accuracy. BDS augmentation enables 20-30 m 3D accuracy within just 2-day arcs.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
