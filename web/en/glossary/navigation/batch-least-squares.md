# Batch Least Squares

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that simultaneously uses all observation data within an observation arc to solve satellite orbit, clock difference, and other parameters through least squares adjustment. Batch processing can fully utilize observation data redundancy to obtain optimal solutions.
