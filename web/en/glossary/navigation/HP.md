# Hold Point, HP

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A pre-determined waypoint during rendezvous approach where the chaser stops relative to the target, checks system status, and decides whether to abort or continue. The hold point sequence is a core element of rendezvous safety design.

## Application Value

This technique is crucial for cislunar navigation and orbit determination, providing high-precision position and velocity information for spacecraft.
