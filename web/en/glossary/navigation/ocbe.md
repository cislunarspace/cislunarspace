# Optimal Control Based Estimator, OCBE

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A filter that links measurement updates with optimal control estimation to handle unmodeled dynamics and maneuver detection, capable of reconstructing unmodeled events within a single linear filter.

## Application Value

This control method is suitable for attitude and orbit control of cislunar spacecraft, enabling precise maneuvers and stationkeeping.
