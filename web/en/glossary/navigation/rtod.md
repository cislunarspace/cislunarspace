# Real-Time Orbit Determination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Real-time estimation of spacecraft position and velocity using inter-satellite link ranging data and an extended Kalman filter, without ground station support.

## Application Value

Real-Time Orbit Determination provides precise positioning capabilities for cislunar spacecraft and is a key technology for autonomous navigation.
