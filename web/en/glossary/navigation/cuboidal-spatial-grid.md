# Cuboidal Spatial Grid

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A three-dimensional grid model with uniform discretization along X, Y, Z axes in the Earth-Moon rotating frame, suitable for navigation performance evaluation over global spatial domains such as the entire Earth-Moon system.

## Application Value

Cuboidal Spatial Grid has important applications in cislunar space navigation and orbit determination systems.
