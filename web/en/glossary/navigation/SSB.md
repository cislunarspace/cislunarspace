# Solar System Barycenter

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Center of mass of the solar system, used as inertial reference point for pulsar observations and deep space navigation.

## Application Value

The solar system center of mass serving as an inertial reference point for describing planetary and spacecraft positions, the fundamental reference frame for deep space navigation.
