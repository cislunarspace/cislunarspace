# Dual-Layer Inter-Satellite Link

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A two-layer inter-satellite network in hybrid constellations: the first layer connects NRHO and DRO satellites for lunar proximity autonomous navigation; the second layer links NRHO/DRO to BDS GEO/IGSO satellites, providing Earth reference and enhancing system observability.

## Application Value

A two-layer inter-satellite network: the first layer connects NRHO/DRO satellites for lunar proximity autonomous navigation, while the second layer links to BDS GEO/IGSO providing an Earth reference frame.
