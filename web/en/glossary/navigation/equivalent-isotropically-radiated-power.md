# Equivalent Isotropically Radiated Power

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The sum of transmitter antenna gain and transmitter power (in dB), representing the equivalent power an isotropic antenna would need to radiate in the direction of maximum radiation. EIRP is a core parameter in GNSS link budgets, determining the signal power level at the receiver.

## Application Value

This concept is applied in analysis and design, with important implications for mission performance.
