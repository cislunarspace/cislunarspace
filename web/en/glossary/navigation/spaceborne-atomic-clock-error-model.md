# Spaceborne Atomic Clock Error Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A quadratic polynomial model describing the propagation of spaceborne atomic clock errors, containing three parameters: clock offset, clock drift, and clock aging, used for clock offset estimation and prediction in autonomous time synchronization.
