# Clock Bias Elimination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The process of canceling dominant clock bias terms through specific observation data combinations (such as the summation combination in dual one-way ranging), exploiting symmetry so that the measurement is no longer dominated by clock errors. Clock bias elimination is a prerequisite for high-precision inter-satellite ranging.
