# Libration Point Navigation Constellation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A navigation system deploying multiple satellites on Earth-Moon libration point orbits (e.g., Lyapunov or Vertical orbits at L3, L4, L5) and DRO, achieving autonomous orbit determination through inter-satellite ranging and gravitational asymmetry, covering the entire cislunar space with a small number of satellites.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
