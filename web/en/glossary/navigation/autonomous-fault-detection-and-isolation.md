# Autonomous Fault Detection and Isolation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technology enabling spacecraft to autonomously identify navigation system fault patterns in orbit and implement isolation and recovery. The paper notes that autonomous navigation demands extremely high reliability, requiring fault pattern identification from mission monitoring results and rapid fault recovery to ensure safe operation. Key research areas include real-time state monitoring and fault pattern recognition, and in-orbit fault recovery and system reconfiguration. The technology is characterized by high technical difficulty and limited exploration experience; China has currently achieved subsystem-level autonomous fault detection and isolation in some spacecraft missions such as autonomous rendezvous and docking.
