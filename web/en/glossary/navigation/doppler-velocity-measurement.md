# Doppler velocity measurement

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Measuring relative velocity between satellites using the Doppler effect of signals. Modeled as the projection of the relative velocity vector onto the line-of-sight direction, with accuracy affected by thermal noise.

## Application Value

Inter-satellite measurement uses links between spacecraft for navigation, providing independent navigation capability.
