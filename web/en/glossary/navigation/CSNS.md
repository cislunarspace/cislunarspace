# Cislunar Space Navigation System, CSNS

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A satellite navigation system deploying 34 navigation satellites on Special Long-Period Orbits, achieving autonomous orbit determination and time synchronization through inter-satellite links to provide PNT services for cislunar space users.

## Application Value

A space-based system providing navigation services for cislunar space, infrastructure supporting cislunar mission operations.
