# Beacon

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Navigation signals broadcast by navigation satellites to user spacecraft, containing satellite ephemeris and clock offset parameters, enabling users to achieve autonomous positioning and orbit determination by receiving these signals.
