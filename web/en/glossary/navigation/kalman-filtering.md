# Kalman Filtering

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A recursive optimal estimation method that recursively estimates satellite orbit, clock difference, and other parameters through state equations and observation equations. Kalman filtering is suitable for real-time orbit determination and is the core algorithm for real-time orbit determination in navigation systems.

## Application Value

Based on its definition, a recursive optimal estimation method that recursively estimates satellite orbit, clock difference, and other parameters through state equations and observation equations. kalman filtering is suitable.
