# Celestial Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Autonomous navigation technique that determines spacecraft position and velocity by measuring angles relative to stars or celestial bodies, including star pattern recognition and stellar occultation sensing.

## Application Value

星际导航是深空探测器自主导航的核心技术，不依赖地面测控站即可实现轨道确定。在地月空间以远的任务中，星敏和太阳传感器观测恒星和行星可推算航天器位置和速度。该技术可与惯性测量单元组合使用，通过滤波算法融合多源信息，提高导航精度。典型的星际导航方法包括星图匹配、光行差分析和天体高度角测量。
