# Orbit Determination Accuracy

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The degree of agreement between determined orbit and true orbit, typically measured by 3D Root Mean Square position and velocity errors. Influenced by ranging accuracy, dynamic model errors, observation geometry, and data arc length.

## Application Value

Orbit Determination Accuracy has important applications in cislunar space navigation and orbit determination systems.
