# Two-Line Element, TLE

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A standardized orbital data format maintained by NORAD, encoding classical orbital elements and epoch information in two lines of data. Widely used for near-Earth space object cataloguing but insufficient in accuracy for cislunar objects, requiring AI-based correction methods.
