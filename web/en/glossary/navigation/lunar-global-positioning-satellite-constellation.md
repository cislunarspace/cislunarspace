# Lunar Global Positioning Satellite Constellation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A constellation system of satellites in circumlunar orbit that provides real-time positioning and timing services to lunar surface users, analogous to GPS or BeiDou on Earth. It can be constructed using near-lunar orbits, elliptical frozen orbits, libration point orbits, or DROs.
