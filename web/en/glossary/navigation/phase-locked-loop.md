# Phase-Locked Loop

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A feedback loop in GNSS receivers used to track carrier phase. By locking onto the carrier phase of the received signal, it extracts pseudo-range rate (Doppler) measurements. Phase noise variance depends on coherent integration time and loop bandwidth.

## Application Value

Navigation system design and implementation must account for observation geometry, error propagation, and signal transmission delay. This concept supports positioning accuracy evaluation, navigation filter design, and constellation optimization.
