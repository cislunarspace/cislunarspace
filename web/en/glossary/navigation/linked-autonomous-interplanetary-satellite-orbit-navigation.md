# Linked, Autonomous, Interplanetary Satellite Orbit Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An autonomous cislunar navigation method that uses inter-satellite link ranging and gravitational asymmetry in a three-body system to achieve overall constellation orbit determination, avoiding the problem of constellation rotation drift. Proposed by Hill et al. in 2006.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
