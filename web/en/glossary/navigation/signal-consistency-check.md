# Signal Consistency Check

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique that cross-compares and checks consistency of measurement data from multiple navigation sensors. When a sensor produces anomalous measurements, it is excluded from the navigation update loop through consistency checking to prevent contamination of navigation results and improve system reliability.
