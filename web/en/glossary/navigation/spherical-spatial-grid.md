# Spherical Spatial Grid

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A local spatial grid model defined by longitude, latitude, and radial distance, suited for evaluating navigation performance in localized regions such as near-Earth or lunar proximity areas.

## Application Value

该方法可用于提高地月空间导航精度和任务安全性。
