# Proximity Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Autonomous navigation of the chaser vehicle within approximately 100 m to several hundred meters of the target. It uses LiDAR ranging, line-of-sight angle measurements, and proximity communication ranging to obtain relative state information, providing centimeter-to-decimeter positioning accuracy for close approach and docking.
