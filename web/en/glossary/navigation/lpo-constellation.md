# LPO Constellation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A satellite constellation based on libration point orbits (LPOs), achieving communication and navigation services across cislunar space through optimized multi-satellite configurations. Compared with traditional Keplerian satellite orbits, LPOs offer more diverse orbital options and more flexible spatial arrangements.

## Application Value

Navigation system design and implementation must account for observation geometry, error propagation, and signal transmission delay. This concept supports positioning accuracy evaluation, navigation filter design, and constellation optimization.
