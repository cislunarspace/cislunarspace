# Coplanar Unobservable Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

When the observer and target move in the same orbital plane, satisfying (D×Ḋ)⊥Ḋ, the IOD problem becomes unobservable with only three optical observations; at least four observations are required.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
