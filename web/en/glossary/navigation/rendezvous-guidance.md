# Rendezvous Guidance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Guidance methods that direct a chaser spacecraft to reach a target and establish a relative position within a predetermined time. In the cislunar three-body problem context, special techniques such as linearized equations or adjoint methods are needed to handle time-varying relative dynamics.

## Application Value

在组合导航系统中，该方法能够提高定轨精度和收敛速度，增强导航系统的鲁棒性，适用于地月空间的自主导航任务。
