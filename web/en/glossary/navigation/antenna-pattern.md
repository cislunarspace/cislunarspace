# Antenna Pattern

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A graphical representation of an antenna's radiation characteristics as a function of spatial direction. Typically parameterized by cone angle and azimuth, it describes the directional distribution of gain or directivity. GPS satellite antenna patterns determine signal coverage and are key inputs for cislunar GNSS navigation analysis.

## Application Value

在组合导航系统中，该方法能够提高定轨精度和收敛速度，增强导航系统的鲁棒性，适用于地月空间的自主导航任务。
