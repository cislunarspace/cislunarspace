# Orbit Determination Error

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Position and velocity measurement deviations in the orbit determination process, modeled with zero-mean Gaussian distributions.

## Application Value

Estimating spacecraft orbital state through observational data. Orbit determination error is a core indicator of navigation accuracy affecting mission safety.
