# Initial Epoch Point

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The state point on a dynamical substitute orbit at the initial observation epoch, corresponding to the state quantity to be estimated in orbit determination. Different initial epoch points correspond to different observation geometries; orbit determination accuracy sensitivity to the initial point decreases as the sampling arc length increases.
