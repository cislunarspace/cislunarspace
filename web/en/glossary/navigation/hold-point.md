# Hold Point

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Intermediate stopping points set during the rendezvous process where the chaser pauses and checks its state. Hold points are selected based on passive safety principles, located on stable manifolds to ensure that even loss of control won't cause collision with the target.

## Application Value

Hold Point has important applications in cislunar space navigation and orbit determination systems.
