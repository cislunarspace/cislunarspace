# Time of Arrival

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Time when pulsar X-ray pulse arrives at spacecraft; core measurement for pulsar navigation.

## Application Value

支撑自主导航系统的开发，提高轨道确定精度 为目标跟踪和状态估计提供关键技术支撑。
