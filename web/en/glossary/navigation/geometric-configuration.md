# Geometric Configuration

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The spatial geometric distribution of navigation satellites relative to the receiver. In cislunar space, all visible GNSS satellites cluster near the zenith direction, resulting in extremely poor geometric configuration and very high DOP values that amplify measurement errors.

## Application Value

在态势感知系统中，该观测方法为低轨空间目标监视提供技术手段，是空间交通管理的数据来源。
