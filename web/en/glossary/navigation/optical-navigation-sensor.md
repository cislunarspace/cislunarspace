# Optical Navigation Sensor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A navigation device that uses optical imaging to acquire celestial surface features. It captures lunar surface images, extracts feature points, and calculates the vehicle's position relative to the surface, providing high-precision relative position information during the landing approach phase.
