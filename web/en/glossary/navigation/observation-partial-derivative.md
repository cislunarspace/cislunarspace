# Observation Partial Derivative

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The partial derivative of an observation quantity with respect to the satellite state vector (position, velocity), used in orbit determination to construct observation equations and update state estimates.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
