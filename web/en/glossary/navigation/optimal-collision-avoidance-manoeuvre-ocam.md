# Optimal Collision Avoidance Manoeuvre, OCAM

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A single-burn collision avoidance scheme executed inside the KOZ. Optimized to push the closest approach vector outside the safety boundary with minimum delta-V while remaining within thruster capability. Executed only when the trajectory presents actual collision risk.

## Application Value

When collision risk actually exists, the optimization algorithm pushes the trajectory outside the safety boundary with minimum delta-V, avoiding unnecessary maneuvers. This strategy is especially suitable for debris-dense cislunar space, maximizing propellant savings while ensuring safety.
