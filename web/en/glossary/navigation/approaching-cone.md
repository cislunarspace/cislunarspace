# Approaching Cone

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A geometric path constraint for the final rendezvous approach phase, defined as a cone-shaped zone emanating from the target docking port. The chaser's center of mass must remain within the cone, whose axis rotates with the target attitude. The paper uses a half-cone angle of 25 degrees.


## Application Value

对接是两个航天器在轨组装和物资补给的前提，需要精确的相对导航和控制。
