# Deterministic Clock Error

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Deterministic Clock Error; the portion of clock error describable by a deterministic polynomial model, typically expressed as a second-order polynomial incorporating clock bias, drift, and aging effects.
