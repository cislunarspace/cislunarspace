# Hold Point Reallocation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

When actuator failure prevents completing rendezvous as planned, selecting new hold point locations on the unstable manifold of the target orbit and determining a new maneuver sequence via graph optimization, allowing the chaser to safely reach the target in the next orbital period.

## Application Value

在周期轨道设计中，该指标用于评估轨道的有界性和长期稳定性，指导轨道维持策略的制定。
