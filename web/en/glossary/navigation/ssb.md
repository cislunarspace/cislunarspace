# Solar System Barycenter

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Center of mass of the solar system, used as inertial reference point for pulsar observations and deep space navigation.

## Application Value

Solar System Barycenter has significant application value in cislunar space missions, primarily used for autonomous positioning and orbit control of spacecraft.
