# Precision Orbit Determination with ISL

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The technique of determining spacecraft orbits using inter-satellite link range or range-rate data. Unlike ground-based tracking, ISL precision orbit determination does not depend on ground stations and can achieve autonomous orbit determination in cislunar space beyond ground coverage. In cislunar applications, dual-one-way measurement achieves meter-level ranging accuracy, and three-satellite joint orbit determination reaches sub-50-meter accuracy within a one-day tracking arc.

## Application Value

This term has significant application value in cislunar space missions。In the orbital design phase, engineers use relevant theories for trajectory optimization；In navigation and orbit determination, it is used to improve measurement accuracy；In attitude control and orbit maintenance tasks, it ensures stable spacecraft operation。In practical applications, parameter optimization and algorithm adaptation can be combined with mission requirements to improve mission success rate and resource utilization efficiency。
