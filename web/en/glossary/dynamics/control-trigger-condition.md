# Control Trigger Condition

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In station-keeping, a condition that propagates the state forward without control to a future time and checks whether the predicted deviation from the baseline remains within tolerance. If the deviation is within bounds, the maneuver is skipped. This mechanism reduces unnecessary propellant consumption by keeping the controller idle when no significant disturbance is present.
