# Non-tangential Injection

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An injection strategy in interior transfers where the impulse direction is not perpendicular to the position vector. The spacecraft first passes near the Moon, then winds around the Earth-Moon system before being captured by the DRO. Achieves fuel consumption comparable to exterior transfers by leveraging natural gravitational dynamics, but requires longer flight time.

## Application Value

In orbital mechanics analysis, this perturbation factor is one of the main sources of orbit prediction error. Accurately modeling this effect helps improve orbit prediction accuracy and supports applications such as station keeping and collision warning.
