# Eulero-Hill Equations

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Linear equations of relative orbit motion, derived by linearizing the relative motion equations around the target position; accurate only when the chaser is sufficiently close to the target.

## Application Value

在欧拉-希尔方程的设计与分析中，可用于优化转移方案，减少燃料消耗 描述系统状态随时间的变化规律，是轨道预报的基础。
