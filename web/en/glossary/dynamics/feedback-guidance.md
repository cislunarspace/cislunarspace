# Feedback Guidance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Guidance method that uses real-time state information to compute guidance commands via feedback control laws, capable of compensating for non-nominal flight conditions without pre-computed reference trajectories, suitable for high-autonomy missions.
