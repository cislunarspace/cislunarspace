# Geocentric Celestial Reference Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Coordinate system with origin at Earth's center of mass, fundamental plane as Earth's equatorial plane, X-axis pointing to vernal equinox, K-axis pointing to North Pole. Also known as GCRF.

## Application Value

In orbit calculation and mission analysis, correct coordinate reference frames are the foundation for ensuring consistency of calculation results. Transformations between different reference frames need to consider this definition to ensure unified processing of multi-source data.
