# Stable Eigenvector

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An eigenvector of the monodromy matrix corresponding to an eigenvalue with absolute value less than 1, indicating the direction along which perturbations naturally decay back toward the periodic orbit. Stationkeeping maneuvers aligned with the stable eigenvector push the spacecraft back into the center subspace, maintaining the orbit.

## Application Value

在周期轨道设计中，该指标用于评估轨道的有界性和长期稳定性，指导轨道维持策略的制定。
