# Nonlinear Orbit Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Orbit control method based on Lyapunov stability theory, designing feedback control laws to drive spacecraft orbital elements to target values. The control law has quasi-global stability and enables real-time guidance without offline reference trajectories.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
