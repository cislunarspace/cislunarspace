# Synchronous Rotation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A state where a spacecraft's rotation period equals its orbital period, always keeping the same side facing the primary body.

## Application Value

该轨道类型可作为地月空间运输网络的中转站或任务的目标轨道。
