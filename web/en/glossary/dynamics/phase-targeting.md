# Phase Targeting

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method for defining target points on the quasi-periodic invariant torus by specifying the target phase angle, with the longitude angle synchronized with the follower to avoid relative drift. This method exploits the symmetry of the torus to minimize discrepancies between ground-based optimization and onboard re-planning.

## Application Value

结合数值优化算法，可实现高性能的轨迹规划 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
