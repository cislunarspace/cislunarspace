# Divergent Solution

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A solution corresponding to the generalized eigenvector of unit eigenvalues in Floquet theory. The deputy drifts monotonically along the tangential direction relative to the chief, with growing radial amplitude. Dynamically, it corresponds to another planar DRO with a different period near the original orbit, causing long-term drift due to period mismatch.

## Application Value

This orbit type can serve as a transit node of the Earth–Moon transportation network or as a mission target orbit. This theory can be used to analyze the stability of motion near periodic orbits and guide station-keeping strategies.
