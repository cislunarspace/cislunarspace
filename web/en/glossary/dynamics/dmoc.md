# DMOC

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A direct local optimal control method based on direct discretization of the variational structure of the mechanical system (Lagrange-d'Alembert principle), using forced discrete Euler-Lagrange equations as equality constraints for nonlinear optimization solved by SQP.

## Application Value

In spacecraft control system design, this method can be used to design attitude control laws or guidance laws, achieving precise control of spacecraft attitude and orbit. In practical missions, controllers based on this method can improve attitude stability and trajectory tracking accuracy.
