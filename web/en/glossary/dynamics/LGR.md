# Legendre-Gauss-Radau Points

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Orthogonal nodes used in pseudospectral discretization, mapping continuous time intervals to discrete nodes for numerical solution.

## Application Value

As discretization nodes for pseudospectral methods, they substantially reduce optimization variables while maintaining numerical accuracy, making them a widely adopted strategy in low-thrust trajectory optimization.
