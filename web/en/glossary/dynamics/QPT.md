# Quasi-Periodic Invariant Tori, QPT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Closed bounded surfaces in the CRTBP covered by specific quasi-periodic non-resonant trajectories, surrounding a reference periodic orbit. The ratio of the main motion direction (longitude) frequency to the winding motion direction (phase) frequency is an irrational number, causing the trajectory to never close. Can be used to design naturally bounded relative trajectories for formation flying.

## Application Value

Closed bounded surfaces in the CRTBP covered by quasi-periodic non-resonant trajectories surrounding reference periodic orbits, with irrational frequency ratios making trajectories never close, usable for designing naturally bounded formation flying relative trajectories.
