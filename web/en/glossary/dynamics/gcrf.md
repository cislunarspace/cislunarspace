# Geocentric Celestial Reference Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The current standard inertial coordinate system for Earth, referenced to the ICRF, officially adopted in 1997, effectively replacing the IAU-76/FK5 J2000 system.

## Application Value

Geocentric Celestial Reference Frame plays an important role in orbital dynamics and attitude control, serving as a critical tool for analyzing spacecraft motion characteristics. Research on this concept enables optimization of orbit transfer schemes and improvement of control system performance.
