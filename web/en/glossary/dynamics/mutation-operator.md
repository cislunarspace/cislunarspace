# Mutation Operator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In differential evolution, the operation of generating a mutant vector by randomly selecting population members. The mutant vector combines with a target vector to produce a trial vector, serving as the algorithm's main mechanism for exploring the search space.
