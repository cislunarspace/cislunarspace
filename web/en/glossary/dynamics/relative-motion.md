# Relative Motion

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The position and velocity of one satellite with respect to another (or with respect to a reference point) in a rotating coordinate frame. Near libration points, relative motion is composed of long-period and short-period modes; judicious selection of initial velocity conditions can eliminate one mode to yield purely elliptical relative trajectories suitable for formation design.

## Application Value

在航天器系统设计和任务分析中，该概念用于描述航天器的运动特性或任务模式，为任务方案论证和系统设计提供理论基础.
