# Tracking Error

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Deviation between actual spacecraft state and nominal trajectory, arising from navigation and actuator accuracy limitations.
