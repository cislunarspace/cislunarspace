# Nonconvex Control Constraints

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Constraints that define a nonconvex region in the control space, such as an annulus defined by lower and upper bounds on thrust magnitude.

## Application Value

This concept is used in orbital analysis and has significant impact on mission design.
