# Invariant Curve

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A closed curve on an invariant torus from which a point returns to itself after one perturber period. The curve varies with the perturber orbital phase and can be parameterized by Fourier series. It serves as a key intermediate tool for computing invariant torus manifolds in the bicircular four-body problem.
