# Pseudospectral Discretization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Method that transforms continuous optimal control problems into finite-dimensional parameter optimization problems using high-order orthogonal nodes.

## Application Value

为航天器的精确控制提供理论依据，确保任务执行的可靠性 结合数值优化算法，可实现高性能的轨迹规划。
