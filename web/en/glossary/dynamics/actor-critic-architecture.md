# Actor-Critic Architecture

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A policy optimization framework in modern reinforcement learning, comprising a policy network (actor) that generates actions and a value network (critic) that estimates the state-value function. A2PPO extends the standard actor-critic architecture with a directional cross-attention module.

## Application Value

Actor-Critic Architecture plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
