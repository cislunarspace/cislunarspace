# Hansen Coefficients

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of coefficients introduced by German astronomer Peter Hansen for lunar motion analysis using an intermediate orbit as the reference, forming an important tool in lunar theory.

## Application Value

Precise determination of these coefficients directly impacts orbit calculation accuracy, requiring continuous refinement with observational data.
