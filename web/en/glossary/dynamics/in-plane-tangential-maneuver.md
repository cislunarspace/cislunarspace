# In-Plane Tangential Maneuver

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A maneuver applying thrust along the in-track direction within the orbital plane. Used for trans-lunar injection from LEO; to rendezvous with the Moon at any declination, the LEO inclination must exceed the lunar orbital inclination (18-28 degrees).

## Application Value

This concept is used in orbital analysis and has significant impact on mission design.
