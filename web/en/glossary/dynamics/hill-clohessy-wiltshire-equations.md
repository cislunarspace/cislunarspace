# Hill Clohessy Wiltshire Equations

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Set of linearized equations describing relative motion of a chaser satellite relative to a target in a near-circular orbit

## Application Value

在希尔-克洛塞-威尔特希尔方程的设计与分析中，可用于优化转移方案，减少燃料消耗 描述系统状态随时间的变化规律，是轨道预报的基础。
