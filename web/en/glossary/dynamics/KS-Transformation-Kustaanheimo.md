# KS Transformation / Kustaanheimo-Stiefel Transformation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Coordinate transformation that regularizes two-body equations of motion by introducing fictitious time s, eliminating the singular 1/r term for more stable numerical integration near periapsis.

## Application Value

This concept has application value in cislunar space research and engineering practice, helping to understand core principles of the field.
