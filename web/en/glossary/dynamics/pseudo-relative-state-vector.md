# Pseudo-Relative State Vector, ρ*

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A modified relative position vector defined to satisfy frustum constraints, transforming conical constraints into linear constraints through offset.

## Application Value

Virtual state vectors introduced in relative motion analysis to simplify relative orbital dynamics analysis and design.
