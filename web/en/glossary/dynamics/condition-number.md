# Condition Number

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The ratio of the largest to smallest singular value of a matrix, measuring the well-posedness of an estimation problem. A smaller condition number of the observability Gramian indicates more uniform sensitivity across state directions and better estimation accuracy; a larger number amplifies measurement noise on the weakest directions. The common logarithm of this value serves as the empirical observability metric.

## Application Value

在航天器导航和定位中，该方法用于从传感器数据中提取有效信息，实现自主定轨和轨道预报. 支持地月空间探测任务的实时导航需求.
