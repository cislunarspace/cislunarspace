# Isochronous Point

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A point on the nominal orbit that moves isochronously with the spacecraft, meaning the time for the spacecraft to reach it along natural motion equals the current time.

## Application Value

在轨道力学分析和任务设计中，This概念为轨道特性评估和方案比选provides理论依据，有助于优化轨道设计参数，提高任务经济性。
