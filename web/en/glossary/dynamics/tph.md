# Target Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In TPhA, the phase angle at a prescribed Poincare section surface where the target state for correction maneuver is located.

## Application Value

The 目标相位 concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
