# Numerical Manifold Approximation Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that approximates invariant manifold state points using two-dimensional interpolation (e.g., bicubic convolution interpolation). By representing manifold states as a bivariate function of the periodic orbit initial-point integration time and the manifold integration time, it pre-computes an interpolation database, allowing direct manifold point retrieval during optimization without repeated integration.
