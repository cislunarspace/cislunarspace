# Interior Interval

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The subinterval of an optimal trajectory where a state constraint is inactive (i.e., holds as a strict inequality). The Lagrange multiplier for the constraint is zero and adjoint variables evolve continuously.
