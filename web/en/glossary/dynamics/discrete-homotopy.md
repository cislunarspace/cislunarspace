# Discrete Homotopy

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A homotopy path tracking method. Divides the homotopy parameter from initial to target value into discrete steps, solving each sub-problem sequentially and using the previous solution as the initial guess for the next. Simple and intuitive, but fails when the homotopy curve has turning points or when adjacent steps are too large.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
