# Powered Descent Guidance, PDG

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The guidance process in which a landing vehicle decelerates from high speed to near-zero speed and lands at a preflight-designated surface location by maneuvering a retropropulsion system. It can be formulated as an optimal control problem to minimize fuel consumption while satisfying control and state constraints.

## Application Value

The 动力下降制导 concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
