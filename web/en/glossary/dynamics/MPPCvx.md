# Adaptive Multi-phase Pseudospectral Convex Optimization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A powered descent guidance method that divides the descent process into multiple phases, discretizes using pseudospectral method, solves via convex optimization, and adaptively determines optimal phase division using the indirect method.

## Application Value

By predefining performance bounds, it guarantees both transient response quality and steady-state accuracy, making it suitable for spacecraft orbit tracking and attitude control with model uncertainties and external disturbances.
