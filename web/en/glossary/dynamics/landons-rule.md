# Landon's Rule

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Nutation stability criterion for dual-spin satellites: slender body can be stable if only one rotor dissipates energy.

## Application Value

This concept provides an important theoretical foundation for cislunar space mission design. In practical engineering, it can be applied to orbit design, mission planning, or control system analysis.
