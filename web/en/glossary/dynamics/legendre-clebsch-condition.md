# Legendre-Clebsch Condition

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Second-order necessary condition in optimal control theory, requiring the second partial derivative of the Hamiltonian with respect to control variables to be nonnegative. Used to determine the correct sign of thrust steering angles.
