# Chebyshev-Gauss-Lobatto Points, CGL Points

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A node distribution strategy using cosine mapping to concentrate nodes near boundaries, used for time domain discretization to compensate the Runge effect, enabling use of higher-degree polynomials.

## Application Value

Nodes densely distributed at boundaries effectively compensate Runge phenomenon for high-degree polynomials, an effective discretization strategy for solving boundary value problems.
