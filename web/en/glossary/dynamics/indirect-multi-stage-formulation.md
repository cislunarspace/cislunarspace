# Indirect Multi-Stage Formulation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that divides a complete trajectory into a series of connected stages via equality constraints, optimizing control independently for each stage.

## Application Value

在轨道控制律设计中，该方法通过优化推力方向和大小实现燃料消耗最小化，是深空任务的核心技术。
