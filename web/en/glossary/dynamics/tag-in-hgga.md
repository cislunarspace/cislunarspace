# Tag (in HGGA)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In HGGA, a binary identifier associated with each gene indicating whether the gene is 'active' or 'hidden'. Hidden genes are not considered in objective function evaluation, enabling variable-length chromosome search capability.
