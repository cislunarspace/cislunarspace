# Pseudostate Transformation Sphere

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A sphere defined in the pseudostate theory, centered at the Moon's position at a given epoch with radius R_PTS, serving as the switching boundary between the Earth-centered and Moon-centered two-body computation regimes. For trans-lunar trajectories, the radius is typically set to 24 Earth radii. Outside the PTS, the trajectory is computed in the Earth-centered two-body model; inside, in the Moon-centered two-body model. The state transformation between the two reference frames is performed via linear back-propagation at the PTS boundary.

## Application Value

This concept has important application value in cislunar space research and mission design.
