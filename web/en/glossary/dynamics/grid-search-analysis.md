# Grid Search Analysis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A systematic trajectory optimization method that evaluates an objective function (total ΔV) at discrete grid points across multiple control variables (e.g., NRHOI and PLSB velocity increments) to find the optimal solution satisfying constraints. The paper uses this method to search for minimum total ΔV in the two-dimensional parameter space of NRHOI and PLSB, with constraints on Earth equatorial inclination and perigee altitude.
