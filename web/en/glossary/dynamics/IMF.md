# Indirect Multi-Stage Formulation, IMF

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that divides a complete trajectory into a series of connected stages via equality constraints, optimizing control independently for each stage.

## Application Value

Indirect methods for solving multi-stage optimal control problems, describing inter-stage boundary relations through co-state equations and transversality conditions.
