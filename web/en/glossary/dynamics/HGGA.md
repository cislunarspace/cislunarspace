# Hidden-Genes Genetic Algorithm, HGGA

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A variant of genetic algorithm that handles variable-length decision vectors. It uses a fixed-length chromosome structure with tags to mark each gene as active or hidden, so that the objective function evaluates only variables corresponding to active genes, enabling efficient search in a variable-size design space.

## Application Value

This method plays an important role in cislunar mission trajectory design and optimization, improving computational efficiency and solution quality.
