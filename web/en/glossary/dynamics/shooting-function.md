# Shooting Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A function mapping initial covector values to terminal state deviations. A zero of the shooting function corresponds to satisfied boundary conditions in minimum time problems. Tracking the zero-level set of the shooting function and detecting rank changes in its derivative identifies conjugate points and turning points.


## Application Value

This concept is of significant importance in cislunar space research and technical applications, helping to deepen understanding of related physical mechanisms and engineering implementations.
