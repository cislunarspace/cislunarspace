# Mesh Refinement

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Strategy of increasing nodes where state changes are rapid and decreasing them where changes are gradual, to improve accuracy and computational efficiency. Key to collocation method convergence.

## Application Value

Mesh Refinement plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
