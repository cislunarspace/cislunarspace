# Perturbation Magnitude Analysis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A quantitative method expressing perturbation intensity as the ratio of perturbative acceleration to the central body's gravitational acceleration. Combined with a minimum perturbation magnitude threshold, it determines which celestial bodies must be included in the dynamical model for a given accuracy requirement.

## Application Value

该方法在地月空间目标轨道预报中用于建立高精度动力学模型，提高预报精度并延长有效预报弧段。
