# Adjoint-Control Transformation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A variable transformation technique that simplifies solving optimal control problems. By combining adjoint variables (costates) with control quantities, a form more suitable for numerical solution is derived. This transformation can reduce the degrees of freedom of the shooting function and lower computational complexity.

## Application Value

It provides the theoretical basis for precise spacecraft control and helps ensure mission reliability. This concept provides an important theoretical foundation for cislunar mission design. In practical engineering it can be applied to orbit design, mission planning, or control system analysis.
