# Patched Three-Body Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A hybrid modeling approach that uses the Earth-Moon three-body model when the spacecraft is near the Moon, and the Sun-Earth three-body model otherwise.

## Application Value

This术语在地月空间任务的设计、分析和控制中具有important应用价值，为相关技术领域的研究和工程实践provides理论支撑。
