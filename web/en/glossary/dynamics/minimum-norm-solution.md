# Minimum-Norm Solution

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

When the number of free variables exceeds the number of constraints, the minimum-norm solution is selected via a minimum-norm update equation that minimizes the difference between successive iterations, ensuring the converged solution retains characteristics of the initial guess.

## Application Value

In orbitdesign和control中, 该概念对理解spacecraftIn cislunar space中 of motion特性和missiondesignhas important role.
