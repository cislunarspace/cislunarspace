# Poincaré Map Representation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Representation of periodic and quasi-periodic orbit families using their intersections with the z=0 plane (Poincaré section).
