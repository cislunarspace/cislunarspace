# Real-time Convex Optimization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Techniques for solving convex optimization problems in real-time on flight processors; combined with Interior Point Methods can achieve runtime speeds 2-3 orders of magnitude faster than conventional methods.

## Application Value

This method can be applied to solve optimization problems in cislunar missions, such as orbit transfer, fuel consumption minimization, or task scheduling.
