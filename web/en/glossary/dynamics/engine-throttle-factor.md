# Engine Throttle Factor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A control variable u in [0, 1] for low-thrust engines. u=1 corresponds to full thrust and u=0 to engine-off. In energy-optimal and fuel-optimal control, the throttle factor is determined jointly by co-state variables and homotopy parameters, enabling continuous thrust modulation.

## Application Value

在航天器姿态和轨道控制中，该方法用于实现高精度跟踪和稳定保持. 通过设计合适的控制律，可以有效抑制外部扰动的影响，保证航天器在复杂动力学环境中的可靠运行.
