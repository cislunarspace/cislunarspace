# Indirect Heuristic Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Numerical method for low-thrust orbit transfer that combines necessary conditions for optimality (Pontryagin's Minimum Principle) with heuristic algorithms such as Differential Evolution.

## Application Value

在设计地月转移方案时，利用该轨道特性可降低任务总速度增量需求。对于大质量航天器的长时间转移，该推进方式可大幅降低推进剂消耗。
