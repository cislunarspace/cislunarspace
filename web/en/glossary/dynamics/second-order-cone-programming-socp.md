# Second-Order Cone Programming, SOCP

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A class of convex optimization problems with a linear objective function and second-order cone constraints (i.e., the 2-norm of an affine function is bounded by another affine function). SOCP is easier to solve globally than general nonlinear programming and can express more constraints than linear programming. In cislunar station-keeping, SOCP unifies terminal ellipsoid constraints and impulse magnitude bounds into a single convex framework.


## Application Value

In a linear quadratic optimal control framework, selecting appropriate weight matrices Q and R achieves a balance between tracking accuracy and control energy consumption, making it suitable for real-time control in cislunar orbit keeping.
