# Launch Velocity Error

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The deviation of actual launch velocity from the nominal value due to launch vehicle inaccuracies. This error has an outsized effect on Halo orbit missions: near the apogee of the transfer orbit, velocity drops sharply, so the required correction Delta-V grows rapidly with delay. For Genesis, the expected error was 7 m/s (1-sigma) relative to a ~3200 m/s boost, with a correction window of only a few days.

## Application Value

在发射速度误差的分析中，可用于轨道传播和机动设计，帮助工程师评估航天器在不同动力学环境下的运动特性 该概念为地月空间任务设计提供了理论基础，尤其在平动点轨道设计和低能转移分析中具有重要应用价值 利用发射速度误差进行轨迹优化，可以有效降低任务燃料消耗，提高任务经济效益 在任务设计中，发射速度误差的分析有助于理解航天器在复杂引力场中的行为，指导轨道保持策略的制定
