# KSG Integrator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A numerical integration method for solving satellite equations of motion. In cislunar space cataloguing orbit determination, it propagates the complete three-body dynamical model with a 60-second step size.

## Application Value

The KSG integrator is a high-precision numerical integration method for orbit calculation.
