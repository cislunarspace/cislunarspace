# Perturbed Lambert Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A two-point boundary value problem that extends the classical Lambert problem (finding a connecting orbit given two position vectors and flight time) by incorporating multi-body gravitational perturbations. Unlike the classical Lambert problem which assumes two-body conditions, the perturbed Lambert problem requires numerical shooting methods. The paper applies it to compute intermediate arc trajectories far from both Earth and Moon, determining two mid-course impulse vectors.
