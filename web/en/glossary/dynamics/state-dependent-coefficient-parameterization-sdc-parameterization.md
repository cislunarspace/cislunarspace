# State Dependent Coefficient Parameterization, SDC Parameterization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique that expresses the state matrix of a nonlinear system as a function of the state itself. By rewriting the nonlinear equation in pseudo-linear form as ẋ=A(x)x+B(x)u, the SDRE method converts the nonlinear problem into a time-varying linear LQR problem at each time instant.
