# Particle Swarm Optimizer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A swarm intelligence optimization algorithm that simulates bird flock foraging behavior, using individual historical optimum and global optimum information to guide the search, employed for initial guess in solving two-point boundary value problems.

## Application Value

PSO provides global search capability for finding initial guesses in two-point boundary value problems, leveraging swarm intelligence to avoid local minima in complex trajectory optimization.
