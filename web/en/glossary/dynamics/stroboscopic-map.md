# Stroboscopic Map

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The stroboscopic map is the collection of states with the same longitude but variable phase angle. The paper exploits this map to ensure that the follower and target point always belong to the same stroboscopic map during the transfer, thereby preventing relative drift between them during the transfer.

## Application Value

This concept is essential for understanding motion characteristics in orbital design and control, and plays a vital role in mission success.
