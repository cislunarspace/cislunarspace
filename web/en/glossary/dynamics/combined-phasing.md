# Combined Phasing

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A phasing strategy composed of multiple two-impulse phasing arcs joined together. When single impulsive maneuver capability is limited, the phasing task is decomposed into multiple arcs executed sequentially, each independently optimized, to achieve large phase difference adjustments through flexible combination of different arc types.

## Application Value

在轨道设计参数优化中，该算法用于在庞大解空间中搜索全局最优或近似最优解. 适用于复杂约束条件下的多目标优化问题.
