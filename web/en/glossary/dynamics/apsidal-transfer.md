# Apsidal Transfer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Two-impulse optimal control for coplanar elliptical orbit transfer via apsidal rotation.

## Application Value

Apsidal transfer via two-impulse optimal control enables efficient coplanar elliptical orbit transfers through rotation of the line of apsides.
