# Bicircular Restricted Four-Body Problem, BCR4BP

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A four-body model that introduces solar gravitational effects on top of the circular restricted three-body problem. The Sun is assumed to move along a circular path in the xy-plane of the Earth-Moon rotating frame.

## Application Value

This reference frame has fundamental applications in cislunar orbital calculations and observation data processing.
