# Position-Based Feature Vector

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A finite-dimensional vector composed of position vectors at sampled states along a trajectory, used in clustering to capture the evolution of the path.

## Application Value

该概念是分析地月空间动力学行为的基础工具。在轨道设计和任务分析中具有重要应用价值。
