# TPA Loop

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The interval between two consecutive orbit determination epochs; if set to an integer multiple of the orbital period, TPA parameters can be reused across loops.

## Application Value

If the TPA loop interval is set to an integer multiple of the orbital period, TPA parameters can be reused across loops. Orbit designers plan navigation arcs accordingly, reducing the computational burden of orbit determination.
