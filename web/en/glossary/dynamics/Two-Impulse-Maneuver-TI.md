# Two-Impulse Maneuver, TI

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Transfer strategy between collinear libration point orbits using two impulsive velocity changes, solved via State Transition Matrix.

## Application Value

This maneuver type plays an important role in cislunar transfer and orbit adjustment missions, affecting energy consumption and flight time.
