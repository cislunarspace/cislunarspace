# Gauss Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A classical initial orbit determination method. It determines the target's position and velocity vectors from angular observations at three epochs using geometric relations. Similar to the Laplace method, it is effective under two-body dynamics but requires modifications for the cislunar three-body gravitational environment.

## Application Value

该方法利用角度观测数据可快速确定目标轨道，适用于初轨确定。该模型是分析地月空间动力学、设计低能量转移轨道的基础工具。在编目系统中，该技术可提高对空间目标的探测、跟踪和编目能力。
