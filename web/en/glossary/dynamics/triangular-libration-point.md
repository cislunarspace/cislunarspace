# Triangular Libration Point

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Equilibrium points in the restricted three-body problem forming equilateral triangles with the two primary bodies, located on opposite sides of the line connecting them, also known as L4 and L5 points.

## Application Value

在三角平动点的分析中，可用于轨道传播和机动设计，帮助工程师评估航天器在不同动力学环境下的运动特性 该概念为地月空间任务设计提供了理论基础，尤其在平动点轨道设计和低能转移分析中具有重要应用价值 利用三角平动点进行轨迹优化，可以有效降低任务燃料消耗，提高任务经济效益 在任务设计中，三角平动点的分析有助于理解航天器在复杂引力场中的行为，指导轨道保持策略的制定
