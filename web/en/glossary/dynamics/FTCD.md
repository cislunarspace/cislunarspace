# Finite-Time-Convergent Differentiator, FTCD

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A signal differentiation estimator based on singular perturbation techniques. Given a measurable signal, it reconstructs the first and second derivatives with high accuracy within finite time. Typically used to estimate velocity from position measurements when direct velocity sensing is unavailable.

## Application Value

In descent phases where direct velocity measurement is unavailable, it estimates velocity information in real-time from position signals, providing essential state feedback for guidance and control. It has important applications in lunar landing and orbital transfer missions.
