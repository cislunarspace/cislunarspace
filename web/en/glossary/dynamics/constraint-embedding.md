# Constraint Embedding

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Analytically integrating constraints into the problem formulation so they are automatically satisfied, eliminating iterative constraint handling during optimization and simplifying the solution process.

## Application Value

约束解析嵌入将约束条件转化为系统方程的一部分，是求解约束优化问题的有效方法。
