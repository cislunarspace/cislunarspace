# Sliding Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The second phase of sliding mode control system motion, where system states slide along the sliding surface toward the equilibrium. During the sliding phase, system dynamics are governed by the sliding surface equation, providing invariance to external disturbances and parametric uncertainties (robustness of the sliding mode). The sliding phase duration is determined by sliding surface design parameters and has an upper bound.
