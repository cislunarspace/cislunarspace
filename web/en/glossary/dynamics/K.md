# Auxiliary Longitude

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An angular variable K used as independent variable instead of true longitude L, avoiding violation of monotonicity of true longitude with respect to time at large thrust or perturbing accelerations, and providing simpler forms of motion equations and optimal control expressions.

## Application Value

The auxiliary longitude parameter in equinoctial elements, together with true longitude describing in-plane orbital position.
