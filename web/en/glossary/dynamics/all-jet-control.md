# All-jet Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Attitude control method using only jet thrusters, without momentum devices.

## Application Value

All-jet control eliminates dependence on momentum devices for attitude control, simplifying spacecraft design but increasing propellant consumption.
