# Underactuation Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A problem where the number of independent control inputs is fewer than the number of degrees of freedom to be controlled. A solar sail has only two control inputs (pitch and yaw angles) for the sail normal vector, making it impossible to independently control three-axis relative positions. Solutions include adding auxiliary control methods (Coulomb force, electric propulsion, multi-element sails) or exploiting dynamic coupling properties.

## Application Value

在航天器姿态和轨道控制中，该方法用于实现高精度跟踪和稳定保持. 通过设计合适的控制律，可以有效抑制外部扰动的影响，保证航天器在复杂动力学环境中的可靠运行.
