# Averaging Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A perturbation method for small control magnitude (low thrust) that uses the true anomaly or longitude as a new time parameter to analyze averaged behavior of fast oscillating systems. It transforms the optimal control problem for elliptical orbits into one with hyperelliptic integral cost.

## Application Value

in analyses involving the averaging method, it can be applied to orbit propagation and maneuver design, helping engineers evaluate spacecraft motion characteristics across different dynamical environments. this concept provides an important theoretical foundation for cislunar mission design, and is of significant value in libration point orbit design and low-energy transfer analysis. using the averaging method for trajectory optimization can effectively reduce mission fuel consumption and improve mission economics. in mission design, analysis with the averaging method helps understand spacecraft behavior in complex gravity fields and guides the formulation of station-keeping strategies
