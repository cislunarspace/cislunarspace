# NTW Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Satellite coordinate system where N is in the orbital plane perpendicular to velocity, T is parallel to velocity vector, and W is parallel to angular momentum vector, forming a right-handed system.
