# Single-Step Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A numerical integration method that computes the next state using only the current state information, such as the Runge-Kutta and trapezoidal methods. Unlike multistep methods, single-step methods do not require storing historical states, facilitating startup and variable step sizes. They are used in the quasilinearization-discretization-recursion algorithm to discretize continuous-time dynamics.

## Application Value

In orbit design and optimization, this concept is used to analyze spacecraft motion characteristics in the cislunar multi-body gravitational field, providing a theoretical basis for low-energy transfer trajectory design.
