# Border Point

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In DBSCAN, a point that lies in the neighborhood of a core point but does not possess enough neighbors within its own neighborhood to be a core point, belonging to a cluster but not a core member.
