# Quasi-random Process for Periodic Orbit Generation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method for discovering periodic orbits by selecting an arbitrary initial position along the x-axis of the synodic reference frame and adjusting the y-direction velocity until the trajectory closes in a periodic manner.

## Application Value

Quasi-random Process for Periodic Orbit Generation plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
