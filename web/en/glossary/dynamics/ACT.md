# Adjoint Control Transformation, ACT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A transformation that maps sensitive costate variables to physically realizable parameters, employed to reduce the difficulty of generating initial guesses for indirect TPBVP solutions.

## Application Value

Adjoint control transformation simplifies sensitivity calculation by introducing adjoint variables, an efficient mathematical tool for optimization problem derivation.
