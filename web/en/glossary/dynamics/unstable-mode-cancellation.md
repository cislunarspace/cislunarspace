# Unstable Mode Cancellation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A stationkeeping strategy for libration point orbits. It applies an impulsive delta-V along the unstable direction to cancel the unstable component of the trajectory error. The unstable mode is typically extracted via Floquet analysis from the state transition matrix of a reference orbit. Not selected for ARTEMIS due to the lack of a pre-generated reference orbit and sensitivity to lunar eccentricity and solar gravity perturbations.
