# Noise Estimator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Algorithm that estimates disturbance dynamics input noise in real time based on correlation between measured model error and prior input noise samples.

## Application Value

Noise estimators enable real-time estimation of disturbance dynamics input noise based on measurement model error correlation, improving navigation accuracy.
