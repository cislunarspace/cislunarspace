# Error Propagation Pattern

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Pattern describing how initial state errors propagate and amplify through orbital states over prediction time. Collinear libration point orbits exhibit fundamentally different error propagation from near-Earth satellites: errors grow linearly along the along-track direction for the latter, but exponentially along the unstable eigenvector of the state transition matrix for the former.

## Application Value

In the design and analysis of error propagation patterns, they can be used to optimize transfer schemes and reduce fuel consumption, to assess the accuracy ceiling of navigation systems and guide filter design, and to describe error propagation and perform sensitivity analysis.
