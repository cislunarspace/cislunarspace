# On/Off Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An intermittent orbital control strategy where thrust maneuvers are applied only when deviation exceeds a threshold, maintaining the orbit by canceling unstable components.

## Application Value

The design of control strategies directly affects spacecraft mission performance and lifespan. Reasonable control methods can ensure mission completion while minimizing propellant consumption.
