# State-Dependent Coefficient

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In SDRE control methods, the state-dependent coefficient matrices A(x) and B(x) when representing nonlinear systems in the form A(x)x + B(x)u. SDC parameterization is non-unique, allowing designers to optimize controller performance through selection.

## Application Value

在轨道控制律设计中，该方法通过优化推力方向和大小实现燃料消耗最小化，是深空任务的核心技术。
