# Error Transformation Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A mathematical tool in prescribed performance control that maps constrained tracking errors to an unconstrained space. The common logarithmic form Γ(ω) = ½·ln((1+ω)/(1-ω)) maps the normalized error ω ∈ (-1,1) to the entire real line, converting inequality constraints into an unconstrained optimization problem.

## Application Value

在航天器姿态和轨道控制中，该方法用于实现高精度跟踪和稳定保持. 通过设计合适的控制律，可以有效抑制外部扰动的影响，保证航天器在复杂动力学环境中的可靠运行.
