# Motion Primitive Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A finite set of representative trajectories extracted from a large set via clustering, supporting initial guess construction for complex trajectories.

## Application Value

该概念在地月空间任务设计中具有重要应用价值，涉及轨道设计、导航控制或动力学分析等多个方面，为地月空间探测任务提供理论支撑.
