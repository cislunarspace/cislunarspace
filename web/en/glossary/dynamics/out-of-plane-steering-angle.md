# Out-of-Plane Steering Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angular component of the thrust vector deviating from the instantaneous orbital plane, used to control out-of-plane motion. In three-dimensional transfers it generates orbital plane changes, which is critical for transitioning from planar to polar orbits.

## Application Value

This concept is applicable in cislunar space mission design, orbit optimization, and trajectory planning for spacecraft transfers and maneuver strategies.
