# SDC

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

State-Dependent Coefficient; matrix in SDRE control that parameterizes nonlinear systems, dependent on system state.

## Application Value

状态相关coefficient SDC is SDRE control中parameter化非线性system of matrix, 其取值依赖于system状态. is achieve 非线性system反馈线性化 of important 工具.
