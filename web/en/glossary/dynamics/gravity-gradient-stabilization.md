# Gravity Gradient Stabilization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Passive attitude stabilization method using gravity gradient torque to naturally stabilize spacecraft attitude

## Application Value

Gravity gradient stabilization provides passive attitude stability using the gravitational torque gradient, reducing active control requirements and propellant consumption.
