# Lie Transformation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A canonical transformation method in Hamiltonian systems that constructs a generating function G to simplify the original Hamiltonian. The paper uses this method to decouple hyperbolic directions from central directions.

## Application Value

This concept provides an important theoretical foundation for cislunar mission design. In practical engineering it can be applied to orbit design, mission planning, or control system analysis.
