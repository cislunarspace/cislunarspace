# Logistic Map

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A discrete dynamical system model describing population growth, with equation x_{n+1}=rx_n(1-x_n). This map is a classic paradigm for studying chaos, bifurcation, and the Feigenbaum constant.
