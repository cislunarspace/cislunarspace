# RKF7(8) Integrator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An adaptive step-size Runge-Kutta-Fehlberg method that uses a 7th-order formula to compute the solution and an 8th-order formula to estimate the error, automatically adjusting the step size. The paper uses RKF7(8) for numerical simulation of navigation constellation orbit determination and user spacecraft navigation, with a data sampling interval of 10 minutes.

## Application Value

Achieving adaptive step-size control through 7th-order solution computation and 8th-order error estimation, RKF7(8) balances numerical accuracy and computational efficiency in navigation constellation orbit determination and user spacecraft navigation simulation.
