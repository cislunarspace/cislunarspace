# Endpoint Mapping

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A nonlinear mapping from control functions to terminal states. The optimal control in minimum time control is a critical point of the endpoint mapping; its gradient condition yields Pontryagin's Maximum Principle.

## Application Value

The unique dynamical environment near the libration points offers special orbit options for cislunar missions.
