# Throttle Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In a multimode propulsion system, the function characterizing propellant mass flow rate variation with time. In the dual-mode electric propulsion system studied, throttle functions delta_P1 and delta_P2 take values of 0 or 1, determining the thruster on/off state. The optimal solution is derived from Pontryagin's Minimum Principle in the indirect optimization framework, exhibiting a bang-bang profile.
