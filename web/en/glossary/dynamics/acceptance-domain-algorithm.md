# Acceptance Domain Algorithm

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A criterion in landing guidance that determines whether an alternative landing site should replace the current target. Defined by a ternary exponential function of spacecraft altitude, deviation distance, and continuous deviation time: the new site is accepted when the function value exceeds a threshold, otherwise the previous target is retained. Analogous to simulated annealing, it prevents excessive landing-point oscillation during descent and reduces unnecessary maneuvers and fuel consumption.
