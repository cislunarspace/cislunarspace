# Linear Programming

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Mathematical optimization where the objective function and constraints are linear expressions, forming the basis of mixed-integer linear programming.

## Application Value

Linear Programming plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
