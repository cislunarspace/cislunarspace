# Attracting Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In nonlinear orbit control, the set of equilibrium points defined by b=0, containing the target set (global minimum) and several local extreme points (saddles or local maxima). The system convergence region is the intersection of the attracting set and invariant set.
