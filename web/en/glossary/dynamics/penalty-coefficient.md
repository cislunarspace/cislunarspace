# Penalty Coefficient

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A weighting factor in the optimal control performance index that balances the collision probability term against the fuel consumption term. A larger coefficient prioritizes safety, requiring more fuel to reduce collision probability; a smaller coefficient prioritizes fuel savings.

## Application Value

It provides the theoretical basis for precise spacecraft control and helps ensure mission reliability. This concept provides an important theoretical foundation for cislunar mission design. In practical engineering it can be applied to orbit design, mission planning, or control system analysis.
