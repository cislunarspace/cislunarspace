# Finite-Burn Pulse

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A control input model that simulates thruster operation as a fixed-duration pulse.

## Application Value

Thrust burning of finite duration as opposed to impulsive maneuvers, more closely matching actual engine operating characteristics.
