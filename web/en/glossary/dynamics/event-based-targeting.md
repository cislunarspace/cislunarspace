# Event-based Targeting

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The core mechanism of x-axis crossing control: instead of matching a reference state at a fixed time, the controller targets state components at the event where the trajectory crosses the xz-plane near perilune. This event-triggered rather than time-triggered paradigm does not inherently constrain phase, requiring additional measures to prevent along-track drift.

## Application Value

Event-based Targeting has practical applications in cislunar space mission design and analysis.
