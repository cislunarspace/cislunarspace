# Attainable Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The set of all states reachable from an initial condition using piecewise constant controls under given control constraints. Analysis of the structure of the attainable set is the basis for proving controllability.
