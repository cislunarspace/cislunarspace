# Zero-Order-Hold

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A control parametrization where the input remains constant between discretization nodes.

## Application Value

A zero-order hold discretizing continuous control signals, keeping control constant within each sampling period.
