# Minimum-Norm Update

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The solution method used in differential correction when the number of targeted state components is less than the control degrees of freedom: the velocity correction is computed as the minimum-norm solution that satisfies the targeting constraints.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
