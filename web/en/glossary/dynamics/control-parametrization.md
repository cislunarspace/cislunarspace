# Control Parametrization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method of representing continuous control as finite parameters (such as polynomial or Fourier coefficients), transforming the optimal control problem into a nonlinear programming problem.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
