# Battin-Giorgi Approach

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A nonlinear method for describing relative orbit motion between a chaser and a target spacecraft using a non-Keplerian reference orbit, without requiring linearizing approximations.

## Application Value

This term has significant practical applications in cislunar mission planning and execution.
