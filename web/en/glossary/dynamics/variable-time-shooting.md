# Variable-Time Shooting

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A shooting method that allows flight time to participate as a free variable in iterative correction.

## Application Value

在任务规划阶段用于评估不同推进方案的优劣 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
