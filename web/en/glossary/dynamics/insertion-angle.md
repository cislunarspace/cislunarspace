# Insertion Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle between the negative x-axis and the radial line connecting the Moon to the manifold insertion point in the xy-plane, describing the azimuth of the insertion point in the Moon-centered frame.


## Application Value

Correct reference frame selection is fundamental to orbital mechanics calculations; different mission phases may require switching between different reference frames.
