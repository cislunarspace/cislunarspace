# Actor-Critic Algorithm, AC

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A reinforcement learning framework where a critic network approximates the value function to evaluate the current policy, and an actor network updates policy parameters based on the value function gradient.

## Application Value

This method can be applied to solve optimization problems in cislunar missions, such as orbit transfer, fuel consumption minimization, or task scheduling.
