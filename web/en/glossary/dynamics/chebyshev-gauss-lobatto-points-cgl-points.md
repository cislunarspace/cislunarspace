# Chebyshev-Gauss-Lobatto Points, CGL Points (CGL点)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A node distribution strategy using cosine mapping to concentrate nodes near boundaries, used for time domain discretization to compensate the Runge effect, enabling use of higher-degree polynomials.

## Application Value

该方法利用角度观测数据可快速确定目标轨道，适用于初轨确定。该多项式逼近方法可用于高效表达轨道边界条件。
