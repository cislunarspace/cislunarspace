# High-Order Sensitivity Matrix, HOSM

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that constructs polynomial surrogate models via Taylor expansion to replace per-sample integration for reachable domain computation. It expands the state propagation function to a specified order at the initial state and evaluates high-dimensional integrals using weighted sums at finite sample points, avoiding the exponential computational scaling of Monte Carlo methods. The trade-off between accuracy and efficiency depends on the truncation order.
