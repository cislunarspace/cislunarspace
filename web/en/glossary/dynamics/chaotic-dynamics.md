# Chaotic Dynamics

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In cislunar space, the Moon's gravitational influence and three-body coupling produce nonlinear, non-integrable orbital behavior. Small perturbations in position or velocity can cause exponential divergence in state prediction, rendering classical two-body orbital elements ineffective. This is the core physical challenge for cislunar SSA.
