# Linear Programming (LP)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Mathematical optimization where the objective function and constraints are linear expressions, forming the basis of mixed-integer linear programming.

## Application Value

Linear programming is used in cislunar mission planning to solve fuel-optimal transfer trajectory design, constellation deployment scheduling, and observation resource allocation problems. The simplex method and its variants can find the global optimal solution of the objective function under linear constraints in polynomial time, with high computational efficiency and reliable convergence, making it a common tool in the preliminary design phase of space missions. Mixed-integer linear programming further introduces integer decision variables, enabling the handling of logical constraints and combinatorial optimization problems such as satellite mission mode selection and observation area allocation.
