# Maneuver Execution Error

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Magnitude and direction deviations during corrective maneuver execution, possibly modeled as fixed-magnitude random-direction errors.

## Application Value

Maneuver Execution Error represents magnitude and direction deviations during corrective maneuver execution. Modeling these errors as fixed-magnitude random-direction errors helps assess their impact on trajectory accuracy.
