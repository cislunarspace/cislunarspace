# Gauss-Lobatto Collocation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A collocation point selection scheme that places nodes at the endpoints and interior Gauss-Lobatto points. For n nodes, including n-2 interior nodes and 2 endpoints, it provides high-order accuracy.

## Application Value

该方法利用角度观测数据可快速确定目标轨道，适用于初轨确定。
