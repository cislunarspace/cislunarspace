# Kustaanheimo-Stiefel Transformation, KS Transformation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A coordinate transformation that regularizes the three-dimensional Kepler problem into a four-dimensional harmonic oscillator, eliminating collision singularities. Combined with modified Chebyshev-Picard iteration to enhance convergence domain of Picard iteration.

## Application Value

Regularizing three-body collision singularities, it expands the convergence domain when combined with modified Chebyshev-Picard iteration, an important tool for deep space transfer trajectory numerical computation.
