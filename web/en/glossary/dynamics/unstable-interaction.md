# Unstable Interaction

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The unstable interaction between rigid-body modes and certain flexible modes when actuators and sensors are non-collocated, manifesting as open-loop instability that requires phase or gain stabilization.

## Application Value

Unstable Interaction occurs between rigid-body modes and certain flexible modes when actuators and sensors are non-collocated, manifesting as open-loop instability that requires phase or gain stabilization. Understanding this phenomenon is critical for spacecraft attitude control design.
