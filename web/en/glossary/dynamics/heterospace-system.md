# Heterospace System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Refers to three-body systems governed by different primary bodies, such as the Sun-Earth system and the Earth-Moon system, which can be independently described but linked through invariant manifold connections.

## Application Value

In orbital mechanics analysis and mission design, this concept provides the theoretical basis for evaluating orbit characteristics and comparing design options, helping optimize orbit design parameters and improve mission cost-effectiveness.
