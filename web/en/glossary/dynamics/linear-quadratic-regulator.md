# Linear Quadratic Regulator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An optimal control method that minimizes the weighted sum of state deviation and control energy. It designs a state feedback gain matrix based on a linearized model, with control parameters determined by weighting matrices Q (state deviation) and R (control energy). It performs well near the linearized operating point but has limited accuracy for strongly nonlinear systems. In this paper, it serves as a baseline comparison for fixed-time sliding mode control.
