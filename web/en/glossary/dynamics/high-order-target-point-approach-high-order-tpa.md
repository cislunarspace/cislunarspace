# High-order Target Point Approach, High-order TPA

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A nonlinear Target Point Approach that computes high-order maneuver maps using Differential Algebra techniques, enabling fast calculation of fuel-optimal and error-robust corrective maneuvers via polynomial evaluation.


## Application Value

This dynamic method or concept has significant application value in cislunar space mission analysis, helping to understand and optimize spacecraft motion characteristics.
