# Universal variable

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Defined as x = √α χ, related to the difference in eccentric anomaly (elliptic) or hyperbolic anomaly (hyperbolic).

## Application Value

通用variable x = √α χ 统一关联偏近点角差和双曲偏近点角差, is 推导统一形式 of orbit动力学equation of important 工具. In 圆锥曲线orbit of 积分和optimize中has applicationvalue.
