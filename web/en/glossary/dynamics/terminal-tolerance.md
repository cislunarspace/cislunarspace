# Terminal Tolerance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Success criteria for a transfer mission, specifying that position and velocity deviations upon reaching the target orbit must fall below set thresholds. A2PPO training progressively tightens this tolerance via curriculum learning, from 5×10^-3 down to 1×10^-3.

## Application Value

Terminal Tolerance plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
