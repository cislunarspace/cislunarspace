# Runge Effect
> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The phenomenon of violent oscillations near interval endpoints when high-degree polynomial interpolation uses equally spaced nodes. Non-uniform node distributions such as CGL points mitigate this effect.

## Application Value

The Runge Effect plays a significant role in cislunar space mission design, analysis, and control. In orbital design, it can be leveraged for transfer trajectory optimization; in navigation and control, it improves mission execution precision and reliability; in system analysis, it facilitates deeper understanding of complex multi-body dynamical behavior, guiding mission planning and risk assessment.
