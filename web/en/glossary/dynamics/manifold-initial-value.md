# Manifold Initial Value

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The initial state given when computing an invariant manifold, obtained by offsetting a point on the Halo orbit along the stable or unstable eigenvector direction by a small amount.
