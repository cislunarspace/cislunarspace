# Differential Correction Principle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An iterative orbit design method that corrects initial states using the state transition matrix (Jacobian matrix) based on the deviation between terminal and initial orbital states, until the terminal state satisfies constraint conditions.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
