# Multi-Impulsive Staging Guidance, MISG

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Numerical impulsive planning algorithm inspired by launcher staging mass optimization, using product of exponential velocity increments as cost function and solving recursive optimal thrust directions.

## Application Value

This concept has application value in cislunar space research and engineering practice, helping to understand core principles of the field.
