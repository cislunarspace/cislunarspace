# Thrust Saturation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The state where the actual thrust output reaches the maximum thrust limit of the engine. The paper accounts for thrust saturation by imposing a two-norm constraint on the Δv at each prediction step, approximately implemented in the quadratic programming as an infinity-norm inequality.
