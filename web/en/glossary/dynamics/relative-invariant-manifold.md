# Relative Invariant Manifold

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Geometric structures in relative phase space invariant under dynamics, including stable, unstable, and center manifolds.

## Application Value

Relative invariant manifolds include stable, unstable, and center manifolds, forming the fundamental geometric structures for orbit design near libration points. Relative invariant manifolds can be used to design low-energy transfer orbits.
