# Practical Stability Region

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Regions near the Earth-Moon triangular libration points (L4, L5) where spacecraft can remain for extended periods. Although linear stability analysis shows triangular libration points are center-type stable, nonlinear effects create bounded stability regions where spacecraft can remain for decades.

## Application Value

Practical Stability Region plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
