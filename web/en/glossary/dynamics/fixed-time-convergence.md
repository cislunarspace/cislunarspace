# Fixed-Time Convergence

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A convergence property of control systems: the system state converges to the equilibrium within a fixed time, where the convergence time upper bound depends only on controller parameters and is independent of initial conditions. This is stronger than finite-time convergence (where convergence time depends on initial conditions). Fixed-time convergence is suitable for mission scenarios like formation deployment that require deterministic completion times.

## Application Value

This concept is essential for understanding motion characteristics in orbital design and control, and plays a vital role in mission success.
