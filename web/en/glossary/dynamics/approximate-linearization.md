# Approximate Linearization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique that linearizes nonlinear dynamics by Taylor expansion about a reference state (e.g., a reference orbit point), retaining only first-order terms to obtain an approximate linear model. It simplifies controller design but inevitably reduces control accuracy and applicable range, with errors increasing significantly far from the linearization point. This paper uses this method when designing the LQR controller.
