# Mixed-Integer Linear Programming

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A linear programming problem containing both continuous and integer variables, suitable for encoding combinatorial decisions and efficiently solved under branch-and-bound frameworks.


## Application Value

This control method can be applied to spacecraft attitude stabilization, orbit keeping, and maneuver trajectory optimization in cislunar space missions, improving mission execution flexibility and reliability.
