# Trigger Threshold

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In recursive simulation, the threshold used to determine whether a maneuver is warranted. A maneuver is computed and executed only when the state deviation exceeds the trigger threshold; combined with the targeting threshold, this creates a hysteresis effect that reduces unnecessary maneuvers.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
