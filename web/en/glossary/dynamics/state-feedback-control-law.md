# State Feedback Control Law

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A control law where the control quantity is expressed as a linear function of the state vector. Form: u_k = -K x_k, where K is the feedback gain matrix.
