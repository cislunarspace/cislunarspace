# State Predictor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Closed-loop predictor composed of the embedded model and noise estimator, predicting future states from past measurements, with uncertainty-based design.

## Application Value

The state predictor enables real-time state estimation and forecast by combining an embedded model with noise estimation, providing uncertainty-aware predictions for spacecraft navigation and control.
