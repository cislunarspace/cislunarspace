# Polar Coordinate Parameters

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Parameters defined in a polar coordinate system centered at the midpoint of the initial position vector, with unit vectors along the initial position direction and the transfer orbit plane normal as basis vectors, effectively reducing the infeasible region in the input parameter space and improving surrogate model accuracy.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
