# Targeting Threshold

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The tolerance used within the controller for convergence judgment. In PC-SCoP, explicitly given as constraint bounds, replacing the non-intuitive weight parameter in differential correction, and can be derived directly from mission requirements.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
