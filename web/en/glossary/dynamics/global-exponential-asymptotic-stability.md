# Global Exponential Asymptotic Stability

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A stability property where the system state converges to the equilibrium at an exponential rate for any initial condition. The paper proves via Lyapunov analysis that the backstepping sliding mode control law achieves this for both position and velocity errors globally.

## Application Value

该稳定性分析方法可用于设计能保证误差指数收敛的控制器。
