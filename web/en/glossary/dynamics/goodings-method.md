# Gooding's Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The efficient and robust Lambert algorithm by Gooding (1990), one of the most widely used Lambert solvers, used as benchmark in this paper.

## Application Value

Gooding's method is a numerical algorithm for solving Lambert's problem, featuring high precision and wide convergence domain. In orbit design tasks such as Lambert problem solving and preliminary orbit determination, Gooding's method provides reliable velocity increment calculation results and serves as a fundamental algorithm in orbital mechanics.
