# Mixed Method / Hybrid Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A class of trajectory optimization methods. Uses the optimal control law derived from the indirect method without including other optimality conditions, and solves the problem via parameter optimization. Combines the control law accuracy of the indirect method with the solving convenience of the direct method.

## Application Value

In the design and analysis of mixed/hybrid methods, it can be used to optimize transfer schemes and reduce fuel consumption. It provides the theoretical basis for precise spacecraft control and helps ensure mission reliability. Combined with numerical optimization algorithms, it enables high-performance trajectory planning.
