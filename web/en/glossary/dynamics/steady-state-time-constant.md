# Steady-State Time Constant

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In steady-state Kalman filtering, the ratio coefficient between covariance matrix elements and sampling time, used to simplify model-noise parameter q determination

## Application Value

This concept is important for understanding the dynamics and characteristics relevant to cislunar space missions.
