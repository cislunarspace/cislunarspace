# Solar Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle β between the Earth-Moon line and the ecliptic, determining the positions and Hamiltonian values of equivalent libration points. Solar phase affects transportation tube wall deformation and transiting trajectory distribution, serving as a key parameter for time periodicity in SBCM.

## Application Value

在太阳相位的设计与分析中，可用于优化转移方案，减少燃料消耗 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
