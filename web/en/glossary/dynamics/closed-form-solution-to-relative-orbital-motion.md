# Closed-form Solution to Relative Orbital Motion

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Analytical solution to relative orbital motion, expressed as functional relationships between position vector r and velocity vector v with initial conditions (Δr, Δv) and the chief's orbital elements. The paper obtains closed-form solutions by reducing the relative motion problem to the Kepler problem via tensor methods, applicable to any chief and deputy orbit (elliptic, parabolic, hyperbolic).

## Application Value

在轨道力学分析和任务设计中，This概念为轨道特性评估和方案比选provides理论依据，有助于优化轨道设计参数，提高任务经济性。
