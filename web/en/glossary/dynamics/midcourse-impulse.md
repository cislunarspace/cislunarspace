# Midcourse Impulse

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Impulse applied mid-transfer to improve non-optimal two-impulse trajectories. When the primer vector magnitude exceeds 1, adding a midcourse impulse can reduce propellant consumption.

## Application Value

在中途脉冲的分析中，研究者首先需要建立描述航天器运动的数学模型，通过数值积分或解析方法求解该术语所对应的动力学方程，进而评估航天器在不同初始条件下的运动特性。
在实际任务中，中途脉冲直接影响转移轨道的燃料消耗和任务窗口选取，需要结合轨道优化算法进行详细设计。
在实际任务中，需要结合数值仿真和解析方法对中途脉冲进行分析验证，确保设计方案满足任务约束和性能指标。
