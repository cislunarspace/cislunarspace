# Inverse Polynomial Shape Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A class of shape functions for low-thrust trajectory design. They describe the trajectory geometry using inverse polynomials (reciprocal forms of time polynomials), providing initial guesses for subsequent numerical optimization during the preliminary trajectory design phase.

## Application Value

Inverse Polynomial Shape Function plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
