# Skew-symmetric Tensor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A tensor satisfying ~ω^T = -~ω, in one-to-one correspondence with angular velocity vectors. Describes angular velocity in the Darboux equation.

## Application Value

斜对称张量用于表示向量的叉乘运算，在刚体动力学中表示角速度与位置矢量的关系。
