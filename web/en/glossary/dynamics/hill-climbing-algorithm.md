# Hill-Climbing Algorithm

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A local search optimization algorithm that iteratively improves from an initial solution by moving in the direction of steepest ascent until reaching a local optimum. The paper uses the dynamic hill-climbing algorithm (steepest descent) to refine the initial guesses found by the genetic algorithm until converging to a local minimum.

## Application Value

在轨道控制律设计中，该方法通过优化推力方向和大小实现燃料消耗最小化，是深空任务的核心技术。
