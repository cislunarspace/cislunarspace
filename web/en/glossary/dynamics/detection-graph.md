# Detection Graph

## Definition

A Detection Graph is a graph-based model in space situational awareness used to describe the coverage and detection relationships between sensor networks and space objects. Nodes in the graph represent sensors or space targets, while edges indicate the observability of targets by sensors. This model is widely applied in cislunar space object tracking, sensor resource scheduling, and orbit catalog maintenance.
