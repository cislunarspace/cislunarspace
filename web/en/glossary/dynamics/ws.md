# Stable Manifold

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In manifold theory, the stable manifold of a periodic orbit consists of all phase trajectories that asymptotically approach it. A spacecraft on the stable manifold naturally approaches the target orbit without external energy input, making it a core tool for low-energy transfer trajectory design. The paper exploits the property that stable manifolds of L1-centered HLOs approach Earth closely, using them as initial estimates for LEO departure transfer trajectories.

## Application Value

This concept has important application value in cislunar space research and mission design.
