# Dynamic Feasibility

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Whether a geometrically defined curve can be driven by a physically realizable thrust history. For exponential sinusoids, the feasibility condition is |k₁k₂²| < 1. The paper derives a feasibility criterion in terms of the initial flight-path angle γ₁: when the discriminant Δ > 0, γ₁ between the two roots tan γ₁m and tan γ₁M yields feasible trajectories. Δ < 0 means no feasible trajectory existsInParameter class.

## Application Value

Dynamic feasibility analysis determines whether geometrically defined trajectories can be executed with physically realizable thrust, essential for trajectory validation.
