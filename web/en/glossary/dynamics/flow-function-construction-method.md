# Flow Function Construction Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A novel method for computing periodic orbits by constructing flow functions using CRTBP symmetry, solving for intersections with the x-axis; can obtain numerical solutions when approximate analytical solutions fail.

## Application Value

Flow Function Construction Method plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
