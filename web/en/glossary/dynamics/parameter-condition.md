# Parameter Condition

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Transversality condition satisfied by unknown time parameters (initial and final epochs) in optimal control problems.

## Application Value

参数条件是系统参数必须满足的约束条件，设计师在参数优化中确保满足参数条件以获得物理可行的解。
