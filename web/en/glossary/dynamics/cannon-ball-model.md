# Cannon Ball Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A simplified spacecraft solar radiation pressure model that treats the spacecraft as a sphere with constant cross-sectional area and uniform reflectivity. In libration point orbit stationkeeping, this model estimates SRP accelerations; its key parameter (coefficient of reflectivity, Cr) can be updated from navigation data to improve model accuracy. ARTEMIS P2 saw significantly reduced stationkeeping costs after updating Cr.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
