# Initial Conjugate Variable Values

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The unknown values of conjugate (adjoint) variables at the initial time in a two-point boundary value problem. The paper has seven initial conjugate variable values (lambda1 through lambda7), where the first six correspond to three velocity and three position state variables and the seventh corresponds to the mass state variable. These initial values cannot be determined directly from initial conditions and must be found through parameter optimization with the shooting method. Once obtained, together with the known initial state values, real-time integration of the state and adjoint equations enables optimal soft landing guidance.
