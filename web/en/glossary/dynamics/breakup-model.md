# Breakup Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A mathematical model describing the generation patterns of fragments during spacecraft breakup events. The NASA standard breakup model specifies statistical characteristics including fragment size distribution, surface-to-mass ratio distribution, and separation velocity distribution (lognormal). Separation velocity directions are uniformly distributed across all spatial directions. The breakup model is an input condition for debris cloud evolution analysis, determining the initial state of the debris cloud.
