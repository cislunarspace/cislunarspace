# Scale Transformation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A transformation that derives new solutions of the same family from known solutions: if r_j(t) is a solution, then ρ_j(t)=k²r_j(t/k³) is also a solution, with energy inversely proportional to k² and angular momentum proportional to k.

## Application Value

尺度变换通过调整问题中物理量的量级改善数值计算的稳定性，优化算法设计师利用尺度变换提高收敛速度和精度。
