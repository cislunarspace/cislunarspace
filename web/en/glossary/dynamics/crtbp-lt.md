# Circular Restricted Three-Body Problem with Low-Thrust, CRTBP-LT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An extension of the Circular Restricted Three-Body Problem (CRTBP) that incorporates continuous low-thrust engine dynamics. The system state is augmented to seven dimensions (position, velocity, mass), with control variables including the engine throttle parameter and thrust direction unit vector. In the nondimensional rotating frame, the acceleration terms include pseudopotential gradient, Coriolis acceleration, and thrust acceleration.

## Application Value

The 圆形限制性三体问题小推力扩展 concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
