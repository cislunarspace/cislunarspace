# Column Generation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A decomposition technique for large-scale integer programming that progressively introduces new columns (variables) to approximate the full problem, suitable for large-scale combinatorial optimization.
