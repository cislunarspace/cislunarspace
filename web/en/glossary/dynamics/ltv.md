# Linear Time-Varying System, LTV System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A linear system whose state-space matrix A(t) varies with time: dx/dt = A(t)x + Bu. Unlike linear time-invariant (LTI) systems, the state transition matrix of an LTV system cannot be reduced to a matrix exponential and must be computed by numerical integration. In the restricted three-body problem, the linearized relative motion model is an LTV system.

## Application Value

The 线性时变系统 concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
