# Positivity Condition

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The condition ensuring that the angular rate in the shape-based method takes a positive value (the positive root). This requires a > 0 and a non-negative discriminant, where a is related to the flight-path angle and its partial derivatives. Together with feasibility conditions, it ensures the resulting trajectory is physically achievable.

## Application Value

Constraint conditions define the feasible region for trajectory optimization, including boundary conditions and path constraints.
