# Control Curve (U_i)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A curve describing the range over which the low-thrust Hamiltonian varies with the thrust angle α on a low-thrust arc, H_lt = H_nat,i − a_lt(x_i cosα + y_i sinα).

## Application Value

The design of control strategies directly affects a spacecraft's mission performance and lifetime; a sound control method can minimize propellant consumption while still ensuring mission completion.
