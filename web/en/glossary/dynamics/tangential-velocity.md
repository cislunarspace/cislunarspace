# Tangential Velocity

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The velocity component perpendicular to the position vector. In WSB initial conditions, velocity is taken in the tangential direction with magnitude determined by periapsis geometry.

## Application Value

该概念在地月空间任务设计中具有重要应用价值，涉及轨道设计、导航控制或动力学分析等多个方面，为地月空间探测任务提供理论支撑.
