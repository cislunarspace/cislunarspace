# Tent Map

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A simple chaotic map that produces exponentially diverging nearby orbits through stretching and folding operations. The logistic map can be transformed into the tent map for specific parameter values.
