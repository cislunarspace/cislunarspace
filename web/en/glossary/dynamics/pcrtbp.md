# Planar Circular Restricted Three-Body Problem, PCRTBP

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A dynamics problem where two primary bodies move in coplanar circular orbits, and the spacecraft moves in the same plane under the gravitational action of both.

## Application Value

This provides a fundamental theoretical framework for cislunar dynamics modeling and analysis, serving as a mathematical tool for studying spacecraft motion.
