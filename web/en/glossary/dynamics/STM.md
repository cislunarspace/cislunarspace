# State Transition Matrix, STM

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A first-order approximation of a linear time-varying system that describes how initial perturbations propagate over time; the core tool for Floquet theory, manifold computation, and sensitivity analysis.

## Application Value

A matrix describing linear time-varying system state propagation, core for calculating orbit deviation propagation and sensitivity analysis.
