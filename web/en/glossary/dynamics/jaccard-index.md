# Jaccard Index

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A metric for measuring similarity between two sets, defined as the ratio of intersecting to union elements. The paper introduces a modified version for multisets with repeated elements to handle cases where the same orbital family appears multiple times in an architecture (e.g., multiple GEO observers), used in K-Medoids clustering analysis.
