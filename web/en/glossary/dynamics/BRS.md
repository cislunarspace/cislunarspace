# Backward Reachable Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The set of all states at time t that free-drift into an avoid set after a specified duration.

## Application Value

The set of all reachable states computed backward from target states, used to analyze the feasible region and safety boundaries of orbital maneuvers.
