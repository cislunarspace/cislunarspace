# Sequential Quadratic Programming Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Sequential quadratic programming, which solves a sequence of quadratic programming subproblems to progressively approximate the optimal solution of a nonlinearly constrained optimization problem, used in the lower-layer local search of the two-layer optimization algorithm.
