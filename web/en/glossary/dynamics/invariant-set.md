# Invariant Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In nonlinear orbit control, the set of points where system state remains unchanged when non-Keplerian acceleration is zero. Contains four subsets: two unstable equilibria (saddles), one unstable equilibrium (local maximum), and the target set (global minimum).

## Application Value

The invariant set theory provides a rigorous mathematical framework for nonlinear orbit control, defining the collection of states that remain unchanged under zero non-Keplerian acceleration.
