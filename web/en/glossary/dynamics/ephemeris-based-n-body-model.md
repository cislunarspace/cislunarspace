# Ephemeris-Based N-Body Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A high-fidelity orbital dynamics model with the Moon as the central body and Earth, Sun, Jupiter, etc. as perturbing bodies. It uses NAIF SPICE software and DE438 ephemeris files for instantaneous body positions. Unlike the analytical simplification of CR3BP, it faithfully represents multi-body gravitational and solar radiation pressure perturbations.

## Application Value

Ephemeris-Based N-Body Model plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
