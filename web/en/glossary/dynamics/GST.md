# Gaussian Smoothing Technique, GST

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A discontinuity-approximation method based on the Gaussian error function (erf). It uses parameterized S-shaped curves to progressively approximate discontinuous signum functions by gradually reducing the smoothing parameter rho, thereby improving convergence of indirect optimization methods and avoiding local optima. Unlike the generalized Gaussian smoothing homotopy method, GST directly approximates discontinuities with erf rather than performing time-domain convolution on the system.

## Application Value

Gaussian smoothing techniques reduce noise effects, fundamental methods in data processing and orbit filtering.
