# Dynamical Noise

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The process noise covariance matrix describing dynamics model uncertainty, used to absorb unmodelled acceleration disturbances. Its magnitude directly affects the filter's state estimation accuracy.

## Application Value

在自主导航滤波算法中，该方法通过自适应调整滤波器参数提高收敛速度，适用于地月空间的实时定轨任务。
