# Dual-Layer Iterative Algorithm

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An iterative algorithm by Sukhanov and Prado that simultaneously corrects initial and final position vectors based on reference orbits, using inner and outer loops for propagation and constraint satisfaction respectively.

## Application Value

This concept is applicable in cislunar space mission design, orbit optimization, and trajectory planning for spacecraft transfers and maneuver strategies.
