# Optimal Multi-Impulse, Opt-MI

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Strategy that optimizes both the execution times and magnitudes of N impulses using linear programming with l¹-norm of total impulse as fuel consumption proxy.

## Application Value

This theory provides a mathematical basis for multi-objective optimization in cislunar missions, finding optimal solutions under constraints.
