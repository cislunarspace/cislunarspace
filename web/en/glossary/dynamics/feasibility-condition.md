# Feasibility Condition

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of constraints in shape-based methods ensuring physically meaningful solutions. These include: positive angular rate (ensuring trajectory evolves forward in time), bounded thrust acceleration (not exceeding actual propulsion system capability), and a non-negative radicand in the angular rate expression (ensuring real-valued solutions).

## Application Value

在低推力轨道优化中，该推进方式可通过长时间持续加速实现低能量转移，比高推力系统更具燃料经济性。
