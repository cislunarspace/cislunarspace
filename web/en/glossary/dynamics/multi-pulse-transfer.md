# Multi-Pulse Transfer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A control scheme where multiple maneuver points are selected along a reference trajectory, and velocity impulses are applied at each point so that the deputy transfers segment by segment. Compared to continuous thrust, multi-pulse transfer better matches conventional chemical propulsion and allows trade-offs between fuel consumption and transfer time by adjusting maneuver duration and the number of points.

## Application Value

Multi-Pulse Transfer has practical applications in cislunar space mission design and analysis.
