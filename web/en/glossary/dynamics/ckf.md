# Cubature Kalman Filter

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Sigma point Kalman filter based on spherical-simplex cubature rule

## Application Value

Cubature Kalman Filter plays an important role in orbital dynamics and attitude control, serving as a critical tool for analyzing spacecraft motion characteristics. Research on this concept enables optimization of orbit transfer schemes and improvement of control system performance.
