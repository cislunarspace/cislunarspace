# Battin-Giorgi Approach, BG Approach

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A nonlinear method for describing relative orbit motion between a chaser and a target spacecraft using a non-Keplerian reference orbit, without requiring linearizing approximations.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
