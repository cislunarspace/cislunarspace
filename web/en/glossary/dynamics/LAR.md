# Least Angle Regression

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An adaptive coefficient regression method used in adaptive polynomial chaos expansion to achieve sparsity, constructing a sparse expansion by progressively selecting basis functions most correlated with the current residual.

## Application Value

An efficient method for variable selection and sparse regression, suitable for selecting key parameters from large candidate sets.
