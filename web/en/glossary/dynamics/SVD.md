# Singular Value Decomposition, SVD

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A matrix decomposition that yields a diagonal matrix of singular values and two unitary matrices; the left and right singular vectors provide principal stretching directions at initial and final times respectively, with singular values giving stretching magnitudes.

## Application Value

Orthogonal decomposition of a matrix obtaining eigenvalues and singular values, important for analyzing dynamical stability and error propagation.
