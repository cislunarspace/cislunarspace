# Lagrangian Relaxation Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An integer programming solution method that incorporates complicating constraints into the objective via Lagrange multipliers, decoupling the original problem into easier-to-solve subproblems.

## Application Value

In the field of dynamics, Lagrangian Relaxation Method is a key element for understanding and analyzing system behavior. This concept is widely used in spacecraft trajectory design, dynamics modeling, and mission planning, providing theoretical support for engineering practice.
