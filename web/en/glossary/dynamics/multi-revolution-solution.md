# Multi-Revolution Solution

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Solution to Lambert's problem where the time of flight exceeds one orbital period with multiple complete revolutions.

## Application Value

When flight time exceeds a single orbit period, multi-revolution Lambert problems must be solved. The number of solutions grows exponentially with revolution count, a key issue for long-time-of-flight transfer missions.
