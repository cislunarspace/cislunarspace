# Inverse State Transition Tensor, ISTT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

High-order state transition tensors obtained by backward integration from the terminal time. When multiplied with forward STTs, they yield state transition relationships for arbitrary intermediate segments without re-integration, suited to scenarios where correction times change frequently.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
