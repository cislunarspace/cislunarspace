# Attractor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set in phase space toward which a dynamical system evolves. For conservative systems attractors may be stable periodic orbits or invariant tori; for dissipative systems attractors are usually stable equilibrium points or strange attractors.


## Application Value

This orbital design method can be applied to transfer trajectory design, orbit keeping, and mission planning in cislunar space missions, improving spacecraft performance and mission flexibility.
