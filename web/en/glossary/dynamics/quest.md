# QUEST

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Quaternion Estimation algorithm that solves the Wahba problem via singular value decomposition to directly obtain the optimal attitude quaternion.

## Application Value

四元数estimate法(QUEST)through 奇异值分解solve Wahba problem, is 姿态estimate of 经典算法. In spacecraft姿态determine中has 广泛application.
