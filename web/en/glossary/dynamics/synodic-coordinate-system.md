# Synodic Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A coordinate system rotating with the primaries, in which the primaries remain fixed. The transformation from the inertial to the rotating frame eliminates explicit time dependence from the equations, yielding the Jacobi integral.

## Application Value

描述系统状态随时间的变化规律，是轨道预报的基础 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
