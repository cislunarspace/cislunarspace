# Multi-objective Optimization Problem, MOOP

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A mathematical programming problem that optimizes multiple objective functions simultaneously. Its solution is not a single optimum but a Pareto front composed of Pareto-optimal solutions, reflecting the trade-offs and constraints among objectives.

## Application Value

The solution to a multi-objective optimization problem is a set of Pareto-optimal solutions. Designers can trade off multiple objectives such as velocity increment, transfer duration, and mission windows in orbit optimization to find the scheme that best meets mission requirements.
