# Adjoint Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that constructs the dual system of an original system and uses the dual system's impulse response to compute optimal control inputs. Applicable to time-varying linear systems, transforming multi-impulse maneuver design problems into pseudoinverse solutions.
