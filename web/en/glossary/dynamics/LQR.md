# Linear Quadratic Regulator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An optimal control law for linear systems based on quadratic performance index. It minimizes a weighted sum of state error and control input quadratics, yielding feedback control gains via the Riccati difference equation.

## Application Value

The linear quadratic regulator is optimal control for linear systems with quadratic performance indices, the foundation of modern control theory.
