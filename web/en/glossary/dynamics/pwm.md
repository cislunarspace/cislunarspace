# Pulse Width Modulation, PWM

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique that controls average thrust by adjusting the duty cycle of pulse signals. The thruster is turned on for a portion of each cycle and off for the remainder; the ratio of on-time to period determines the average thrust level.

## Application Value

This concept has application value in cislunar space research and engineering practice, helping to understand core principles of the field.
