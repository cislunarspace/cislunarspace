# Stumpff Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Auxiliary functions used in the universal variable method, defined as c₂(ψ) and c₃(ψ). Calculated using trigonometric functions for ψ≥0 and hyperbolic functions for ψ<0, they unifiedly express the time-position relationship in Kepler's equation.
