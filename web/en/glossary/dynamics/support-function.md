# Support Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Linearly independent basis functions in TFC constrained expressions used to embed constraints, mapping constraint conditions to functional coefficients.

## Application Value

supportfunction is TFC 受控表达式中used for 嵌入constraint of 线性无关基function, 承担willconstraintcondition映射到泛函coefficient of mission. In constraintprocess中has important role.
