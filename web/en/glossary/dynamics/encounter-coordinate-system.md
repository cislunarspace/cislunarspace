# Encounter Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A coordinate system defined at the instant of nominal closest approach, with origin at the secondary object, y-axis along the relative velocity direction, x-axis pointing to the primary object, and z-axis completing the right-handed triad.

## Application Value

This concept is used in orbital analysis and has significant impact on mission design.
