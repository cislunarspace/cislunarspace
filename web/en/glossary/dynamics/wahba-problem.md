# Wahba Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Maximum likelihood estimation problem of determining rigid-body attitude from a set of direction observations, equivalent to finding the attitude matrix that minimizes a loss function.

## Application Value

在态势感知系统中，该观测方法为低轨空间目标监视提供技术手段，是空间交通管理的数据来源。
