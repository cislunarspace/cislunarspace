# Hanning Window

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A time-domain truncation function used to reduce spectral leakage, given by H(t)=1/2 - 1/2 cos(2πt/N).

## Application Value

Based on its definition, a time-domain truncation function used to reduce spectral leakage, given by h(t)=1/2 - 1/2 cos(2πt/n)..
