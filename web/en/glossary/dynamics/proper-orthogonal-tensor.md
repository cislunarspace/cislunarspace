# Proper Orthogonal Tensor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A tensor satisfying R·R^T=I and det(R)=1, constituting the special orthogonal group SO(3). Used to describe frame rotations in relative motion analysis.
