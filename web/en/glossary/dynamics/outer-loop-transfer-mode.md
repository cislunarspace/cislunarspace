# Outer-Loop Transfer Mode

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A phasing transfer mode in which the transfer orbit lies outside the NRHO (farther from the Moon). It is more fuel-efficient when the chaser has a phase lead, because the larger orbital radius yields a longer period, allowing the chaser to wait for the target to catch up.

## Application Value

When the chaser spacecraft has a phase lead over the target, the outer-loop transfer mode is more fuel-efficient because the larger orbital radius provides a longer period, allowing the chaser to "take the long way" and wait for the target to catch up.
