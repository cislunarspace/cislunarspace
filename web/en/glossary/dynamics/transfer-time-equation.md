# Transfer time equation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The equation expressing transfer time as a function T(x) of the universal variable x; the core equation iterated upon in Lambert solvers.

## Application Value

在转移时间方程的分析中，可用于轨道传播和机动设计，帮助工程师评估航天器在不同动力学环境下的运动特性 该概念为地月空间任务设计提供了理论基础，尤其在平动点轨道设计和低能转移分析中具有重要应用价值 利用转移时间方程进行轨迹优化，可以有效降低任务燃料消耗，提高任务经济效益 在任务设计中，转移时间方程的分析有助于理解航天器在复杂引力场中的行为，指导轨道保持策略的制定
