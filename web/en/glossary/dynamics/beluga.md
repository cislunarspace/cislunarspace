# beluga

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An open-source Python package for optimal control and trajectory optimization, providing sparse collocation methods for solving two-point boundary value problems. In the paper, it is used for the cooperative agent's transfer trajectory optimization, solving a bi-objective optimal control problem (minimizing L2-norm thrust and apparent magnitude) via indirect methods.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
