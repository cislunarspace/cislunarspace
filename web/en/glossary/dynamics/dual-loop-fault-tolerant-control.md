# Dual-Loop Fault Tolerant Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A fault-tolerant attitude control method with inner-outer dual-loop structure. The inner loop achieves rapid attitude stabilization while the outer loop performs fault detection and isolation. When an actuator fault is detected, the outer loop switches control strategy to maintain normal operation under fault conditions.

## Application Value

This concept is used in orbital analysis and has significant impact on mission design.
