# Reaction Wheel Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Attitude control via angular momentum exchange using reaction wheels.

## Application Value

Reaction wheel control provides precise attitude control via angular momentum exchange, commonly used in Earth observation and communication satellites.
