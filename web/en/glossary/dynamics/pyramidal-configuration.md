# Pyramidal Configuration

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Layout of four reaction wheel axes pointing to the four vertices of a regular tetrahedron with the origin as the apex, enabling three-axis attitude control while avoiding singularities.

## Application Value

Four reaction wheels arranged in a regular tetrahedral configuration enable three-axis attitude stabilization while avoiding singularity issues inherent in traditional wheel configurations. This approach has broad application prospects in attitude-agile satellites and deep space probes.
