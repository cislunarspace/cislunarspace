# Target Point, TP

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Designated positions along the reference orbit at future times in TPA, used to construct the cost function and compute position deviations.

## Application Value

The target position point for orbital transfer, the terminal condition determining transfer endpoint and orbit insertion geometry.
