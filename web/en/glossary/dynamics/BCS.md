# Bayesian Compressive Sensing

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A sparse coefficient regression method for adaptive polynomial chaos expansion that uses a Bayesian inference framework to automatically select sparse terms.

## Application Value

Bayesian compressive sensing combines sparse representation with Bayesian inference, recovering complete signals from few observations, suitable for resource-constrained exploration missions.
