# System Translation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique to directly translate periodic orbits and transfer trajectories computed in one three-body system to another by continuously varying the mass parameter, without regenerating orbits and manifolds in the new system.
