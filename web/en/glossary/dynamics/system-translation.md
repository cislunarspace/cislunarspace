# System Translation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique to directly translate periodic orbits and transfer trajectories computed in one three-body system to another by continuously varying the mass parameter, without regenerating orbits and manifolds in the new system.

## Application Value

This concept is of significant value in cislunar orbit design, navigation control, and mission analysis; understanding its essence helps master the core knowledge of related fields.
