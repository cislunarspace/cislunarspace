# NASA Standard Break-up Model, SBM

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A statistical debris model developed by NASA based on actual explosion and collision breakup event databases, providing distribution laws for fragment size, area-to-mass ratio, and ejection velocity. The paper uses an improved POEM version that ensures mass and momentum conservation.

## Application Value

NASA's statistical debris model based on actual breakup events, providing distributions of fragment size, area-to-mass ratio, and ejection velocity, used for assessing consequences of breakup events.
