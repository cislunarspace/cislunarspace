# Birkhoff Equations

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A reformulation of the circular restricted three-body problem that replaces six state variables with five new ones (x, y, z, γ, νz), eliminating velocity magnitude via the Jacobi integral. In the 3D Birkhoff equations, γ is the velocity azimuth angle and νz is the velocity component perpendicular to the x-y plane. This equation set has a concise form convenient for numerical integration and manifold computation.
