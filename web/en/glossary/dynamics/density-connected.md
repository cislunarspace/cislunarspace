# Density-Connected

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In DBSCAN, two points are density-connected if there exists a sequence of core points where each point lies in the neighborhood of the next core point in the sequence.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
