# Control Weighting Matrix

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A symmetric positive definite matrix in LQR used to weigh control effort, determining the relative cost of control.

## Application Value

This control method is suitable for attitude and orbit control of cislunar spacecraft, enabling precise maneuvers and stationkeeping.
