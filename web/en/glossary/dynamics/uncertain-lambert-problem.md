# Uncertain Lambert Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A Lambert problem where input parameters such as initial position vector, terminal position vector, and flight time are uncertain, so the corresponding initial and terminal velocities are no longer deterministic values but random variables with known distributions.

## Application Value

This术语在地月空间任务的设计、分析和控制中具有important应用价值，为相关技术领域的研究和工程实践provides理论支撑。
