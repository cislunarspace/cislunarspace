# Numerical integration (orbit propagation)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Step-by-step numerical solution of the spacecraft equations of motion to obtain state vectors at discrete times, using methods such as Runge-Kutta or Gauss-Jackson.

## Application Value

该概念是分析地月空间动力学行为的基础工具。在轨道设计和任务分析中具有重要应用价值。
