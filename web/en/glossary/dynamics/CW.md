# Clohessy-Wiltshire Equations

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of linearized equations describing the relative motion of a chaser spacecraft relative to a target in a two-body periselene frame. Near the periselene, lunar gravity dominates, and these equations can be used to approximately describe relative motion.

## Application Value

Linearized equations describing relative motion in a periselene frame, approximately valid near lunar periselene where lunar gravity dominates, foundational for formation flying and rendezvous relative navigation.
