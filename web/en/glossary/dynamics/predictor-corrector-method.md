# Predictor-Corrector Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An iterative algorithm that first estimates an initial guess via prediction, then refines it via differential correction.

## Application Value

在预测矫正法的设计与分析中，可用于优化转移方案，减少燃料消耗 为状态估计提供概率框架，提高跟踪精度。
