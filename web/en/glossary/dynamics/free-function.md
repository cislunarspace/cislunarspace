# Free Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In the Theory of Functional Connections, a function containing no constraint information, expressed as a linear combination of basis functions. Its coefficients are estimated through least-squares and root-finding algorithms, allowing the entire function to satisfy constraints while fitting the true trajectory.
