# Jet Transport, JT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An automatic differentiation technique that uses truncated Taylor polynomial algebra to compute high-order derivatives of nonlinear functions, enabling explicit high-order polynomial formulations of control laws.

## Application Value

An automatic differentiation technique computing high-order derivatives via truncated Taylor polynomial algebra, obtaining explicit high-order polynomial forms of control laws.
