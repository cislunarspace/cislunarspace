# Particle Swarm Optimizer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A swarm intelligence optimization algorithm that simulates bird flock foraging behavior, using individual historical optimum and global optimum information to guide the search, employed for initial guess in solving two-point boundary value problems.

## Application Value

A global optimization algorithm simulating bird flock foraging behavior, suitable for solving complex orbit design problems.
