# Fixed-Point Homotopy

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A homotopy function construction method. Sets the initial homotopy problem as G(y) = y - y₀, where y₀ is a known initial guess. The homotopy function is H(y, κ) = κF(y) + (1-κ)(y - y₀). When κ = 0, the solution is exactly y₀; as κ increases, it approaches the original problem. Does not depend on the specific form of the original problem, making it broadly applicable.

## Application Value

This concept is essential for understanding motion characteristics in orbital design and control, and plays a vital role in mission success.
