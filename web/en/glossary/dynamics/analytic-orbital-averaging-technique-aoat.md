# Analytic Orbital Averaging Technique, AOAT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A semi-analytic trajectory propagation method that computes per-revolution orbital element increments using analytic approximations of integrals over eccentric anomaly, then propagates revolution by revolution. It rapidly propagates hundreds to thousands of revolutions in low-altitude orbits with J₂ and shadowing effects, with accuracy suitable for preliminary design.

## Application Value

Based on its definition, a semi-analytic trajectory propagation method that computes per-revolution orbital element increments using analytic approximations of integrals over eccentric anomaly, then propagates revolution by r.
