# Indirect Phasing

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A phasing method that uses libration point orbits (such as Lyapunov orbits) and their invariant manifolds to construct transfer trajectories for phase adjustment. The spacecraft transfers to the libration point orbit, accumulates phase difference through period differences or manifold transfers, then returns to the original orbit.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
