# Cubic Polynomial Vertical Guidance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Models the spacecraft altitude as a cubic polynomial function of time to simplify vertical motion control during landing. Requires the spacecraft to be stationary relative to the lunar surface at the start of this phase, with the main engine thrust controlling altitude.
