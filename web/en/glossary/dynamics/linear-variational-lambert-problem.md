# Linear Variational Lambert Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The variational Lambert problem that obtains the mapping from given position variations to velocity variations near a nominal orbit in first-order linear approximation.

## Application Value

The linear variational Lambert problem maps position variations to velocity variations near nominal orbits, useful for covariance analysis and navigation filter design.
