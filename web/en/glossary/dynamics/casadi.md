# CasADi

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An open-source optimization framework for constructing and solving nonlinear programming problems. A2PPO's direct collocation baseline uses CasADi with the IPOPT solver at a tolerance of 10^-10 to obtain high-accuracy reference trajectories.
