# Circumlunar Orbit Angular Velocity

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angular velocity parameter of the crewed spacecraft orbiting the Moon. Used to calculate the phase difference and orbital plane deviation caused by the Moon's rotation during the lander's surface stay, serving as a fundamental input for emergency ascent and rendezvous window design.

## Application Value

环月轨道角速度是航天器绕月轨道的角速度，与轨道高度一一对应，是轨道设计的基本参数。
