# Linear Active Disturbance Rejection Control, LADRC

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A linearized form of active disturbance rejection control. It uses a linear extended state observer to estimate total system disturbance (including unmodeled internal dynamics and external disturbances) and compensates online, making the plant behave as an integrator cascade system and reducing dependence on accurate models.

## Application Value

Linear active disturbance rejection control estimates and compensates unknown disturbances in real time.
