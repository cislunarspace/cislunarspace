# Gauss Pseudospectral Method, GPM

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A pseudospectral method that discretizes continuous optimal control problems into nonlinear programming using Gauss points as nodes and Lagrange polynomials to approximate states and controls.

## Application Value

In spacecraft attitude and orbit control, this method is used to achieve high-precision tracking and stable maintenance. By designing appropriate control laws, external disturbances can be effectively suppressed, ensuring reliable spacecraft operation in complex dynamical environments.
