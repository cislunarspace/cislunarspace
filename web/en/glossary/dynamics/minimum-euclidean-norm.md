# Minimum Euclidean Norm

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A mathematical method for determining iteration step size in differential correction. When free variables exceed constraint variables (under-constrained system), the pseudoinverse matrix is used to find the minimum-norm correction, ensuring iteration convergence stability.

## Application Value

Minimum Euclidean Norm plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
