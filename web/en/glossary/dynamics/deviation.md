# Deviation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The offset distance of the manifold starting point relative to the nominal Halo orbit, serving as a key optimization variable in the upper layer of the two-layer optimization algorithm.

## Application Value

In the two-layer optimization algorithm, deviation serves as the core variable in the upper-level optimization, searching for the energy-optimal transfer orbit by adjusting the manifold starting position. This parameter extends the rigid manifold of orbit design into an adjustable elastic space, significantly expanding the range of feasible solutions.
