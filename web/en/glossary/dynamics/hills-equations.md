# Hill's Equations

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Approximate equations for studying small body motion near a primary, derived by shifting the origin to the secondary mass and expanding in small quantities. A fundamental tool for analyzing encounter events and ring dynamics.

## Application Value

This concept is a fundamental tool for analyzing cislunar space dynamics behavior. It has important application value in orbit design and mission analysis.
