# Scaling Factor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In differential evolution, a parameter that controls the intensity of the mutant vector. A larger F value increases the search range but may slow convergence, while a smaller F value favors fine search but may get stuck in local optima.

## Application Value

比例因子用于修正传感器测量值与真实值之间的系统性偏差，导航系统设计师在数据处理中校正比例因子误差提高定轨精度。
