# Tisserand Relation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An approximate relation derived from the Jacobi integral in the restricted three-body problem, connecting orbital elements before and after a planetary encounter, used to identify whether an object has undergone a close planetary encounter.

## Application Value

该模型是分析地月空间动力学、设计低能量转移轨道的基础工具。该矩阵在可观测性分析和滤波器设计中起关键作用。
