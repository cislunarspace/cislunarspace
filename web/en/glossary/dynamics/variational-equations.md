# Variational Equations

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A system of differential equations governing the evolution of the state transition matrix along an orbit, in the form dPhi/dt = A * Phi, where A is the Jacobian of force F with respect to state X. The eigenvalues of the variational equation determine the properties of the state transition matrix and thus the observability of the orbit.

## Application Value

The variational equations describe the evolution of the state transition matrix along an orbit, whose eigenvalues determine the observability of the orbit. Variational equations are a core tool in sensitivity analysis and observability analysis for orbit design.
