# Stability Factor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Parameter measuring stability of libration point periodic orbits, defined as half the sum of absolute values of unstable and stable eigenvalues of the monodromy matrix. Smaller values indicate stronger stability; minimum value of 1 corresponds to linearly stable orbit.

## Application Value

In orbit design and control system analysis, the Lyapunov method provides an effective means to assess system stability without solving differential equations, particularly suitable for analyzing trans-lunar transfer orbits and orbit stability near small celestial bodies.
