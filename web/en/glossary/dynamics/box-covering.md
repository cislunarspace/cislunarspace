# Box Covering

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set covering method implemented in GAIO software. By subdividing the high-dimensional space containing a Poincare map into progressively smaller rectangular boxes, it constructs a discrete approximation of the target invariant set. Only boxes intersecting the target set are retained, forming a discrete approximation of manifold-section intersections. This enables systematic detection of connecting points between manifolds in different CRTBP models while controlling intersection accuracy in configuration space.

## Application Value

This concept plays a key role in trajectory transfer design, helping evaluate transfer costs and flight time to provide quantitative basis for mission trade studies. Combined with global search algorithms, multiple solution families and Pareto frontiers can be identified to guide orbital design decisions.
