# Relative Orbital Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In the coupled three-body problem, the angle between the positive x-axes of the Sun-Barycenter and Earth-Moon rotating reference frames, equal to the difference of their initial orientation angles. This phase determines the Sun's position relative to the Earth-Moon system and is a key parameter for searching low-cost cross-system trajectory connections.
