# Embedded Model Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A control design methodology built around a discrete-time state equation model (embedded model) running in parallel with the plant, combined with disturbance dynamics and noise estimation for uncertainty rejection.

## Application Value

In spacecraft control system design, this method can be used to design attitude control laws or guidance laws, achieving precise control of spacecraft attitude and orbit. In actual missions, controllers based on this method can improve attitude stability and trajectory tracking accuracy.
