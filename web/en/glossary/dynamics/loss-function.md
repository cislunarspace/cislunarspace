# Loss Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An optimization objective function defined based on differential equation residuals; minimized via iterative least-squares in the TFC method to obtain optimal control solutions.

## Application Value

为航天器的精确控制提供理论依据，确保任务执行的可靠性 结合数值优化算法，可实现高性能的轨迹规划 描述系统状态随时间的变化规律，是轨道预报的基础。
