# Sun-Earth+Moon Synodic Coordinate System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A rotating coordinate system with the Sun as the reference point and the common center of mass of Earth and Moon as the origin. Earth and Moon rotate together as a unified system around the Sun. This coordinate system is used to describe the Poincare section for manifold splicing in Weak Stability Boundary transfers.

## Application Value

When designing Earth-Moon transfer schemes, this orbital characteristic can reduce the total mission delta-V requirement. Exploiting manifold structures enables low-energy transfer trajectory design, reducing dependence on propellant.
