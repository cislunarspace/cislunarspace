# Kustaanheimo-Stiefel Regularization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A regularization method using quaternion transformation to eliminate singularities in the two-body problem, extendable to the restricted three-body problem.

## Application Value

该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
