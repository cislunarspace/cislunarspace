# Genetic Algorithm

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An evolutionary optimization algorithm that searches the solution space through natural selection processes (selection, crossover, mutation). The paper uses a genetic algorithm for preliminary search in the transfer phase space to identify the approximate location of local energy minima, which are then refined using hill-climbing algorithms.
