# Augmented Lagrangian Iterative LQR, AL-iLQR

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Algorithm combining augmented Lagrangian method with iterative LQR to solve discrete constrained optimization problems, applicable to both impulsive and continuous-thrust missions.

## Application Value

This concept is applied in cislunar space: 在轨道动力学数值仿真中，该方法用于提高计算精度和效率. This concept is applied in cislunar space: 通过合理的离散化策略，可以在保证数值稳定性的同时大幅减少计算量.
