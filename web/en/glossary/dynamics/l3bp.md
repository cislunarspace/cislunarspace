# Lambert's Three-Body Problem, L3BP

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The problem of finding a transfer trajectory given initial point, final point and time of flight within the R3BP framework.

## Application Value

This provides a fundamental theoretical framework for cislunar dynamics modeling and analysis, serving as a mathematical tool for studying spacecraft motion.
