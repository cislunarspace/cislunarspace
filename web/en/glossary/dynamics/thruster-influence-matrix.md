# Thruster Influence Matrix

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Geometric matrix describing thruster configuration. The force influence matrix has columns representing the three-axis force produced by each thruster; the torque influence matrix has columns representing the three-axis torque about the spacecraft center of mass. Multiplying with thruster on-time ratios yields actual force and torque.

## Application Value

用于描述误差传播和灵敏度分析 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
