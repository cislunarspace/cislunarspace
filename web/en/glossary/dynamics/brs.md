# Backward Reachable Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The set of all states at time t that free-drift into an avoid set after a specified duration.

## Application Value

Backward Reachable Set plays an important role in orbital mechanics and mission planning, applicable for analyzing spacecraft motion characteristics and optimizing transfer trajectories.
