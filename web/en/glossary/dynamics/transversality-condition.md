# Transversality Condition

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The terminal constraint condition in optimal control problems that determines the values of adjoint variables at the final time. For free terminal time problems, it also requires the Hamiltonian to vanish at the final time (H(tf)=0). It is an essential boundary condition for solving two-point boundary value problems.
