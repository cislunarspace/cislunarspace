# Phasing

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Compensating for phase differences by adjusting the target orbit semi-major axis, enabling Lyapunov controllers to achieve rendezvous with the target body.

## Application Value

Phasing has practical applications in cislunar space mission design and analysis.
