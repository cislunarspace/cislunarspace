# Radial-Tangential-Normal Coordinate System, RTN

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A local orthogonal coordinate system with the radial axis along the spacecraft position direction, the tangential axis along the orbital velocity direction, and the normal axis perpendicular to the orbital plane. Used to decompose orbital deviations into three components for orbit error analysis and TLE correction.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
