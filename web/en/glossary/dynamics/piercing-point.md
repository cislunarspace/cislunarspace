# Piercing Point

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The intersection point of an invariant manifold with a given reference plane. In Earth-Moon transfer design, the YZ plane passing through Earth (at x = -mu) in the CR3BP synodic frame is commonly used as the reference. The eccentricity, inclination, and geocentric distance at piercing points directly determine propellant consumption for the transfer arc, making them key criteria for selecting manifold-based transfer initial conditions.

## Application Value

在流形穿刺点的设计与分析中，可用于优化转移方案，减少燃料消耗 在任务规划阶段用于评估不同推进方案的优劣。
