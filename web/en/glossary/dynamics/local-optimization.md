# Local Optimization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The process of finely searching for a locally optimal solution in the neighborhood of an initial value; in the two-layer algorithm, the lower layer uses the SQP method to perform local optimization near the initial value provided by the global search.

## Application Value

Local Optimization finely searches for a locally optimal solution in the neighborhood of an initial value. In two-layer algorithms, the lower layer uses the SQP method to perform local optimization near the initial value provided by the global search.
