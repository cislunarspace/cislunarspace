# return time
> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In pseudostate theory, the time required for a spacecraft to return from the approach-phase endpoint (the pseudostate sphere boundary) to the sphere boundary via gravity assist. Return time determines the pseudostate sphere radius: the optimal return time for the Moon is approximately 65% of the total flight time, at which the pseudostate trajectory approximation achieves maximum accuracy.

## Application Value

The return time plays a significant role in cislunar space mission design, analysis, and control. In orbital design, it can be leveraged for transfer trajectory optimization; in navigation and control, it improves mission execution precision and reliability; in system analysis, it facilitates deeper understanding of complex multi-body dynamical behavior, guiding mission planning and risk assessment.
