# Polynomial Chaos Expansion

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An expansion that transforms nonlinear uncertainty mapping into a sum of orthogonal polynomials multiplied by coefficients, serving as a surrogate model approach in uncertainty quantification.

## Application Value

Representing uncertain parameters and system responses using stochastic orthogonal polynomial expansions, suitable for analyzing parameter uncertainty effects on orbits.
