# BFGS Formula

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A quasi-Newton formula used in sequential quadratic programming to update the approximation of the Lagrangian Hessian matrix at each iteration.

## Application Value

A classical quasi-Newton formula for approximating Hessian matrices, an efficient algorithm for solving nonlinear programming problems.
