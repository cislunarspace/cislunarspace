# Chattering Boundary Width

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The boundary layer width parameter of the saturation function in sliding mode control. Within this width, the control signal varies linearly with the error for smooth switching; beyond it, the control signal takes a fixed value. Smaller ζ yields higher control precision but greater chattering risk; larger ζ suppresses chattering better but reduces control precision. A trade-off is required.

## Application Value

This concept plays a key role in trajectory transfer design, helping evaluate transfer costs and flight time to provide quantitative basis for mission trade studies. Combined with global search algorithms, multiple solution families and Pareto frontiers can be identified to guide orbital design decisions.
