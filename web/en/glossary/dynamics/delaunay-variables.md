# Delaunay Variables

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Canonical action-angle variables used in the two-body problem and restricted three-body problem. Include pairs of conjugate variables such as mean anomaly M, eccentric anomaly E, argument of perihelion ω, and right ascension of ascending node Ω.

## Application Value

在轨道力学建模和分析中，该问题或模型提供了简化分析方法，用于理解航天器在多体引力场中的运动特性，支撑轨道设计和任务规划.
