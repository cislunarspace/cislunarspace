# Moment Constraint Equations, MCE

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The core mathematical constraints of designed quadrature methods. After substituting the Taylor expansion into the numerical integration formula, the weighted moments of the quadrature point set must exactly equal the theoretical moments of the input random variables, forming a system of equations on point positions and weights. Solving these equations ensures that the polynomial approximation statistically reflects the true probability distribution.

## Application Value

The 矩约束方程 concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
