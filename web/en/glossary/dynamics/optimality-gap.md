# Optimality Gap

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The difference between the objective value of a feasible solution and the upper-bound solution in Lagrangian relaxation, reflecting the gap between the current solution and theoretical optimum.
