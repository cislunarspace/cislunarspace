# Indirect Collocation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Combining indirect optimal control with collocation to solve TPBVPs, discretizing state and costate trajectories at collocation points to improve convergence reliability.

## Application Value

该概念是分析地月空间动力学行为的基础工具。在轨道设计和任务分析中具有重要应用价值。
