# Prescribed Performance Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A time function in prescribed performance control that defines the allowable boundary of tracking errors. It must be positive, strictly decreasing, and bounded below by a positive constant. The finite-time variant allows users to directly specify the convergence time T rather than adjusting an exponential rate parameter.

## Application Value

This term has significant practical applications in cislunar mission planning and execution.
