# Cassini Division

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The wide gap between Saturn's A and B rings, created by the 2:1 orbital resonance with the satellite Mimas.

## Application Value

共振轨道可用于设计长期稳定的任务轨道，减少轨道维持代价。
