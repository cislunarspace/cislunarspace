# Second-order State Transition Tensor, STT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A 6×6×6 tensor describing second-order sensitivity of state dispersion, used for accurate nonlinear state propagation estimation.

## Application Value

为状态估计提供概率框架，提高跟踪精度 用于描述误差传播和灵敏度分析。
