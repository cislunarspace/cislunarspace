# Projection Factor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In station-keeping control, the coefficient used to project state deviations onto the unstable manifold direction for computing correction maneuvers.

## Application Value

投影因子will状态偏差投影到不stable方向, is calculate驻留机动optimal修正量 of keycoefficient. In 平动点orbit of 站maintaincontrol中, 投影因子决定了controlWhen 机和大小.
