# Local Vertical Local Horizontal Frame

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

当地垂线当地水平坐标系的英文缩写。

## Application Value

A target-centered reference frame with the r-axis pointing to the primary body, h-axis parallel to orbital angular momentum, the standard framework for describing relative orbital motion.
