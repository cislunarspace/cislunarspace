# Quasi-Floquet Theory

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An extension of classical Floquet theory to quasi-periodic systems. For variational equations around dynamical substitutes with quasi-periodic coefficient matrices, a quasi-periodic transformation matrix of the same fundamental frequencies can reduce the linearized system to constant-coefficient form, decomposing motion into center, unstable, and stable components.

## Application Value

该轨道类型可作为地月空间运输网络的中转站或任务的目标轨道。该理论可用于分析周期轨道附近运动的稳定性，指导轨道保持策略。
