# Minimum Spanning Tree

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A spanning tree that possesses the same nodes as the original graph but retains only edges that connect nodes without forming cycles and minimize the total edge weight, used in constructing the cluster hierarchy in HDBSCAN.

## Application Value

Minimum Spanning Tree plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
