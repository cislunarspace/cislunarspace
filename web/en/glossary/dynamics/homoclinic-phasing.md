# Homoclinic Phasing

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An indirect phasing strategy that uses homoclinic transfer trajectories of libration point orbits to achieve phase adjustment. The spacecraft enters a homoclinic transfer via a Lyapunov orbit (departing along the unstable manifold and returning along the stable manifold to the same periodic orbit), then returns to the original orbit, consuming fuel only for the two tangential maneuvers entering and leaving the Lyapunov orbit.

## Application Value

该方法在轨道转移设计中被用于分析转移通道和能量最优轨迹，为低能量转移方案提供理论支撑。
