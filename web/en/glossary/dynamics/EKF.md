# Extended Kalman Filter, EKF

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A state estimation method that extends Kalman filtering to nonlinear systems by linearizing nonlinear functions via first-order Taylor expansion, propagating state vector and error covariance matrix in the prediction step, and fusing measurements in the correction step to obtain a posteriori estimates.

## Application Value

The extended Kalman filter handling nonlinear estimation through linearization, a classical algorithm for spacecraft navigation.
