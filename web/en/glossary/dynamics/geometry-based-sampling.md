# Geometry-Based Sampling

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An approach to sampling initial conditions in the phase space by leveraging curvature maxima and localized clustering to construct a sparse yet representative set of trajectories.

## Application Value

该概念是分析地月空间动力学行为的基础工具。在轨道设计和任务分析中具有重要应用价值。
