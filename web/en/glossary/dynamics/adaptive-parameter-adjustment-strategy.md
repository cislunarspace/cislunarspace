# adaptive parameter adjustment strategy

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A parameter adjustment method in pseudostate theory used to improve computational efficiency and robustness. This strategy automatically adjusts step size and patching parameters based on the quality of the current iterative solution, avoiding divergence or oscillation that fixed-parameter methods may exhibit under complex orbital conditions, enhancing convergence performance in trajectory optimization.

## Application Value

在自适应参数调整策略的设计与分析中，可用于优化转移方案，减少燃料消耗 结合数值优化算法，可实现高性能的轨迹规划。
