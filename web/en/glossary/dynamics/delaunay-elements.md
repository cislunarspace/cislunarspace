# Delaunay Elements

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of conjugate parameters that make the three-body equations of motion take Hamiltonian form, including L, G, H and their conjugate angular variables.

## Application Value

在轨道力学建模和分析中，该问题或模型提供了简化分析方法，用于理解航天器在多体引力场中的运动特性，支撑轨道设计和任务规划.
