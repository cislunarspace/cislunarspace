# Position Offset Compensation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Because the fourth-stage burn pushes the interceptor away from the target point, Lambert guidance leads it to an offset aimpoint R_offset = R_T − ΔR to compensate for the position deviation caused by the burn, where ΔR is computed by integrating the burn duration with the rocket equation.

## Application Value

Position offset compensation guides the interceptor to an offset aimpoint via Lambert guidance to compensate for the position deviation caused by the burn; it is a key technology for improving impact-point accuracy, with applications in ballistic missiles and lunar landing.
