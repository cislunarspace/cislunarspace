# Continuous Homotopy

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A homotopy path tracking method. Continuously tracks the homotopy path along the tangent direction using pseudo-arclength as the step size. Employs a predict-correct strategy: first predicts the next node along the tangent, then corrects using Newton's method. Handles turning points on the homotopy curve (where the homotopy parameter can increase or decrease), making it more robust than discrete homotopy.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
