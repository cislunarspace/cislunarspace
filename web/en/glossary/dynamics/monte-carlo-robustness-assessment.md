# Monte Carlo Robustness Assessment

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Evaluating control policy robustness under uncertainty by sampling a large number of initial state perturbations (100 in the paper), measuring success rate and terminal accuracy. A2PPO achieves 100% success rate across all four scenarios.

## Application Value

在轨道控制律设计中，该方法通过优化推力方向和大小实现燃料消耗最小化，是深空任务的核心技术。
