# Linear Interpolation Parameterization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A numerical method for discretizing continuous control functions. The function is evaluated at a set of control nodes with linear interpolation between them, converting the infinite-dimensional optimal control problem into a finite-dimensional nonlinear programming problem. In this paper, it parameterizes the continuous variation of thrust direction cosines.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
