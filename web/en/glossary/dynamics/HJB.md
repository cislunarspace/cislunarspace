# Hamilton-Jacobi-Bellman Equation, HJB

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A PDE whose viscosity solution zero-level set gives the exact reachable set.

## Application Value

The core equation of optimal control, obtaining global optimal control laws through solving the Hamilton-Jacobi-Bellman equation.
