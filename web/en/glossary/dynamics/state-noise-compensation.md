# State Noise Compensation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method for estimating the covariance matrix of unmodeled accelerations by mapping them to the six degrees of freedom of the state vector through a transformation matrix.

## Application Value

为状态估计提供概率框架，提高跟踪精度 用于描述误差传播和灵敏度分析。
