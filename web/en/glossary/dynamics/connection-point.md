# Connection Point

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The intersection point of Sun-Earth manifold and Earth-Moon manifold on the Poincaré section, serving as the key location for achieving low-energy transfer through heterospace orbit connection.

## Application Value

该方法在轨道转移设计中被用于分析转移通道和能量最优轨迹，为低能量转移方案提供理论支撑。
