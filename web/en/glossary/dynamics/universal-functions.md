# Universal Functions

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A class of universal functions (U₀, U₁, U₂, U₃) used to solve the Kepler problem, capable of uniformly expressing the time-position relationship for all conic orbits (ellipse, parabola, hyperbola).

## Application Value

万有function U₀、U₁、U₂、U₃ 可统一表达椭圆、抛物、双曲线orbit of When 间 and 位置关系, is solve开普勒problem of 通用工具. In orbitpredict和transferorbitdesign中has 广泛application.
