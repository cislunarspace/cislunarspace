# Complex Dual Numbers Automatic Differentiation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Automatic differentiation using complex dual numbers for computing both first and second derivatives simultaneously, avoiding complex analytical derivation of perturbing accelerations with respect to state vector.

## Application Value

Computing exact derivatives to machine precision without truncation error, a core technology for efficient sensitivity equation generation in optimal control.
