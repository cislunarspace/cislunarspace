# Unstable Manifold

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The set of trajectories that asymptotically depart from an unstable periodic orbit at an exponential rate. In Hamiltonian systems, the unstable manifold forms a tube-like structure of escaping trajectories. Contrasted with the stable manifold (trajectories approaching the orbit), the unstable manifold enables escape or return transfers. In the three-impulse Halo transfer, the return design uses the unstable manifold with forward time integration instead of the stable manifold with backward integration.

## Application Value

This concept has important application value in cislunar space research and mission design.
