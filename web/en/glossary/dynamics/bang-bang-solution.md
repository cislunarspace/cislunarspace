# Bang-bang Solution

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A typical solution structure for fuel-optimal control problems, where the control switches between maximum value and zero with no intermediate thrust arcs. This is a local optimal characteristic of minimum-fuel problems.
