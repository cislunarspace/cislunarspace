# Inner-Loop Transfer Mode

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A phasing transfer mode in which the transfer orbit lies inside the NRHO (closer to the Moon). It is more fuel-efficient when the chaser has a phase lag, because the smaller orbital radius yields a shorter period, enabling the chaser to take a shortcut to catch up with the target.
