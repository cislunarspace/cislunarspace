# Probability Density Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A function describing the density of probability of a random variable near a given value.

## Application Value

Probability Density Function plays an important role in orbital dynamics and attitude control, serving as a critical tool for analyzing spacecraft motion characteristics. Research on this concept enables optimization of orbit transfer schemes and improvement of control system performance.
