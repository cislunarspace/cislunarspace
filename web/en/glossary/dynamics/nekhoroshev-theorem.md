# Nekhoroshev Theorem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A theorem stating that action variables remain bounded for long times in near-integrable Hamiltonian systems. Provides exponential stability time estimates and describes dynamical behavior in transitions between resonance zones.

## Application Value

共振轨道可用于设计长期稳定的任务轨道，减少轨道维持代价。
