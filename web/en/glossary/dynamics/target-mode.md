# Target Mode

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

One of the two fundamental Halo orbit station-keeping strategies, proposed by Farquhar and Breakwell. It targets the nominal orbit, guiding the spacecraft to the desired position. This approach has a standard feedback control system structure, is conceptually straightforward, and easy to implement in engineering. It contrasts with the Floquet mode, which uses invariant manifold structure to suppress unstable components.

## Application Value

Target Mode has practical applications in cislunar space mission design and analysis.
