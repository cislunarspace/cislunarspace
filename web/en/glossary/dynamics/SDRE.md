# State Dependent Riccati Equation Control, SDRE

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A control method for nonlinear systems that linearizes the nonlinear system at each time instant and then solves the state-dependent Riccati equation to obtain optimal control gains. Compared with MPC, SDRE is more computationally efficient under an infinite-horizon formulation but more sensitive to dynamical model errors, requiring separate tuning for different epochs.

## Application Value

Linearizing nonlinear systems at each instant and solving state-dependent Riccati equations for optimal control gains, more computationally efficient for infinite-horizon problems but more sensitive to dynamical model errors.
