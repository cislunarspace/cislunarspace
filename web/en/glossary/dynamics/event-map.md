# Event Map

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A companion to the survival map using the same grid of initial conditions, but instead of showing lifetime, it classifies each initial state by its termination event: lunar impact, exit via L1, exit via L2, or stability within the propagation window. While the survival map answers 'how long,' the event map answers 'what happened.'

## Application Value

This concept has practical applications in cislunar space science and engineering. Related research supports the planning, implementation, and operations of cislunar missions, forming an integral part of the knowledge system in this field.
