# Autonomous Swarm

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Multiple sub-swarms in particle swarm optimization that adopt different acceleration factor update strategies, enabling parallel multi-strategy search to improve global optimization performance.

## Application Value

在轨道设计参数优化中，该算法用于在庞大解空间中搜索全局最优或近似最优解. 适用于复杂约束条件下的多目标优化问题.
