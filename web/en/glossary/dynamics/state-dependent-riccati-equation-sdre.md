# State Dependent Riccati Equation, SDRE (SDRE)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A nonlinear optimal control method that converts the infinite-horizon quadratic cost function into an algebraic Riccati equation at each time instant via SDC parameterization, yielding a nonlinear feedback control law with local stability and suboptimality. Compared to the HJB PDE, SDRE enables real-time computation.

## Application Value

该概念是分析地月空间动力学行为的基础工具。在轨道设计和任务分析中具有重要应用价值。
