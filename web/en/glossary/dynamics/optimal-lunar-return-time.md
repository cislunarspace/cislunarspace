# optimal lunar return time

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The lunar gravity-assist return time in pseudostate theory that maximizes the approximation accuracy of the pseudostate sphere, approximately 65% of the total flight time. The paper uses this as a key parameter in the perturbed gravity assist model to determine the pseudostate sphere boundary, dividing the region where precise dynamics applies from where conic approximations are valid.

## Application Value

This concept is essential for understanding motion characteristics in orbital design and control, and plays a vital role in mission success.
