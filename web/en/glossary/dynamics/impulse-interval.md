# Impulse Interval

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The time between two consecutive station-keeping impulses. It is a key design parameter: longer intervals typically reduce annual cost but increase position deviation. Stable or weakly unstable orbits (e.g., DROs, NRHOs) permit much longer intervals than unstable halo orbits.

## Application Value

Impulse interval is a key station-keeping design parameter: longer intervals reduce annual propellant cost but increase position deviation. Stable orbits like DROs permit much longer intervals than unstable halo orbits.
