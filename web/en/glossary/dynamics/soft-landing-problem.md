# Soft Landing Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Problem of finding a thrust program that lands a spacecraft softly at a target point from given initial conditions while minimizing fuel.

## Application Value

The soft landing problem finds minimum-fuel thrust programs for landing spacecraft at target points from given initial conditions, fundamental for lunar descent missions.
