# Bifurcation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A phenomenon where parameter changes in dynamical systems cause sudden changes in orbit stability or topological properties, such as halo orbits bifurcating from planar Lyapunov orbits.


## Application Value

Lyapunov orbits are the most fundamental periodic orbit type near libration points, and their invariant manifolds provide natural pathways for low-energy transfers.
