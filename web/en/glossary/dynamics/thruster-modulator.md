# Thruster Modulator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Algorithm that computes the on-time ratio of each thruster within a control cycle based on controller-demanded force and torque. Involves torque allocation and force allocation sub-problems solved via linear programming to minimize propellant consumption.

## Application Value

This algorithm minimizes propellant consumption by solving torque allocation and force allocation sub-problems via linear programming. It is essential for efficient spacecraft attitude and orbit control.
