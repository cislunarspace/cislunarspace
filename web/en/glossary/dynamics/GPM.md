# Gauss Pseudospectral Method, GPM

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A pseudospectral method that discretizes continuous optimal control problems into nonlinear programming using Gauss points as nodes and Lagrange polynomials to approximate states and controls.

## Application Value

The Gauss pseudospectral method uses Legendre polynomials at collocation points to discretize state and control, suitable for solving finite-time optimal control problems.
