# Inertia

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The sum of squared Euclidean distances between each member and its cluster centroid, used to evaluate cluster compactness.

## Application Value

Inertia measures cluster compactness as the sum of squared distances to cluster centroids, used in trajectory clustering and classification for cislunar orbit families.
