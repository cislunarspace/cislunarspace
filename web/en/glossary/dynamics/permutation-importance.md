# Permutation Importance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method for evaluating the importance of input features in a machine learning model by randomly permuting each feature's values, re-predicting, and observing the drop in accuracy. This study's permutation importance analysis reveals that sensor aperture diameter is the most influential feature for predicting cislunar surveillance coverage, outweighing sensor number and architecture type.

## Application Value

置换重要性是机器学习中评估特征重要性的方法，可用于分析轨道影响因素。
