# Angular Rate

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The time rate of change of the angle swept by the position vector relative to the central body. In the shape-based derivation, angular rate is obtained analytically from the shape function via a second-order polynomial equation and is a key intermediate quantity for computing thrust acceleration and flight time.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
