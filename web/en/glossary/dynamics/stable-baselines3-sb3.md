# Stable-Baselines3, SB3

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A PyTorch-based reinforcement learning library providing stable implementations of algorithms such as PPO and SAC. A2PPO extends the SB3 PPO implementation with a cross-attention feature fusion module.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
