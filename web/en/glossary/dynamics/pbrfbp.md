# Planar Bicircular Restricted Four-Body Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Four-body model incorporating solar perturbation into PCRTBP, with the Sun revolving in a circular orbit around the Earth-Moon barycenter.

## Application Value

This provides a fundamental theoretical framework for cislunar dynamics modeling and analysis, serving as a mathematical tool for studying spacecraft motion.
