# Local Lyapunov Exponent, LLE

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A measure of the maximum growth rate of terminal state deviations caused by small perturbations in initial conditions. In orbital error propagation analysis, a larger LLE indicates faster error divergence in that orbital arc, requiring more frequent midcourse corrections to suppress error accumulation.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
