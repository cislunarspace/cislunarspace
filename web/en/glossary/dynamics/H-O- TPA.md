# High-order Target Point Approach, High-order TPA

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A nonlinear Target Point Approach that computes high-order maneuver maps using Differential Algebra techniques, enabling fast calculation of fuel-optimal and error-robust corrective maneuvers via polynomial evaluation.

## Application Value

High-order target point methods improve transfer target computation accuracy through higher-order terms, suitable for high-precision cislunar transfer and rendezvous missions.
