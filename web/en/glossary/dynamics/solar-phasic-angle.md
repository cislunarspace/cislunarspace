# Solar Phasic Angle (β)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The parameter measuring the included angle between the line from Earth to Moon and the intersecting line of the ecliptic and lunar planes, serving as a key variable determining cislunar transfer opportunities.

## Application Value

In orbit design and transfer mission planning, this orbit type can be used to optimize fuel consumption and flight time. In practical missions, appropriate analysis methods must be selected based on specific application scenarios and constraints.
