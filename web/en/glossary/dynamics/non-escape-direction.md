# Non-Escape Direction

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A direction vector s in the xy-plane, orthogonal to the escape direction. A velocity increment along this direction changes the orbit amplitude without exciting the unstable exponential component, keeping the spacecraft on non-escape orbits.

## Application Value

Based on its definition, a direction vector s in the xy-plane, orthogonal to the escape direction. a velocity increment along this direction changes the orbit amplitude without exciting the unstable exponential component, kee.
