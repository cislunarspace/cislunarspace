# Generating Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An auxiliary function in Lie transformation that achieves coordinate transformation through Poisson bracket operations. The nth-order generating function Gn is used to eliminate specific terms of order n in the Hamiltonian.

## Application Value

该概念是分析地月空间动力学行为的基础工具。在轨道设计和任务分析中具有重要应用价值。
