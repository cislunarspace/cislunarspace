# Dual-Actor Network

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A dual-network architecture where separate actor networks output weights and effectivity thresholds for Earth-centered inertial and Moon-centered inertial Lyapunov controllers respectively, enabling end-to-end forward propagation from GTO to LPO.

## Application Value

Dual-Actor Network has practical applications in cislunar space mission design and analysis.
