# Jump Condition

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In optimal control problems with state constraints, the conditions governing possible discontinuities in adjoint variables and the Hamiltonian at the entry or exit times of a boundary interval. The jump magnitude is determined by the state constraint gradient and a nonnegative multiplier η.

## Application Value

该概念是分析地月空间动力学行为的基础工具。在轨道设计和任务分析中具有重要应用价值。
