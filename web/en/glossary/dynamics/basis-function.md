# Basis Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The set of orthogonal polynomials (e.g., Legendre or Chebyshev) used to expand free functions, combined with trigonometric functions to capture orbital oscillation frequencies.

## Application Value

This concept plays an important role in cislunar space mission design and orbital dynamics analysis.
