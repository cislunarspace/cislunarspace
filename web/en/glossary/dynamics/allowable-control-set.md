# Allowable Control Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In multi-stage optimal control problems, the finite set of all feasible control decisions satisfying stage-wise constraints. Allowable control sets are constructed for each stage in advance, then a global optimization method such as dynamic programming selects the optimal combination. The set size is determined by the required solution precision: higher precision yields larger sets and greater computational cost.

## Application Value

In orbital design, analysis, and control, dynamics models are used to predict spacecraft trajectories, with equations of motion solved numerically or analytically. This concept underpins critical mission capabilities including orbital maneuver design, orbit improvement, and formation flying.
