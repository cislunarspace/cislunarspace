# Dynamic Control Analysis Package

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

ESA-developed multibody dynamics software

## Application Value

DCAP (Dynamic Control Analysis Package) is ESA-developed multibody dynamics software for analyzing the dynamic characteristics of complex spacecraft systems. It can be used in cislunar mission design to evaluate orbital stability and transfer schemes.
