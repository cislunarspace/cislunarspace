---# Hampath

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)
## Definition
A numerical optimal control solver developed by Caillau et al., implementing differential homotopy continuation for shooting equations. It supports continuation strategies including L2-L1 and logarithmic barrier homotopies, handles non-smooth bang-bang control problems, and integrates conjugate point tests for local optimality verification.

## Application Value
在姿态控制和轨道控制system中，used for设计反馈律，achieve对spacecraft运动的精确调节. 在轨迹优化problem中，used for寻找燃料消耗最少或时间最短的最优飞行scheme.
