# Full-System Comprehensive Verification Test

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A system-level test that connects the complete spacecraft with ground tracking and control equipment for end-to-end full-mission rehearsal. It simulates lunar gravity through cable suspension, using real sensors and propulsion systems to achieve the most realistic ground verification of the landing process.

## Application Value

系统级试验在地面验证着陆全流程，是发射前的最后检验。
