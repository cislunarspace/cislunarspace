# Satellite Tool Kit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A commercial space mission analysis software developed by Analytical Graphics, Inc. It provides a graphical environment for trajectory design and mission support with gravitational fields at various fidelity levels, but focuses on trajectory output rather than insight into underlying dynamical structures.

## Application Value

The Satellite Tool Kit concept is applied in cislunar space research, providing technical support or analytical methods for lunar exploration missions.
