# General Mission Analysis Tool, GMAT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

NASA-developed astrodynamics software for high-fidelity orbital propagation, providing the LP-165 lunar gravity model up to 50th-degree spherical harmonics and incorporating perturbations from Sun, Earth, Moon, Jupiter and solar radiation pressure.

## Application Value

NASA's open-source astrodynamics software supporting high-fidelity orbital propagation with the LP-165 lunar gravity model, a mainstream tool for cislunar orbit design.
