# COOPT

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An optimal control software package developed by the Computational Science and Engineering Group at UC Santa Barbara for optimizing systems modeled by differential-algebraic equations. It combines multiple shooting with the SQP solver SNOPT, computes gradients and Jacobians via the DAE sensitivity software DASPK, and generates sensitivity equations through the automatic differentiation tool ADIFOR.
