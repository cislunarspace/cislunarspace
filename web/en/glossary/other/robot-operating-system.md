## Definition

Open-source robotics middleware framework for robot control and communication

## Application Value

The term "Robot Operating System"in cislunar space missionsholds significant application value. In the orbital design phase, engineers leverage related theories for trajectory optimization; In navigation and orbit determination, to improve measurement accuracy; In attitude control and orbit-keeping missions, ensuring stable spacecraft operation. In specific applications, parameters can be optimized and algorithms adapted according to mission requirements, improving mission success rate and resource utilization efficiency.
