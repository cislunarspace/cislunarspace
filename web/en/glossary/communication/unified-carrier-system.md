# Unified Carrier System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A spacecraft tracking and telemetry system that modulates multiple functional signals (ranging, velocity measurement, telecommand, telemetry) onto a single RF carrier. Different functional signals are distinguished by subcarriers, simplifying RF system design. It is the standard system in spacecraft TT&C. The Chang'e-4 relay satellite uses S-band unified carrier for Earth TT&C and X-band unified carrier for the forward lunar link.
