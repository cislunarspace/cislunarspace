# Time Division Multiple Access (TDMA)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A multiple access protocol where multiple satellites transmit and receive signals in different time slots to share inter-satellite links.

## Application Value

This term has significant application value in cislunar space missions. In trajectory design, it can be used to optimize transfer trajectories and reduce mission fuel consumption. In attitude control and dynamics analysis, it helps understand spacecraft motion characteristics in complex gravitational fields, providing theoretical support for mission planning. In navigation and orbit determination, methods based on this term improve orbit prediction accuracy and support the development of autonomous navigation algorithms.
