# Beam Width Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The spatial angular spread of the electromagnetic beam transmitted by a satellite antenna. Smaller beam angle yields higher antenna gain. Libration point navigation constellations use approximately 6.5 degree beam width (versus GPS 21.3 degrees) to gain antenna advantage and compensate for long-range path loss.

## Application Value

Beam Width Angle is cislunar space 通信系统 关键技术之一。在实际任务中，该技术可用于保障星间/星地通信链路、传递时空基准信息或扩展通信覆盖范围， for cislunar space 任务提供可靠 通信保障。
