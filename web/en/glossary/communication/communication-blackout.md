# Communication Blackout

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The phenomenon where radio communication is blocked by the plasma sheath during spacecraft reentry.

## Application Value

This concept provides an important theoretical foundation for cislunar space mission design In practical engineering, it can be applied to trajectory design, mission planning, or control system analysis.
