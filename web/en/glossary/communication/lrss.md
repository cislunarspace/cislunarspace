# Lunar Relay Satellite System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A data relay station established using cislunar periodic orbits, providing communication relay between far-side lunar probes and Earth ground stations. This paper proposes a periodic orbit with ~77.6-day period (perilune altitude ~208 km, perigee altitude ~113 km) that covers most lunar orbiter altitudes.

## Application Value

This term has significant practical applications in cislunar mission planning and execution.
