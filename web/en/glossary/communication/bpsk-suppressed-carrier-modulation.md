# BPSK Suppressed Carrier Modulation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A variant of Binary Phase Shift Keying (BPSK) that completely suppresses the carrier component, transmitting only the information-bearing sideband signals. Compared to conventional BPSK, all transmit power is concentrated on the information sidebands, achieving higher power utilization efficiency. The Chang'e-4 relay satellite uses this modulation for both the return lunar link and Earth data transmission.
