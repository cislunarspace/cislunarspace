# Earth-Halo-Moon Relay Path, EHM Path

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The total signal path length from Earth through an L3 halo orbit relay satellite to the Moon. This distance directly affects the link budget and is a key constraint in L3 orbit selection. As the orbit's perigee approaches Earth, the Earth-halo segment shortens but the halo-Moon segment lengthens, requiring a trade-off between the two.

## Application Value

This term has important reference value in cislunar space research and engineering applications.
