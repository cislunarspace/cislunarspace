# Four-Dimensional Point Matching

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Algorithm matching craters using 2D coordinates and two semi-axis lengths

## Application Value

Four-Dimensional Point Matching provides technical support for space situational awareness and target tracking, playing a key role in satellite navigation, space debris monitoring, and deep space communications.
