# Adaptive Thresholding

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An image segmentation method that dynamically determines the separation threshold between targets and background based on local image characteristics. Compared to fixed thresholds, it better adapts to brightness variations across different regions, separating celestial targets from the varying sky background.

## Application Value

在天文图像处理中用于目标提取和背景分离 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
