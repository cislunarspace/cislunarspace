# Target Coverage Time Ratio

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The percentage of time within one orbital period during which an observation satellite achieves full coverage of the target orbital area under payload field-of-view constraints. It is the primary metric for observation orbit selection; a higher value indicates better coverage.

## Application Value

This metric is the primary criterion for observation orbit selection; higher values indicate better coverage of target orbital areas under payload field-of-view constraints.
