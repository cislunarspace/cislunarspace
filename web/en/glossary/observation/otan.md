# Optical Terrain Absolute Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Vision-based navigation system using terrain features like craters for absolute position estimation in pinpoint lunar landing

## Application Value

Optical Terrain Absolute Navigation provides technical support for space situational awareness and target tracking, playing a key role in satellite navigation, space debris monitoring, and deep space communications.
