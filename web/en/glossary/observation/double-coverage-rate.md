# Double Coverage Rate

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The fraction of a 24-hour period during which a target is simultaneously observed by two or more satellites. Double coverage provides cross-viewpoint observations for position verification, improving cataloguing and orbit determination accuracy while reducing anomaly detection false alarm rates. Simulations show double coverage rates of 41.3%-98.3% across four typical solar terms.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
