# Magnitude Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A mathematical model that calculates the brightness of a space object based on the apparent magnitude concept, using parameters including diffuse reflectance coefficient, effective reflecting area, and observation distance. The paper adopts a spheroid-like assumption to simplify the calculation for assessing cislunar object observability.
