# Ionosphere

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Conductive layer in Earth's atmosphere formed by ionization, affecting radio communications

## Application Value

电离层是地球高层大气的一部分，对无线电信号有折射和延迟效应，导航系统设计师必须修正电离层延迟以提高定位精度。
