# Angle-Only Measurement

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Relative measurements containing only azimuth and elevation information.

## Application Value

Inter-satellite measurement uses links between spacecraft for navigation, providing independent navigation capability.
