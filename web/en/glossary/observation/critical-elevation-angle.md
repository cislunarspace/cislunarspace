# Critical Elevation Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The minimum elevation angle threshold h₀ for determining CN satellite visibility from a lunar surface point. The satellite is visible if h ≥ h₀. For the atmosphereless Moon, h₀ is typically set to 0°.

## Application Value

Critical Elevation Angle is significant for spacecraft tracking, identification, and perception in cislunar space.
