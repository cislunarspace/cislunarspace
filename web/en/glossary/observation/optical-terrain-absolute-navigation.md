# Optical Terrain Absolute Navigation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Vision-based navigation system using terrain features like craters for absolute position estimation in pinpoint lunar landing


## Application Value

视觉导航不依赖地面站设备，适合地月空间的自主相对导航，通过特征点提取和滤波估计实现追踪航天器相对目标的位置姿态估计。
