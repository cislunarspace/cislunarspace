# Multiple Object Tracking Accuracy

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A comprehensive metric for multi-object tracking performance, computed as 1 - (FN + FP + IDSW) / GT. Higher values indicate better tracking accuracy, reflecting both detection quality and identity maintenance.

## Application Value

This technology has broad applications in deep space communication and TT&C, forming an essential part of ground support for cislunar missions.
