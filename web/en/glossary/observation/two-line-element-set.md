# Two-Line Element Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A spacecraft orbital element data format published by US Air Force Space Command, encoded in two 69-character lines. Contains information including mean motion, eccentricity, and atmospheric drag parameters, used for orbit prediction. Widely used in commercial and military space situational awareness.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
