# Median Filter

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A nonlinear filtering method that replaces each pixel value with the median of its neighborhood values. It effectively suppresses random and salt-and-pepper noise while preserving edge information. In astronomical image preprocessing, it removes cosmic ray hits and hot pixels.

## Application Value

Median Filter has important applications in cislunar space navigation and orbit determination systems.
