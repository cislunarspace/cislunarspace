# Time-Expanded Facility Location Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A sensor deployment optimization model proposed by Shimane et al. that extends traditional facility location problems to the spatiotemporal dimension. Combining Lagrangian relaxation with heuristic algorithms for dynamic sensor pointing scheduling, it achieves 5.2x speedup over traditional methods, applicable to cislunar constellation design.

## Application Value

Time-Expanded Facility Location Model is significant for spacecraft tracking, identification, and perception in cislunar space.
