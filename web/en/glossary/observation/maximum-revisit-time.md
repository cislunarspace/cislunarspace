# Maximum Revisit Time

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Longest duration between consecutive coverages of a point on the lunar far side; an important metric for measuring coverage gap.

## Application Value

最大重访时间是目标被连续观测的最大时间间隔，是观测任务规划的重要约束。
