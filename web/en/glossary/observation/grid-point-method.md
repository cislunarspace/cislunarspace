# Grid-point Method

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Method dividing the lunar far-side region into grids by longitude and latitude, evaluating relay satellite coverage by checking whether each grid satisfies elevation angle constraints.
