# Limiting Magnitude

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The faintest apparent magnitude that a sensor can detect; set to magnitude 18 in this work, consistent with typical CubeSat and small satellite telescope capabilities.

## Application Value

在观测系统设计中，需要考虑传感器性能、观测几何和数据处理方法。该概念支撑目标检测、跟踪和识别等任务。
