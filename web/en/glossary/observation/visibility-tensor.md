# Visibility Tensor

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A four-dimensional Boolean tensor that records whether a target is visible from an observer location along a given pointing direction at a given time step.

## Application Value

用于描述误差传播和灵敏度分析 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
