# Visibility Boolean

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A Boolean flag indicating whether a target can be effectively observed by an observer, requiring satisfaction of four conditions: Moon occlusion, Earth occlusion, field-of-view containment, and brightness threshold.

## Application Value

可观测性布尔量表征传感器对目标的可见性，观测系统设计师用它快速判断目标是否在传感器视野内。
