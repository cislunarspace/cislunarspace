# Initial Orbit Determination

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The process of determining orbital elements from limited observation data (angles, ranges, etc.). Typical methods include Laplace's method, Gauss's technique, Gibbs method, and Herrick-Gibbs method.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
