# CDN-Net

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A celestial densely nested hierarchical backbone network designed for faint celestial target detection, using multi-channel brightness representation to capture astronomical targets at different luminance levels while maximally preserving faint object feature information. Experiments show CDN-Net outperforms both traditional algorithms and general deep learning methods for faint celestial detection tasks.
