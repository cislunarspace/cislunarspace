# Cislunar Space Domain Awareness Architecture

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A network of electro-optical sensor observers distributed across cislunar orbits for monitoring space objects. The architecture optimizes observer quantity, orbital distribution, phasing, and telescope aperture to achieve persistent coverage of cooperative or non-cooperative targets at reasonable cost.

## Application Value

地月空间态势感知架构整合多种传感器实现对地月空间目标的监视，是空间安全领域的基础设施架构。
