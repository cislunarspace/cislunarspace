# Identity Switch

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A critical error type in multi-object tracking where the same target is assigned different identity labels across frames. The number of identity switches is a component of the MOTA metric and a key indicator of tracking robustness. DeepSORT significantly reduces ID switches by fusing appearance features.

## Application Value

This technology has broad applications in deep space communication and TT&C, forming an essential part of ground support for cislunar missions.
