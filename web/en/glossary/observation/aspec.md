# Specular Reflectance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The proportion of incident light that is reflected in a mirror-like (directional) manner by the target surface. In this paper, targets are modeled as purely diffuse reflectors, so this value is set to zero.

## Application Value

This term has significant practical applications in cislunar mission planning and execution.
