# Edge Intelligence System

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A system architecture that deploys AI algorithms on edge devices close to the data source for real-time processing. In cislunar applications, it refers to deploying lightweight AI models onboard spacecraft for autonomous object detection and orbit determination, reducing dependence on ground stations.

## Application Value

Edge Intelligence System is significant for spacecraft tracking, identification, and perception in cislunar space.
