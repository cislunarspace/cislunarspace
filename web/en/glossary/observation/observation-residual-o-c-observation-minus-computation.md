# Observation Residual, O-C (Observation minus Computation)

> Author: [Tianjiang Says](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The difference between the measured and theoretically computed observables. In cataloguing orbit determination, it is used to assess convergence of orbit improvement, and is theoretically required to follow a white noise distribution.

## Application Value

In observation system design, sensor performance, observation geometry, and data processing methods must be considered. This concept supports target detection, tracking, and identification tasks in cislunar space situational awareness systems.
