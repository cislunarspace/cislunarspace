# Spacecraft Break-up Event

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An in-orbit explosion or collision fragmentation event of a spacecraft that generates a large number of fragments propagating through cislunar space. Break-up events are one of the main sources of cislunar debris, posing threats to future lunar infrastructure and Earth's protected orbital regions.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
