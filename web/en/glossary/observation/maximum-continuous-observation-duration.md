# Maximum Continuous Observation Duration

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The maximum duration during which an observation satellite can continuously observe a target area without interruption. This metric reflects the orbit's suitability for persistent surveillance missions; a larger value indicates stronger continuous observation capability.
