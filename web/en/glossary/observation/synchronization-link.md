# Synchronization Link

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A dedicated communication link for transmitting synchronization information between formation-flying spacecraft. The TanDEM-X mission uses a two-way synchronization link that eliminates phase offsets due to inter-satellite distance through bidirectional phase measurements.

## Application Value

在航天器导航和定位中，该方法用于从传感器数据中提取有效信息，实现自主定轨和轨道预报. 支持地月空间探测任务的实时导航需求.
