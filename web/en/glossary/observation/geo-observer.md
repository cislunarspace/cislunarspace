# GEO Observer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An electro-optical sensor observer deployed in a geostationary orbit. The paper finds that when using the control weighted coverage metric, the frequency of GEO observers increases significantly, because cooperative agents departing from GEO expend large amounts of propellant during the escape phase, which GEO observers can effectively cover.
