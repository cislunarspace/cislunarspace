# Vertical Domain Large Model

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A large language or multimodal model trained and optimized for a specific professional domain, possessing reasoning and generalization capabilities within that field. The paper proposes developing a vertical domain large model for cislunar awareness, integrating multi-task capabilities including object detection, localization, orbit determination, and behavioral reasoning.
