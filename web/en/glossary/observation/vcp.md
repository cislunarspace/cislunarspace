# Visibility Count Percentage

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The percentage of time steps during which an object is visible out of the total observation time, used to quantify object visibility. Computed as the sum of visible time steps across all observers divided by total time steps, multiplied by 100.

## Application Value

This concept has application value in cislunar space research and engineering practice, helping to understand core principles of the field.
