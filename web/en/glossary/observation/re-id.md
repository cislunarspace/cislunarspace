# Person Re-Identification

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique for recognizing the same person across different camera views or time points by extracting and comparing appearance feature vectors. DeepSORT incorporates this technique into multi-object tracking, using appearance features to assist motion-based target association.

## Application Value

This term has significant practical applications in cislunar mission planning and execution.
