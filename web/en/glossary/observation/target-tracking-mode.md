# Target Tracking Mode

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A telescope observation mode that tracks a specific space target's motion, keeping the target within the field of view across consecutive frames. In this mode, stars appear as streaks while the tracked space target (if successfully tracked) appears as a point source. Image sequences from this mode are typical inputs for multi-object tracking algorithms.
