# Connected Component Labeling

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An image analysis technique that groups adjacent foreground pixels in a binary image into the same region. In astronomical target detection, connected component labeling is applied to the thresholded image, with each component representing a candidate celestial body, then filtered by area to exclude noise and invalid regions.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
