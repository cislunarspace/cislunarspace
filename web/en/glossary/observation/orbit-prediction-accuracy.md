# Orbit Prediction Accuracy

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The deviation between the orbit propagated forward from orbit determination results and the true orbit at the predicted epoch. Typically measured by RMS or maximum position error, it is a core metric for the timeliness of cataloguing systems.

## Application Value

在编目系统中，该技术可提高对空间目标的探测、跟踪和编目能力。轨道预报精度是编目系统时效性的核心指标。
