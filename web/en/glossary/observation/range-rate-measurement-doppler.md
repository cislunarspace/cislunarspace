# Range Rate Measurement (Doppler)

> Author: [Tianjiang Says](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Measuring spacecraft radial velocity using Doppler frequency shift. Doppler count integration over a counting time interval yields the average range rate over that period.

## Application Value

In observation system design, sensor performance, observation geometry, and data processing methods must be considered. This concept supports target tracking, orbit determination, and navigation tasks in cislunar space.
