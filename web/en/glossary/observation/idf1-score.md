# IDF1 Score

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A metric measuring how well a tracker maintains consistent target identities over time. Computed as 2*IDTP / (2*IDTP + IDFP + IDFN), where IDTP, IDFP, and IDFN are identity true positives, false positives, and false negatives. Higher IDF1 indicates better long-term identity preservation.

## Application Value

IDF1 Score is significant for spacecraft tracking, identification, and perception in cislunar space.
