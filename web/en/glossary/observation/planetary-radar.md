# Planetary Radar

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A ground-based radar system designed to observe planets and other deep-space objects. Originally built for planetary radar astronomy, it has been extended to detect cislunar targets such as spacecraft in lunar orbit. The basic operational principle involves a high-power transmitter sending modulated radar signals that reflect off the target and are captured by a receiving antenna, from which azimuth, elevation, range (delay), Doppler shift, and echo power are extracted for orbit determination and radar imaging. Major planetary radar facilities worldwide include the Goldstone Solar System Radar, Arecibo Planetary Radar, and the Green Bank Observatory planetary radar.

## Application Value

This term has significant application value in cislunar space missions。In the orbital design phase, engineers use relevant theories for trajectory optimization；In navigation and orbit determination, it is used to improve measurement accuracy；In attitude control and orbit maintenance tasks, it ensures stable spacecraft operation。In practical applications, parameter optimization and algorithm adaptation can be combined with mission requirements to improve mission success rate and resource utilization efficiency。
