# Collision Warning

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Using catalogue database information, observational data, and mathematical models to dynamically monitor space object orbits, performing rapid collision probability analysis with high-performance computing systems, and issuing advance warnings to spacecraft at risk of collision so they can perform avoidance maneuvers.
