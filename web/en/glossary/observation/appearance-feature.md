# Appearance Feature

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Visual information extracted from target images, such as shape, texture, and brightness distribution, used to distinguish different targets. In multi-object tracking, appearance features complement motion features: motion is suited for short-term prediction, while appearance features recover identity after prolonged occlusion.
