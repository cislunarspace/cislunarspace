# Inter-Satellite Link Ranging

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique that determines the relative distance between spacecraft by mutually transmitting and receiving ranging signals. Distance and clock bias can be decoupled through bidirectional transmission.

## Application Value

This technique is crucial for cislunar navigation and orbit determination, providing high-precision position and velocity information for spacecraft.
