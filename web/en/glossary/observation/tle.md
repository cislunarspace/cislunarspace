# Two-Line Element Set

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A spacecraft orbital element data format published by US Air Force Space Command, encoded in two 69-character lines. Contains information including mean motion, eccentricity, and atmospheric drag parameters, used for orbit prediction. Widely used in commercial and military space situational awareness.

## Application Value

Two-Line Element Set provides technical support for space situational awareness and target tracking, playing a key role in satellite navigation, space debris monitoring, and deep space communications.
