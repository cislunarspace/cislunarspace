# Lunar Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The changing appearance of the Moon's illuminated disc, including new moon, first quarter, full moon, and last quarter.

## Application Value

在编目系统中，该技术可提高对空间目标的探测、跟踪和编目能力。
