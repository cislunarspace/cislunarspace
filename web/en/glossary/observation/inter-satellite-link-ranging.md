# Inter-Satellite Link Ranging

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A technique that determines the relative distance between spacecraft by mutually transmitting and receiving ranging signals. Distance and clock bias can be decoupled through bidirectional transmission.

## Application Value

This technique enables autonomous orbit determination for cislunar spacecraft by mutually transmitting and receiving ranging signals, with distance and clock bias decoupled through bidirectional transmission.
