# Along-Track Interferometry, ATI

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An interferometric technique that measures target velocity by comparing time-delayed radar echoes acquired by two phase centers separated along the flight direction. Applied to ocean current monitoring and moving target indication.

## Application Value

ATI measures target velocity by comparing time-delayed radar echoes from along-track separated phase centers, applied to ocean current and moving target monitoring.
