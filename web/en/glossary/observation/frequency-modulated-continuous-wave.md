# Frequency-Modulated Continuous Wave (FMCW)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A radar signal waveform that transmits a continuous wave whose frequency varies linearly over time. By mixing the received echo with the transmitted signal, the resulting beat frequency is proportional to target range, enabling distance measurement. FMCW radar does not require high peak-power pulse transmission, making it suitable for long-range detection with continuous-wave transmitters. It is one of the standard signal formats used in planetary radar systems.

## Application Value

在编目系统中，该技术可提高对空间目标的探测、跟踪和编目能力。
