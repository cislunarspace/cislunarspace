# Cross-Track Interferometry

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A method that measures target height or terrain by using the phase difference of radar echoes acquired by two or more spatially separated antennas. Digital Elevation Models can be generated by deriving topographic information from interferometric phase measurements.

## Application Value

Cross-Track Interferometry provides technical support for space situational awareness and target tracking, playing a key role in satellite navigation, space debris monitoring, and deep space communications.
