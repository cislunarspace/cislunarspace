# Radiation Angle Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A function describing how the reflected light intensity of a diffuse spherical surface varies with the solar phase angle. The formula is φ = (2/3π²)(sinθ + (π-θ)cosθ), where θ is the solar phase angle.
