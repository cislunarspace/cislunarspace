# Reflection Resonant Orbit, RRO

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A type of three-dimensional resonant orbit symmetric about the x-z plane, analogous to halo orbits in libration point orbits, generated from planar resonant orbits through bifurcation theory.

## Application Value

A type of resonant orbit where spacecraft exhibits reflective motion in the orbital plane, suitable for specific scientific observation missions.
