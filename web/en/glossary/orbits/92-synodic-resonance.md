# 9:2 Synodic Resonance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Resonance relationship where orbital period is 9/2 times the synodic rotation period.

## Application Value

This concept is applied in cislunar space: 9:2 共旋谐振是轨道周期与月地连线旋转周期成9:2比例的共振关系，在地月空间的轨道设计中具有特定的.
