# Libration-Point Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A periodic or quasi-periodic orbit around a libration point (Lagrange point), including Lyapunov orbits, halo orbits, vertical orbits, and axial orbits.

## Application Value

Libration point orbits are the core orbital form for cislunar missions, including various types such as Halo orbits and Lissajous orbits, key infrastructure for deep space exploration.
