# Nominal Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The designed reference orbit state, such as the nominal Halo orbit, serving as the baseline for actual manifold deviation and optimization.

## Application Value

在轨道设计阶段，该方法可用于求解低能量转移轨道，减少推进剂消耗。该轨道类型可作为地月空间运输网络的中转站或任务的目标轨道。利用流形结构可设计低能量转移轨道，减少对推进剂的依赖。
