# Pseudo-Perilune Parameters

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of characteristic parameters describing a spacecraft's perilune state in free-return orbit design. Using these parameters as design variables combined with a hybrid multi-conic method for piecewise orbit stitching and iterative correction, high-precision initial trajectory solutions can be rapidly generated under multiple constraints including Earth departure, lunar flyby, and safe reentry. The nominal transfer orbit library in the paper is generated using this approach.

## Application Value

This concept is applicable in cislunar space mission design, orbit optimization, and trajectory planning for spacecraft transfers and maneuver strategies.
