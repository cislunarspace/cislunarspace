# Trajectory Section Width

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The unit of measurement for DRO orbital stability. Defined as the maximum distance between all trajectory intersection points on a given cross-section. A larger section width indicates a wider bounded motion range and poorer stability.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
