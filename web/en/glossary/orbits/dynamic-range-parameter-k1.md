# Dynamic Range Parameter k1

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A parameter in the exponential sinusoid shape function that determines the ratio of apoapsis to periapsis radii. k1 controls how elongated the spiral orbit is near and far from the primary; larger values produce more eccentric shapes. The product k1 k2 is constrained to avoid infinite thrust and angular rate at periapsis.

## Application Value

对于大质量航天器的长时间转移，该推进方式可大幅降低推进剂消耗。
