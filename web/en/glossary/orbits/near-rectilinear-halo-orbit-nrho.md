# Near-Rectilinear Halo Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A class of near-rectilinear periodic orbits near Lagrange points, selected by NASA for the Lunar Gateway space station; close to the lunar polar regions. In NRHO, the x- and y-direction amplitudes are much smaller than the z-direction amplitude, giving the orbit its nearly linear appearance.

## Application Value

This orbit type holds significant application value for cislunar space missions. In orbital design, it can be used to optimize transfer trajectories and reduce mission fuel consumption. In attitude control and dynamics analysis, it helps understand spacecraft motion characteristics in complex gravitational fields, providing theoretical support for mission planning. In navigation and orbit determination, methods based on NRHO can improve orbit prediction accuracy and support the development of autonomous navigation algorithms.
