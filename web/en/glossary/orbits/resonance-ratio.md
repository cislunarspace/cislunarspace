# Resonance Ratio

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The integer ratio between the DRO orbital period and the lunar sidereal period. For example, 4:1 means the DRO completes 4 revolutions around the Moon for each lunar orbit around the Earth. The resonance ratio affects the gravitational field asymmetry and z-direction motion amplitude; DROs in the 2:1 to 4:1 range have stronger asymmetry and better autonomous orbit determination via inter-satellite measurement, with 4:1 providing the largest elevation angle at lunar poles.

## Application Value

This term has significant application value in cislunar space missions。In the orbital design phase, engineers use relevant theories for trajectory optimization；In navigation and orbit determination, it is used to improve measurement accuracy；In attitude control and orbit maintenance tasks, it ensures stable spacecraft operation。In practical applications, parameter optimization and algorithm adaptation can be combined with mission requirements to improve mission success rate and resource utilization efficiency。
