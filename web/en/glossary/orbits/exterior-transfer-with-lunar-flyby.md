# Exterior Transfer with Lunar Flyby

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An Earth-Moon transfer that first flies by the Moon then returns to the Earth side, using lunar gravity assist to reduce total fuel consumption.

## Application Value

An Exterior Transfer with Lunar Flyby first flies by the Moon then returns to the Earth side, using lunar gravity assist to reduce total fuel consumption. It provides an alternative low-energy transfer option.
