# Lunar Soft Landing Trajectory

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The flight trajectory descending from lunar orbit to the lunar surface, requiring velocity reduction to near zero for a damage-free landing. The referenced study in the paper's appendix parameterizes the soft landing trajectory optimization problem, converting it to a parameter optimization problem where all optimization parameters and motion states have specific physical meanings. This problem can be solved using global optimization methods such as ant colony algorithms, yielding fuel consumption quite close to the result of Pontryagin's maximum principle.

## Application Value

在月球软着陆轨道的设计与分析中，可用于优化转移方案，减少燃料消耗 结合数值优化算法，可实现高性能的轨迹规划 在任务规划阶段用于评估不同推进方案的优劣。
