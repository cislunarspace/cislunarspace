# Polar Circular Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Circular lunar orbit with 90-degree inclination, offering uniform coverage of the lunar far side; a key component in heterogeneous relay constellations.

## Application Value

在极地圆轨道的设计与分析中，可用于优化转移方案，减少燃料消耗 该概念为地月空间任务设计提供了重要的理论基础 在实际工程中可用于轨道设计、任务规划或控制系统分析。
