# Axial Resonant Orbit, ARO

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A type of three-dimensional resonant orbit symmetric about the x-axis, analogous to axial orbits in libration point orbits, generated from planar resonant orbits through bifurcation theory.

## Application Value

Periodic orbit type with axial resonance, suitable for sustained observation or communication coverage in specific directions.
