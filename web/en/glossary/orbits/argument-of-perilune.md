# Argument of Perilune

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The angle measured along the orbit from the ascending node to perilune, specifying the orientation of the orbit's closest approach point relative to the ascending node. It influences how lunar higher-order gravitational perturbation affects RAAN and is a key variable in parking orbit traversal analysis.

## Application Value

近月点幅角是近月点相对于升交点的角度，是描述月球轨道的重要参数。
