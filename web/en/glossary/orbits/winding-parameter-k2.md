# Winding Parameter k2

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A parameter in the exponential sinusoid shape function that governs the number of revolutions of the spiral. k2 determines how many turns the trajectory makes within a given angular travel, with larger values producing tighter spirals with more revolutions. Together with k1 it defines the trajectory shape.


## Application Value

This control method can be applied to spacecraft attitude stabilization, orbit keeping, and maneuver trajectory optimization in cislunar space missions, improving mission execution flexibility and reliability.
