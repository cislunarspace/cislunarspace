# Eclipse Avoidance

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Orbital maneuvers in libration point missions to avoid Sun, Earth, or Moon occultation. Lissajous orbits are more suitable than Halo orbits for long-duration mission eclipse avoidance.

## Application Value

Eclipse avoidance is an important reference orbit type in cislunar orbit design and can be used for target orbit selection and transfer scheme design. In actual missions, orbit design based on Eclipse avoidance can satisfy specific mission constraints such as communication elevation angle, coverage, and fuel optimality. Exploiting the characteristics of Eclipse avoidance allows transfer trajectory optimization for efficient Earth-to-Moon transfers. Eclipse avoidance offers diverse orbit options for lunar exploration missions and supports flexible mission planning.
