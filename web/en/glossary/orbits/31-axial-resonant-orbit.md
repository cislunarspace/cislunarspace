# 3:1 Axial Resonant Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An axial resonant orbit with period ratio 3:1, translatable to other three-body systems (e.g., Saturn-Titan) via system translation technique.

## Application Value

Based on its definition, this term has significant application value in cislunar space missions. For example, in orbit design, its characteristics can be leveraged for transfer trajectory optimization; in orbit maintenance, it enables precise orbital control; in navigation and orbit determination, it can improve state estimation accuracy; in mission planning, it assists in determining transfer timing and strategies. Specific engineering applications require comprehensive analysis considering mission constraints and orbital characteristics.
