# Argument of Latitude

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Angle in the orbital plane from the ascending node to the spacecraft position, equal to the sum of argument of perigee and true anomaly

## Application Value

The angle in the orbital plane from the ascending node to spacecraft position, equal to the sum of argument of perigee and true anomaly, used to describe in-plane position.
