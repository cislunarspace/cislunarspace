# Orbital Stability Index

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An index measuring the long-term stability of DRO under multi-body perturbations. Multiple cross-sections through the lunar center, perpendicular to the x-y plane and equally spaced in phase angle, intersect the DRO trajectory; the average of the maximum distances between intersection points on each section quantifies the orbital boundedness and configuration preservation capability.

## Application Value

In periodic orbit design, this index evaluates orbital boundedness and long-term stability, guiding the formulation of station-keeping strategies.
