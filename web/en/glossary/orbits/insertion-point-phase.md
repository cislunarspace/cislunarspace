# Insertion Point Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The phase angle of the spacecraft's insertion point on the stable manifold relative to the Moon, which corresponds one-to-one with the insertion point position. This phase determines the splicing condition between the Earth-Moon transfer segment and the stable manifold, and significantly affects the total transfer velocity increment. Simulations show that fuel consumption is minimized when the insertion phase is approximately 120 degrees; smaller phases degrade the lunar gravity assist effect, while larger phases are constrained by the manifold trajectory direction.

## Application Value

Insertion point phase determines the splicing condition between Earth-Moon transfer segments and stable manifolds. Simulations show minimum fuel consumption at approximately 120°, a key parameter requiring focus in mission planning.
