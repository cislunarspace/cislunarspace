# Quasi-Satellite Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A family of quasi-periodic orbits in the restricted three-body problem with period close to the host body's orbital period, exhibiting satellite-like retrograde or prograde motion in the host body's reference frame.

## Application Value

This concept is used in orbital analysis and has significant impact on mission design.
