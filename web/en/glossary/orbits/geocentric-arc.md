# Geocentric Arc

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Orbit transfer arc dominated by Earth as the primary attracting body, propagated using Earth-centered modified equinoctial elements.

## Application Value

This concept plays an important role in trajectory optimization and mission planning applications.
