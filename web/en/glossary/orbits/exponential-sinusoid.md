# Exponential Sinusoid

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An analytical shape-based representation for low-thrust trajectories, defined by r = k₀ exp[k₁ sin(k₂θ + φ)], where four parameters control the trajectory shape. Under tangential thrust assumptions, the corresponding thrust history and polar angle rate are uniquely determined by analytical expressions. When |k₁k₂²| < 1, the entire curve is dynamically feasible with pure tangential thrust. First proposed by Petropoulos in his Ph.D. thesis, it laid the foundation for shape-based low-thrust mission design.

## Application Value

为航天器的精确控制提供理论依据，确保任务执行的可靠性 用于分析航天器在复杂引力场中的运动特性。
