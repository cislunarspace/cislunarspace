# Constellation Configuration

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The combined scheme of orbit types, orbital parameters, and phase relationships of satellites within a constellation. The paper compares multiple configurations (e.g., 6ELFO+2NRHO, 8ELFO) and selects the optimal one at each construction stage using a comprehensive evaluation index.

## Application Value

This concept is applicable in cislunar space mission design, orbit optimization, and trajectory planning for spacecraft transfers and maneuver strategies.
