# Minimum-Time Trajectory

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The trajectory that minimizes transfer time under a given maximum thrust constraint. In low-thrust optimization, minimum-time solutions serve as a prerequisite for fuel-optimal problems: first determine the minimum flight time for a given thrust, then set the terminal time of the fuel-optimal problem above that value.

## Application Value

In low-thrust trajectory optimization, minimum-time trajectories serve as a prerequisite, first determining the minimum flight time, then using it as the terminal time constraint for the fuel-optimal problem. This hierarchical optimization strategy significantly reduces the computational complexity of multi-objective trajectory design.
