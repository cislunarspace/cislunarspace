# Minimum-Thrust Trajectory

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Trajectory that minimizes the thrust value for a given angular distance and boundary conditions. Used to verify existence of solution and correct angular distance distribution between geocentric and selenocentric segments.

## Application Value

Minimum-Thrust Trajectory is an important concept in cislunar orbit design, crucial for understanding spacecraft motion in the Earth-Moon space.
