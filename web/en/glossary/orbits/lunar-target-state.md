# Lunar Target State

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A pre-selected initial state (position and velocity) near the lunar L2 point in the Earth-Moon CR3BP whose dynamical evolution leads to a desired outcome such as lunar impact or weak capture. Transfer design proceeds by first identifying suitable lunar target states via survival and event maps, then matching them at a Poincare section with the unstable manifold flowing from the Sun-Earth libration point orbit.

## Application Value

在轨道设计与任务规划中，需要选择合适的轨道类型并分析其动力学特性。该概念对于转移轨道设计、轨道插入和轨道保持具有重要指导意义。
