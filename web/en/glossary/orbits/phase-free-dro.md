# Phase-Free DRO

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Distant retrograde orbit that permits spacecraft entry at any solar phase angle within the Earth-Moon barycentric rotating frame, accommodating DRO insertion at any epoch.

## Application Value

该轨道类型可作为地月空间运输网络的中转站或任务的目标轨道。
