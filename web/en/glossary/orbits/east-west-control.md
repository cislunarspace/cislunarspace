# East-West Control

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A longitudinal station-keeping strategy that applies small thrust in the orbit-cross-track direction to correct the semi-major axis, thereby controlling the spacecraft's drift in longitude relative to the target position. Adapted from GEO satellite east-west control for triangular libration point positioning.

## Application Value

在轨道设计与任务规划中，需要选择合适的轨道类型并分析其动力学特性。该概念对于转移轨道设计、轨道插入和轨道保持具有重要指导意义。
