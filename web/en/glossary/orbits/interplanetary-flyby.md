# Interplanetary Flyby

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A mission where a spacecraft uses a planet's gravity to change trajectory while flying past it.

## Application Value

在行星际飞越的设计与分析中，可用于优化转移方案，减少燃料消耗 用于分析航天器在复杂引力场中的运动特性。
