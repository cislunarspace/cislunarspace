# Constant Exhaust Velocity Problem

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Optimal fuel trajectory optimization problem with constant exhaust velocity, bounded thrust with switching capability. This is the final problem type solved in the paper.

## Application Value

A trajectory optimization model assuming constant exhaust velocity, a theoretical framework for analyzing variable specific impulse engine performance.
