# Perigee-Point Scenario

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A baseline transfer configuration method for halo orbits that requires the manifold insertion maneuver to be performed at the perigee of the manifold segment. This approach is intuitive but not optimal, as constraining the insertion point to perigee sacrifices some energy-change efficiency.

## Application Value

When designing transfer trajectories, this concept helps evaluate transfer cost and flight time, providing a quantitative basis for comparing mission schemes. Combined with global search algorithms, families of solutions and Pareto fronts can be found to guide orbit design decisions.
