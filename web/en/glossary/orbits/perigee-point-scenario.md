# Perigee-Point Scenario

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A baseline transfer configuration method for halo orbits that requires the manifold insertion maneuver to be performed at the perigee of the manifold segment. This approach is intuitive but not optimal, as constraining the insertion point to perigee sacrifices some energy-change efficiency.

## Application Value

在进行轨道转移设计时，This概念有助于评估转移代价和飞行时间，为任务方案比选provides定量依据。结合全局搜索算法，可找到多族解和帕累托前沿，指导轨道设计决策。
