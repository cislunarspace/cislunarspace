# Heterospace-system Manifold Connection

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Connecting invariant manifolds of the Sun-Earth and Earth-Moon systems on a Poincaré section to achieve low-energy orbit transfer across different three-body systems.

## Application Value

When designing orbital transfers, this concept helps evaluate transfer cost and flight time, providing quantitative support for comparing mission schemes. Combined with global search algorithms, multiple solution families and Pareto fronts can be found to guide orbit design decisions.
