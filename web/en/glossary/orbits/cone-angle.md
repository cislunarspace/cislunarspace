# Cone Angle

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A geometric parameter describing the angular deviation of a quasi-periodic orbit relative to the x-axis of the rotating frame, used to evaluate communication and visibility constraints.

## Application Value

锥角是地月空间轨道设计中的重要参考轨型，可用于目标轨道选择和转移方案设计 在实际任务中，基于锥角的轨道设计能够满足特定的任务约束，如通信仰角、覆盖范围和燃料最优等要求 利用锥角的特性，可以优化转移轨道设计，实现从地球到月球的高效转移 锥角为月球探测任务提供了多样化的轨道选择方案，有助于任务的灵活规划
