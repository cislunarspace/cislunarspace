# Inner Earth Escape

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

In inner transfer via LL2, the spacecraft escapes from the inner side of Earth's gravity boundary. The spacecraft only reaches LL2 without truly crossing; essentially it achieves transfer via LL1.

## Application Value

内侧地球逃逸是地月空间轨道设计中的重要参考轨型，可用于目标轨道选择和转移方案设计 在实际任务中，基于内侧地球逃逸的轨道设计能够满足特定的任务约束，如通信仰角、覆盖范围和燃料最优等要求 利用内侧地球逃逸的特性，可以优化转移轨道设计，实现从地球到月球的高效转移 内侧地球逃逸为月球探测任务提供了多样化的轨道选择方案，有助于任务的灵活规划
