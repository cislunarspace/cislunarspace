# Simple Periodic Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A class of basic periodic three-body orbits in the Stromgren classification: each orbit crosses the x-axis exactly twice per period, symmetric about the x-z plane, with each crossing occurring orthogonally. Lyapunov orbits about L1/L2 and distant prograde orbits about the Moon are examples. Simple periodic orbits serve as building blocks for complex periodic orbits and orbit chains.

## Application Value

This concept is fundamental to cislunar orbital mechanics and mission analysis, providing essential theoretical support for trajectory design and operational planning.
