# Orbital Period, T₀

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The time required for a spacecraft to complete one orbit, expressed in either non-dimensional time units or days. It is a key parameter for evaluating orbital mission suitability.

## Application Value

In low-thrust trajectory optimization, minimum-time trajectories serve as a prerequisite step: first determining the shortest flight time, then using it as the terminal time constraint for the fuel-optimal problem. This hierarchical optimization strategy significantly reduces the computational complexity of multi-objective trajectory design.
