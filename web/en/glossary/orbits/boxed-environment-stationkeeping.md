# Boxed Environment Stationkeeping

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A guaranteed-convergence stationkeeping strategy for libration point orbits. A box is defined around the libration point in terms of specified distances from the x- and y-axes. The trajectory evolves freely within the box; when it crosses a boundary (indicating departure along a manifold toward the Moon, Sun-Earth direction, or triangular points), a bisection method searches for the minimum delta-V to return. While not fuel-optimal, this method guarantees a solution and is typically used as a fallback when other strategies fail to converge.

## Application Value

在轨道设计与任务规划中，需要选择合适的轨道类型并分析其动力学特性。该概念对于转移轨道设计、轨道插入和轨道保持具有重要指导意义。
