# escape phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The flight segment in an Earth-Moon free-return trajectory where the spacecraft escapes from perilune to the landing point. The paper controls the initial velocity of this phase so the spacecraft reaches the designated landing target with the desired trajectory, a key step in lunar gravity assist trajectory optimization.

## Application Value

escape phase plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
