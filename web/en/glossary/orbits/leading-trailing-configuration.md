# Leading/Trailing Configuration

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A constellation configuration where observers are non-uniformly distributed along an orbit, following each other in phase rather than being equally spaced, beneficial for collaborative coverage of static targets.

## Application Value

In the orbit design phase，it can be used to analyze the motion characteristics of spacecraft in cislunar space，and evaluate the feasibility and efficiency of different orbital schemes。
supports monitoring and tracking of space objects，providing data input for collision early warning and orbit prediction。
used for analyzing the stability and transfer characteristics of periodic orbits，supporting orbital design solutions for cislunar space stations。
