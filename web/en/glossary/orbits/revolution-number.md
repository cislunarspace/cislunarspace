# Revolution Number

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A phase parameter on a halo orbit, analogous to mean anomaly for conic orbits but ranging from [0,1] instead of an angle, advancing linearly with time. The revolution number τ is used to identify the state at a specific point along the halo orbit, and together with the x₀ value uniquely determines a specific halo orbit state.

## Application Value

在轨道设计和转移轨道优化中，该方法用于确定最优转移时机和轨道形状，以最小化燃料消耗或飞行时间. 通过数值仿真和迭代优化，可获得满足任务约束的可行轨道方案.
