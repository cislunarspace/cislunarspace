# Circumlunar Elliptical Parking Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A highly elliptical circumlunar orbit entered by a lander after lunar orbit insertion for extended parking while awaiting crewed spacecraft arrival. Compared to circular parking orbits, its orbital element evolution under lunar gravitational perturbation is more predictable, enabling maintenance-free parking for several months.

## Application Value

This class of orbits has significant application value in lunar mission site selection and space station deployment, providing spacecraft with a stable dwelling environment and favorable mission geometry.
