# escape preparation phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The first phase of a lunar return trajectory, in which the spacecraft uses three impulsive maneuvers to adjust its orbital plane and phase angle, reducing the velocity increment required for subsequent lunar escape. Together with the escape execution phase (Moon-Earth transfer phase), it constitutes the complete lunar return trajectory.

## Application Value

在进行轨道转移设计时，This概念有助于评估转移代价和飞行时间，为任务方案比选provides定量依据。结合全局搜索算法，可找到多族解和帕累托前沿，指导轨道设计决策。
