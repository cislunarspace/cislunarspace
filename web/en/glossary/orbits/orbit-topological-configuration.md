# Orbit Topological Configuration

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The overall geometric shape and spatial envelope of an orbit in position space. Different libration point orbit types have different topological constraints: quasi-halo orbits require equal in-plane and out-of-plane frequencies, imposing strict configuration constraints; Lissajous orbits only require unequal frequencies, allowing more relaxed constraints and easier transitions between neighboring orbits after control maneuvers.

## Application Value

This concept plays a key role in trajectory transfer design, helping evaluate transfer costs and flight time to provide quantitative basis for mission trade studies. Combined with global search algorithms, multiple solution families and Pareto frontiers can be identified to guide orbital design decisions.
