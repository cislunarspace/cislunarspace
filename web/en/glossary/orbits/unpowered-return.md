# Unpowered Return

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The capability of a spacecraft to return to Earth vicinity without executing any orbital maneuvers after propulsion failure or mission abort, relying solely on the inherent dynamical properties of the free-return trajectory. This is a critical safety feature in manned mission design.

## Application Value

Unpowered Return plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
