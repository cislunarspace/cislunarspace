# Flower Constellation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A constellation design where all satellites share the same trajectory in a rotating reference frame, appearing as multi-petaled flowers with repeatable ground tracks and favorable phasing mechanics.

## Application Value

This term has significant practical applications in cislunar mission planning and execution.
