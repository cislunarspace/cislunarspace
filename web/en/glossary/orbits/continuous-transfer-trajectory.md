# Continuous Transfer Trajectory

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A multi-segment transfer trajectory that is continuous in both position and velocity, obtained by eliminating discontinuities between segments using a multiple shooting scheme.

## Application Value

This concept is used in orbital analysis and has significant impact on mission design.
