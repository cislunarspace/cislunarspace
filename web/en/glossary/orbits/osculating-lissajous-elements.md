# Osculating Lissajous Elements

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A set of six parameters [A1, A2, Ax, Az, Φxy, Φz] that characterize a libration point orbit by analogy with osculating Keplerian elements. They include the unstable/stable exponential amplitudes, in-plane and out-of-plane oscillation amplitudes, and their respective phase angles.

## Application Value

This concept is applicable in cislunar space mission design, orbit optimization, and trajectory planning for spacecraft transfers and maneuver strategies.
