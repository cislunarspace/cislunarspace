# Quasi-Periodic Orbit, QPO

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An orbit with multiple incommensurable frequencies that serves as a nominal trajectory, replacing the geometric libration point in the quasi-periodic model.

## Application Value

Quasi-Periodic Orbit, QPO is a key element in cislunar space orbit design, with significant value for planning Earth-Moon transfer trajectories and designing formation flying scenarios. It is widely applied in lunar exploration missions and small body explorations.
