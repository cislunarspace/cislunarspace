# Orbit Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A parameter ranging from 0 to 1 that describes a spacecraft's position along a periodic orbit, where 0 and 1 correspond to the same state. Given the Jacobi constant and orbit family, the orbit phase uniquely determines the state at the x-axis crossing point.

## Application Value

Combined with transfer cost maps, orbit phase enables rapid evaluation of transfer costs and flight times at different orbital positions, supporting efficient trajectory screening during cislunar mission planning.
