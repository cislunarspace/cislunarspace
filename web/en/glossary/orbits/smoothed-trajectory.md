# Smoothed Trajectory

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A continuous trajectory in the ephemeris model obtained by applying multiple shooting corrections to an optimal trajectory originally computed in the CR3BP, satisfying high-fidelity dynamics.

## Application Value

This class of orbits has significant application value in lunar mission site selection and space station deployment, providing spacecraft with a stable dwelling environment and favorable mission geometry.
