# Planar quasi-periodic mode

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

One mode of bounded solutions for linearized relative motion on DRO, composed of two periodic components. The trajectory rotates around the chief spacecraft within a bounded hollow area, usable for designing fly-around formations.

## Application Value

该轨道类型可作为地月空间运输网络的中转站或任务的目标轨道。在编队飞行和交会对接任务中，该运动模型是控制器设计的基础。
