# Rendezvous Transfer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An orbital transfer type with both terminal position and velocity fully specified. Unlike flyby transfers that impose only position constraints, rendezvous transfers require the spacecraft to satisfy all six components (three position, three velocity) simultaneously at the target. NRHO insertion missions typically use rendezvous transfers to precisely match a specific state on the target orbit.

## Application Value

在轨道设计和转移轨道优化中，该方法用于确定最优转移时机和轨道形状，以最小化燃料消耗或飞行时间. 通过数值仿真和迭代优化，可获得满足任务约束的可行轨道方案.
