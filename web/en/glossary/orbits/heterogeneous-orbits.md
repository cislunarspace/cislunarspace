# Heterogeneous Orbits

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Satellite orbit configuration with different orbit types (e.g., circular and Halo orbits), where satellites complement each other's coverage to fill gaps of single-orbit systems.

## Application Value

This concept is used in orbital analysis and has significant impact on mission design.
