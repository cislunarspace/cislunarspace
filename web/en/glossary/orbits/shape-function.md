# Shape Function

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A parametric curve used in shape-based methods to prescribe the trajectory shape a priori. Once the shape function is given, the thrust profile and velocity increment are analytically derived from the inverse solution of the equations of motion. The form of the shape function determines the trajectory's shape characteristics, and its parameters are tuned by optimization algorithms to improve transfer performance.

## Application Value

在轨道设计与任务规划中，需要选择合适的轨道类型并分析其动力学特性。该概念对于转移轨道设计、轨道插入和轨道保持具有重要指导意义。
