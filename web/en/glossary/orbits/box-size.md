# Box Size

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The dimensions of the smallest box enclosing the entire quasi-periodic orbit with sides aligned to the rotating frame axes, used to characterize the geometric size of the orbit.

## Application Value

Box Size plays an important role in orbit maneuver design, analysis, and transfer planning for cislunar missions.
