# Bouncing Trajectory

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Orbits in phase space that approach L1 and then return toward Earth. When the velocity azimuth angle γ at a given point exceeds the stable manifold boundaries (γ<γmin or γ>γmax), the trajectory is a bouncing trajectory. Such trajectories cannot be used for lunar transfer missions.

## Application Value

在轨道设计与任务规划中，需要选择合适的轨道类型并分析其动力学特性。该概念对于转移轨道设计、轨道插入和轨道保持具有重要指导意义。
