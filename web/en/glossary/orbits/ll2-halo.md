# Earth-Moon L2 Halo Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A halo orbit around the Earth-Moon L2 libration point, providing continuous communication coverage for the lunar far side.

## Application Value

Earth-Moon L2 Halo Orbit is a key element in cislunar space orbit design, with significant value for planning Earth-Moon transfer trajectories and designing formation flying scenarios. It is widely applied in lunar exploration missions and small body explorations.
