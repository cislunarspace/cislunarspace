# Planetary System Tour

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An orbital strategy that exploits three-body dynamics and invariant manifolds to sequentially orbit multiple moons within a planetary system for scientific investigation. The paper uses the Uranus system as a benchmark, designing a tour from the outermost moon Oberon to the innermost Miranda, executing closed orbits around each moon. The total tour requires approximately 930 days and only 2.04 km/s of velocity change.

## Application Value

The Planetary System Tour exploits three-body dynamics and invariant manifolds to sequentially orbit multiple moons within a planetary system for scientific investigation. It enables efficient tour design with minimal velocity change requirements.
