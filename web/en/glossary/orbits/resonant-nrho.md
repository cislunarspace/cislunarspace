# Resonant NRHO

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Near-rectilinear halo orbit resonant with the Sun, whose period has a specific integer ratio to the Sun's period.

## Application Value

在周期轨道设计中，该指标用于评估轨道的有界性和长期稳定性，指导轨道维持策略的制定。
