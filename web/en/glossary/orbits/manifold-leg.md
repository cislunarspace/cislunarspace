# Manifold Leg

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The first segment of a transfer trajectory, following the unstable manifold from a libration point orbit toward the perilune.

## Application Value

流形段是不变流形的一段，对应特定的动力学演化路径，轨道设计师用流形段拼接实现低能转移。
