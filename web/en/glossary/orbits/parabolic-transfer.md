# Parabolic Transfer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Transfer orbit with semi-major axis approaching infinity; limiting case corresponding to escape velocity.

## Application Value

抛物线转移是地月空间轨道设计中的重要参考轨型，可用于目标轨道选择和转移方案设计 在实际任务中，基于抛物线转移的轨道设计能够满足特定的任务约束，如通信仰角、覆盖范围和燃料最优等要求 利用抛物线转移的特性，可以优化转移轨道设计，实现从地球到月球的高效转移 抛物线转移为月球探测任务提供了多样化的轨道选择方案，有助于任务的灵活规划
