# Bi-Elliptic Hohmann Transfer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A three-impulse transfer that first expands to an intermediate large ellipse then contracts to the target orbit.

## Application Value

该方法在轨道转移设计中被用于分析转移通道和能量最优轨迹，为低能量转移方案提供理论支撑。
