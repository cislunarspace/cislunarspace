# Orbit Phase

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A parameter ranging from 0 to 1 that describes a spacecraft's position along a periodic orbit, where 0 and 1 correspond to the same state. Given the Jacobi constant and orbit family, the orbit phase uniquely determines the state at the x-axis crossing point.

## Application Value

Orbit phase is the core parameter of transfer cost maps. Orbit designers control spacecraft position on periodic orbits by adjusting phase, thereby optimizing transfer timing and energy consumption to achieve fuel-optimal Earth-Moon transfer.
