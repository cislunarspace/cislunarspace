# Earth-Moon Triangular Libration Point Transfer Network

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A transfer network with the Moon as the central hub linking Earth, low Earth orbit, and the triangular libration point (L4/L5) regions in the Earth-Moon system.

## Application Value

This transfer network with the Moon as hub connects Earth, LEO, and L4/L5 regions, offering diverse trajectory options for cislunar logistics and exploration missions.
