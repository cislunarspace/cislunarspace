# Resonant Orbit

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A periodic orbit whose period bears an integer-ratio relationship to the Moon's orbital period (e.g., 2:1, 3:1). While resonant families are common in solar system dynamics, they have limited application in the Earth-Moon system. Notable applications include the IBEX spacecraft's 3:1 resonant extended mission and TESS's 2:1 resonant orbit for scientific observation.

## Application Value

Resonant Orbit is an important orbit type in cislunar trajectory design, widely applied in mission planning.
