# Earth Escape Stage

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The first phase of a translunar transfer trajectory. Using SE CRTBP dynamics, the spacecraft departs from a LEO parking orbit and is integrated in the SE planar CRTBP until reaching the selected Poincaré section.

## Application Value
