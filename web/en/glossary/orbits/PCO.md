# Prograde Circular Orbit, PCO

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Circular orbits with radius up to 5000 km, highly stable and requiring almost zero corrections to maintain.

## Application Value

Circular orbits with radius up to 5000 km, highly stable requiring almost no maneuvers for maintenance, high-value orbits for long-duration cislunar missions.
