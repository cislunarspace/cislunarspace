# Single-shooting Differential Corrector

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Single-shooting Differential Corrector; a shooting method that generates periodic orbits by adjusting initial velocity so that the trajectory crosses a specified plane vertically, commonly used for generating quasi-periodic DROs in full ephemeris models.

## Application Value

This concept has application value in cislunar space research and engineering practice, helping to understand core principles of the field.
