# Multi-Revolution Transfer Structure

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A basic configuration for low-thrust transfer trajectories where the spacecraft performs multiple revolutions around the libration point under continuous low-thrust to reach the target orbit. Increasing the number of revolutions reduces required thrust but extends flight time. Diminishing returns in thrust reduction and integration error accumulation impose practical limits on the number of revolutions.
