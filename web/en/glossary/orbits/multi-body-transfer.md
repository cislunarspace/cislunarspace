# Multi-body Transfer

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Trajectory transfer designed by exploiting dynamical relationships between multiple three-body gravitational environments, e.g., between Earth–Moon and Sun–Earth systems.

## Application Value

在多体转移的设计与分析中，可用于优化转移方案，减少燃料消耗 用于分析航天器在复杂引力场中的运动特性。
