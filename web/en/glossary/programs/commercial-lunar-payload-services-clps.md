# Commercial Lunar Payload Services (CLPS)

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A NASA-led commercial partnership program that contracts companies like Astrobotic and Intuitive Machines to deliver scientific payloads to the lunar surface using commercial launch vehicles, reducing exploration costs and promoting commercial space development.

## Application Value

This concept has application value in cislunar space mission planning and system design, providing assurance for successful mission execution.
