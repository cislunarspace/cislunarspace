# normalization

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

Standardization processing that maps minimization indicator values to the [0,1] interval. Through range transformation (x'' = (x' - mj')/(Mj' - mj')), the paper converts indicators with different dimensions into dimensionless standardized indicators, ensuring comparability among all indicators in the comprehensive assessment.
