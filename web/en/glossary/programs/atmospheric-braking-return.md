# Atmospheric Braking Return

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A return technique in which a vehicle uses Earth's atmospheric drag to decelerate when returning to LEO. Compared with propulsive braking, it avoids propellant expenditure but requires thermal protection structures to withstand aerodynamic heating, resulting in ablative material loss. The paper evaluates this as one of two braking approaches for the transfer stage's return to the space station.
