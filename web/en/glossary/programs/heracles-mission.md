# HERACLES Mission

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

An ESA lunar exploration concept mission using the Gateway as a transit point for unmanned lunar sample return. This paper adopts its rendezvous approach scheme as baseline for hold point design.

## Application Value

The HERACLES Mission is an ESA lunar exploration concept using the Gateway as a transit point for unmanned lunar sample return. Its rendezvous approach scheme serves as baseline for hold point design in cislunar operations.
