# Deep Space Gateway

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

NASA's proposed crewed lunar space station concept to extend human long-term activity in cislunar space.

## Application Value

NASA's proposed lunar space station serving as a departure and return transit base for lunar surface missions, supporting long-term human presence in cislunar space.
