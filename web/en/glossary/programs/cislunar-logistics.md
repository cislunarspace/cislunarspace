# Cislunar Logistics

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The set of missions including personnel/cargo transport, space tourism, and search and rescue operations conducted in cislunar space, relying on periodic orbits to enable routine commutes between Earth and the Moon.

## Application Value

地月空间物流规划地月间的货物运输，是未来月球资源开发的基础设施。
