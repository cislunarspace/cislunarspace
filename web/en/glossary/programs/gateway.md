# Gateway

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A US-led cislunar space station in a near-rectilinear halo orbit. The paper notes that deploying persistent vehicles at Gateway can establish chokepoint control over cislunar transit routes, making it a critical infrastructure node for extending space situational awareness from near-Earth to cislunar space.

## Application Value

深空门户作为地月空间运输网络的中转节点，是未来载人月球探测任务的重要基础设施。
