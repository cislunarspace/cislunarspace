# land-based return landing site

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A land-surface landing location for crewed spacecraft return. The paper compares and analyzes the impact of land-based and sea-based return sites on the distribution of feasible launch windows: land-based sites offer fewer feasible windows due to latitude constraints but facilitate easier search-and-rescue, making them the preferred option for manned lunar missions.

## Application Value

该系统代表了当前地月空间开发的主流方向，对未来月球基地建设和任务规划具有重要参考价值。
