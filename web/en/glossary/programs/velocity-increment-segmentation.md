# velocity increment segmentation

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)

> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A segmentation strategy in the paper for velocity increment thresholds. Because the velocity increment distribution becomes discontinuous above 1.7 km/s, this value is used as the segmentation point, with smoothing applied at the junction to prevent evaluation weight jumps. This strategy is used to construct the velocity increment indicator function in the comprehensive cost evaluation.
