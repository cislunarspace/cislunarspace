# Lunar Gateway

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A lunar orbital space station led by NASA, planned for deployment in a near-rectilinear halo orbit as a deep-space exploration hub. Gateway provides orbital relay, communication/navigation support, and logistics resupply for crewed lunar landing missions, serving as core infrastructure of the Artemis program. Its demand for navigation services along the Earth-Moon transfer corridor is a key driver for heterogeneous navigation constellation development.

## Application Value

This concept provides fundamental support in cislunar space research and mission design. In practical applications, the appropriate analysis method should be selected based on specific mission scenarios and constraints.
