# HTV-X Cargo Spacecraft

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A cargo supply spacecraft designed by JAXA for the Gateway space station, an upgraded variant of the HTV series. The paper uses HTV-X as the application scenario to demonstrate PRM suitability for cargo missions, saving approximately 90 m/s delta-V over LFM, thereby increasing cargo capacity.

## Application Value

该系统代表了当前地月空间开发的主流方向，对未来月球基地建设和任务规划具有重要参考价值。
