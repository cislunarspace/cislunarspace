# minimization indicator

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A category of indicators in comprehensive cost evaluation that have undergone minimization processing. The paper first converts each evaluation indicator parameter into a unified minimization form (via transformation x' = Mj - xj), then performs subsequent normalization to eliminate the influence of dimensional differences between indicators on assessment results.

## Application Value
