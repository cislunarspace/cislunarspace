# Second Cosmic Velocity Reentry Return

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A reentry technique in which a crewed spacecraft enters Earth's atmosphere at approximately second cosmic velocity (~11.2 km/s) directly from cislunar space. Compared to first cosmic velocity reentry from a LEO station, aerodynamic heating is far more severe, demanding higher-performance thermal protection. In the unmanned transfer stage mode, the crewed capsule must independently handle the round trip and high-speed reentry.
