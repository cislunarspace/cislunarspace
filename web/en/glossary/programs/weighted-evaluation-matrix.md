# weighted evaluation matrix

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A matrix constructed from candidate landing zones and evaluation indicators with applied weights in comprehensive cost evaluation. For each landing zone, the paper computes weighted values of six indicators (velocity increment, transfer duration, mission windows, lunar surface stay, regional scientific value, and return landing), forming a matrix used for final ranking analysis.

## Application Value

该系统代表了当前地月空间开发的主流方向，对未来月球基地建设和任务规划具有重要参考价值。
