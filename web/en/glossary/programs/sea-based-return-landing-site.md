# sea-based return landing site

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A sea-surface landing location for crewed spacecraft return. Compared to land-based sites, sea-based sites offer a wider latitude range and more supplementary launch windows, serving as an important complement for increasing window backup capability in assessments of mid-high-latitude landing zone missions.

## Application Value

This concept plays an important role in cislunar space research and applications.
