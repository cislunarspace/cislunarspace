# weighted synthesis

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

The operation of combining multiple evaluation indicators into a single assessment value through weighting. After separately performing minimization and normalization on performance and engineering constraint indicators, the paper computes the weighted sum using pre-determined weights to obtain comprehensive cost evaluation values for each candidate landing zone, used for final ranking.

## Application Value
