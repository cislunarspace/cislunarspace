# comprehensive cost evaluation value

> Author: [Tianjiang Shuo](https://blog.csdn.net/qq_33254264)
>
> Website: [https://cislunarspace.cn](https://cislunarspace.cn)

## Definition

A single numerical value computed through the comprehensive cost evaluation criterion model, quantifying the comprehensive mission cost of different candidate landing zones. The paper obtains this value by weighted summation of normalized performance and engineering constraint indicator values; smaller values indicate lower comprehensive cost and superior landing zones.

## Application Value

This technology is a key component of lunar sample return and crewed lunar landing missions.Through precise orbital control and multi-phase maneuver coordination, safe landing or takeoff of spacecraft at predetermined times and locations can be achieved.
