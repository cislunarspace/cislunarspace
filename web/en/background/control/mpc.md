# Model Predictive Control

## Overview

Model Predictive Control (MPC) is a model-based advanced control strategy. At each sampling instant, it uses a system model to predict behavior over a finite horizon and solves a constrained optimization problem online to obtain the current optimal control input. MPC's ability to explicitly handle state and control constraints makes it uniquely suited for spacecraft formation flying, rendezvous and docking, and attitude control applications.
