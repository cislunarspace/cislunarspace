# 力学基础

地月空间处于地球引力场与月球引力场强烈竞争的过渡带，航天器受力不再由单一中心天体主导。传统的二体开普勒轨道假设在地月空间中完全失效，必须转向基于多体天体力学与非线性动力学理论的统一建模框架。

本子栏目整理地月空间轨道动力学的物理模型、基本方程以及多源摄动环境机理。

### 1. 限制性三体问题（Restricted Three-Body Problem）

限制性三体问题是研究两主天体（地球与月球）在万有引力作用下绕公共质心运动时，微小质量航天器在复合引力场与旋转离心力场中的运动规律。

- **圆型限制性三体（CR3BP）**：假设两主天体绕质心作匀速圆周运动，在旋转坐标系下具有保守的能量积分：雅可比常数（Jacobi Constant）。五大拉格朗日平动点（L1 至 L5）以及零速度面（Zero-Velocity Surfaces）界定了航天器运动的几何禁区。
- **状态转移矩阵（STM）与单值矩阵（Monodromy Matrix）**：刻画小扰动在相空间中的线性传播规律，其本征值谱（Floquet Multipliers）精确决定了轨道的渐近稳定性与不变流形空间走向。

### 2. 天体力学摄动理论（Perturbation Theory）

在地月空间实际运行环境中，除地月基本三体引力外，航天器还受到多源复杂摄动力的综合调制：

- **太阳引力起潮摄动**：在外层地月空间（如 L2 点外侧或 WSB 区域）起主导作用，是实现低能弱稳定边界转移的核心动力源。
- **月球非球形引力摄动（$J_2, C_{22}$ 及质量瘤 Mascon）**：月球引力场高度不均匀，在低月球轨道（LLO）会引发强烈的偏心率漂移与倾角振荡，而对远距离逆行轨道（DRO）或高倾角 NRHO 轨道的影响则相对温和。
- **太阳光辐射压力（SRP）**：对于具有大面积太阳翼或轻质反射材料的航天器，光压加速度会引起轨道共振和周期的缓慢漂移。
