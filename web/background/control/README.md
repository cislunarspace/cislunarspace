# 控制理论

地月空间轨道动力学具有高度非线性、强混沌敏感性以及多时间尺度的特征。在真实飞行任务中，导航定轨误差、推力执行偏差以及复杂空间环境摄动会导致航天器偏离标称轨迹。为了以最少的推进剂消耗保障长期轨道安全，必须建立现代控制与最优优化理论体系。

本子栏目整理地月空间任务设计中的轨迹最优化、自主制导与鲁棒闭环控制方法。

## 核心理论与工程控制方法

### 1. 最优控制理论（Optimal Control Theory）

在满足航天器动力学微分方程与各种推力/姿态约束条件下，求解使性能指标（如消耗推进剂最少、转移时间最短）达到极值的控制输入历史 $\mathbf{u}(t)$。

- **间接法（Indirect Methods）**：基于变分法与**庞特里亚金极大值原理（Pontryagin's Maximum Principle）**，引入协态变量（Costate Variables）构建哈密顿函数，将最优控制问题转化为两点边值问题（TPBVP）。协态变量对初值高度敏感，需配合延拓法求解。
- **直接法（Direct Methods）**：通过控制参数化（Collocation）或状态参数化，将无限维最优控制问题离散转化为有限维非线性规划（NLP）问题。
- 专题阅读：[最优控制理论与变分推导](/background/control/optimal-control/)

### 2. 轨道维持与微分修正（Orbit Maintenance & Differential Correction）

在地月弱不稳定或中性稳定轨道（如 NRHO 与 Halo 轨道）上实施长期自主轨道保持：

- **靶向机动法（Targeting Methods / Cauchy-Green 控制）**：利用状态转移矩阵（STM）预测未来若干周期的位置偏差，在特定关键轨道位置（如近月点或过赤道面点）施加极小速度修正 $\Delta \mathbf{V}$。
- **不变流形方向投影控制**：将状态偏差投影到轨道的稳定与不稳定特征子空间，仅沿不稳定方向施加修正脉冲，最大化利用自然动力学流形收敛能量。

### 3. 先进闭环制导与鲁棒控制

- **模型预测控制（Model Predictive Control, MPC）**：在有限预测时域内滚动在线求解最优机动，能够显式处理推进器推力饱和与视线避障约束。
- **相对轨道动力学与自主交会对接**：在非开普勒三体旋转坐标系下建立相对运动方程，实现绕月空间站（Gateway）进近、停靠与伴随飞行的自主闭环制导。
