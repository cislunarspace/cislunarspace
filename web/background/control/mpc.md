# 模型预测控制

## 概述

模型预测控制（Model Predictive Control, MPC）是一种基于模型的先进控制策略，其核心思想是在每个采样时刻利用系统模型对未来有限时域内的行为进行预测，并在线求解一个带约束的优化问题以获得当前的最优控制输入。MPC 显式处理状态和控制约束的能力使其在航天器编队飞行、交会对接、姿态控制等场景中具有独特优势。
