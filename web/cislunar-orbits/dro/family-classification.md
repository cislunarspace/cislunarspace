# DRO 轨道族分类

## 围绕月球的单一逆行族

首先要澄清一个常见误解：**DRO 并不围绕平动点运动，而是围绕月球运动的逆行周期轨道**。在地月旋转坐标系中，DRO 以月球为中心闭合，轨道尺度远大于月球影响球；其在地心惯性系中同样呈现大椭圆环绕形态。“L1 DRO / L2 DRO”的说法没有依据——那个位置坐标（x ≈ 0.836 / 1.166）属于 L1/L2 平动点本身，而不是 DRO 的几何中心。

在 CR3BP 中，绕月的逆行周期解构成一条单参数族：从小振幅（紧贴月球）到大振幅（接近地月距离量级）连续延拓，周期随振幅单调增长。工程关注的中大振幅成员典型振幅为 4 万至 10 万公里量级，对应周期约两周；我国中科院先导专项 DRO-A/B 双星采用的是 2:1 会合共振 DRO，周期约 14 天。

| 参数 | 典型范围 |
| ------ | -------- |
| 振幅 | 40,000–100,000 km |
| 典型周期 | 约 10–16 天（随振幅增大变长） |
| 雅可比常数 | 接近 3.0（依振幅略变） |

> 周期与振幅的具体取值依赖所用动力学模型（CR3BP/ER3BP/星历），上表给出的是任务设计常用的数量级。

## 平面族与三维桥接族

经典 DRO 位于旋转坐标系的地月旋转平面内，是一条纯平面周期轨道族，天然不存在“南族/北族”之分（对平面内轨道作 z → −z 反射仍得到轨道自身）。

值得关注的结构性特征来自分岔：沿族延续过程中，DRO 会依次穿越**倍周期分岔**（产生 Butterfly 等派生族）与**垂直自共振分岔**（Vertical Self-Resonant Bifurcation）。越过垂直自共振点后，平面族与空间族之间出现一系列**桥接族**（bridging families）：连接平面逆行轨道与三维顺行空间轨道，形成蜻蜓型（Dragonfly）、食蚜蝇型（Hoverfly）等高倾角/极轨类形态。这一系列桥接族为需要大倾角覆盖的驻留与观测任务提供了从稳定平面族出发的设计入口。

## 与 Lyapunov 轨道的关系

早期文献常从 L1/L2 平动点周期轨道分岔链的角度描述 DRO 的来源：随着能量变化，部分分支经倍周期等分岔关系与 Lyapunov/Halo 族相联系。但就几何而言，DRO 始终以月球为中心，不应将其描述为“位于 L1 或 L2 点附近的轨道”。
