# 空间目标检测（Space Object Detection）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：[地月空间入门指南](https://cislunarspace.cn)

## 定义

在天文图像中识别和定位空间目标的技术，流程包括背景估计、目标检测和目标亮度解算三个步骤。地月空间目标因距离远、信号弱，检测难度远高于近地空间，需结合传统光度分析与深度学习方法。

## 应用价值

空间目标检测通过背景估计、目标检测和亮度解算流程识别天文图像中的空间目标，地月空间目标因距离远、信号弱，检测难度远高于近地空间目标。
