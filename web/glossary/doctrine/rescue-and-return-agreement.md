# 救援与返回协定（Rescue and Return Agreement）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

1968年《关于救回宇航员、送回宇航员和送回发射入太空物体的协定》，规定缔约国有义务救回和援助因事故、危难、紧急或意外降落而着陆的航天器人员。

## 应用价值

该术语在地月空间相关研究和工程实践中具有应用价值，有助于理解该领域的技术体系和操作方法。
