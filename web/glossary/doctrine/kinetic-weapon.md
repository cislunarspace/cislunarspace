# 动能武器（Kinetic Weapon）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 来源：丰松江等(2021)《印度航天力量发展与战略重点探析》
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

动能武器（Kinetic Weapon）是指通过物理撞击方式摧毁目标的武器系统。在太空作战中，动能武器通常指用于击毁或损伤敌方卫星的地基拦截器。2019 年印度成功进行反卫星试验，使用地基弹道导弹以直接上升共面碰撞方式击毁了"微星-R"卫星，标志着印度动能反卫星能力的突破。

## 杀伤机制

动能武器通过以下机制实现对目标的摧毁：

- **直接碰撞**：利用高速飞行器与目标卫星发生物理碰撞
- **动能释放**：通过巨大的动能释放造成目标结构破坏
- **碎片伤害**：碰撞产生的碎片进一步损伤目标

## 印度动能武器发展

### 反卫星试验

2019 年 3 月 27 日，印度成功实施首次地基反卫星试验：

- **拦截方式**：直接上升共面碰撞
- **发射平台**：陆基弹道导弹
- **发射地点**：奥里萨邦惠勒岛
- **目标卫星**：微星-R，运行在 266\~290 千米轨道
- **试验结果**：成功击毁目标卫星

### 发展规划

根据印度《2010—2025 年技术远景及能力路线图》：

| 时间节点 | 能力目标 |
| ---------- | ---------- |
| 2020 年前 | 部署动能攻击漂浮拦截器 |
| 2022 年后 | 研发物理摧毁低轨和地球同步轨道卫星的反卫星武器 |
| 2027 年后 | 列装 4 套反卫星导弹系统 |

## 技术特点

动能武器相比定向能武器的特点：

| 特点 | 动能武器 | 定向能武器 |
| ------ | ---------- | ------------ |
| 打击速度 | 需飞行时间 | 光速 |
| 杀伤效果 | 物理摧毁 | 可控（干扰至摧毁） |
| 天气影响 | 受影响较小 | 受影响较大 |
| 能量需求 | 较低 | 极高 |

## 战略影响

动能反卫星能力的建立产生以下战略影响：

- **太空碎片**：碰撞产生的碎片威胁正常卫星安全
- **军备竞赛**：可能引发反卫星武器竞赛
- **太空治理**：对现行太空国际法规形成挑战
- **作战样式**：开创太空战先例
