# CAPSTONE 任务（CAPSTONE Mission）

> 本文作者：天疆说
>
> 本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

CAPSTONE 全称 Cislunar Autonomous Positioning System Technology Operations and Navigation Experiment，是 NASA 与 Advanced Space 公司合作研制的技术验证任务，用作月球附近近直线晕轨道运行的探路者 \cite{agasid2025cislunar}。任务目标轨道即 Artemis 计划中 Gateway 小型有人照料月轨空间站的预定轨道：近月点半径约 3200 km、远月点半径约 70000 km \cite{agasid2025cislunar}。任务通过在轨运行验证仿真与运行规划，并检验 Gateway 电源与推进元件导航和站位保持需求的性能，为后续工程积累在轨经验 \cite{agasid2025cislunar}。

## 导航试验与任务进展

- **导航技术验证**：CAPSTONE 搭载的地月导航技术验证包括自主定轨能力，利用一颗航天器与月球轨道器的星间测量支持自主定位，减少对地面测控的依赖 \cite{Thompson2022}。
- **自主定位试验**：任务在轨持续推进地月自主定位试验，为地月空间导航体系提供实测数据 \cite{Stuit2023}。
- **任务更新**：入轨后的持续运行与机动结果表明站位保持策略满足近直线晕轨道的任务需求，相关进展为 Gateway 任务设计提供直接参考 \cite{gardnerCAPSTONEMissionUpdates2023}。

## 意义

CAPSTONE 把近直线晕轨道从纸面设计推向在轨验证，其导航与站位保持实测直接支撑 Gateway 任务体系，也为地月空间其他平动点轨道任务提供了先例 \cite{agasid2025cislunar}。
