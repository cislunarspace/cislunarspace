# 行星系统巡游（Planetary System Tour）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：[地月空间入门指南](https://cislunarspace.cn)

## 定义

利用三体动力学和不变流形，在一个行星的卫星系统内依次环绕多颗卫星执行科学任务的轨道策略。论文以天王星系统为例，设计了从最外卫星天卫四（Oberon）到最内卫星天卫五（Miranda）的巡游方案，在每颗卫星附近执行多圈闭合轨道环绕，总飞行时间约 930 天，总速度增量仅 2.04 km/s。

## 应用价值

行星系统巡游利用三体动力学和不变流形在一个行星卫星系统内依次环绕多颗卫星，设计师在规划深空探测任务时以最小能量消耗实现多目标科学探测。
