# 自由返回轨道（Free-Return Trajectory）

> 本文作者：天疆说
>
> 本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

自由返回轨道是一类地月转移轨道，航天器从地球出发飞掠月球后，即使不实施任何轨道机动，也能在月球引力作用下自动返回地球并进入再入走廊。这一性质使其成为载人月球任务的安全保障设计：当服务舱发动机失效时，乘组仍可沿该轨道安全返回地球 \cite{BaiYuZhuZaiRenDengYueZiYouFanHuiGuiDaoYuHybridGuiDaoSheJiFangFa2010}。典型的自由返回轨道在地心段顺行、到达月球附近后相对月球逆行，见[地心顺行月心逆行](/glossary/orbits/prograde-in-perigee-and-retrograde-in-perilune/)。

## 谱系与设计方法

自由返回轨道的概念可追溯到 Apollo 时代的任务安全设计。白于柱等系统研究了载人登月自由返回轨道与 Hybrid 轨道设计方法，讨论了自由返回与月球轨道插入相结合的方案 \cite{BaiYuZhuZaiRenDengYueGuiDaoSheJiXiangGuanWenTiYanJiu2010,BaiYuZhuZaiRenDengYueZiYouFanHuiGuiDaoYuHybridGuiDaoSheJiFangFa2010}。彭坤与杨雷给出了地月空间对称自由返回轨道族的设计与分析，揭示了轨道族关于地月连线的对称结构 \cite{PengKunDiYueKongJianDuiChengZiYouFanHuiGuiDaoSheJiYuFenXi2018}。贺波勇等针对典型约束给出了载人登月自由返回轨道窗口的存在性判据，把窗口问题化为约束可行性的解析判断 \cite{HeBoYongDianXingYueShuDeZaiRenDengYueZiYouFanHuiGuiDaoChuangKouCunZaiXingPanJu2022}。

## 全飞行过程设计与入轨衔接

彭祺擘等在星历模型下完成了地月自由返回全飞行过程的轨道设计，覆盖发射、地月转移、月面近距离飞掠与返回再入各阶段，并在高保真模型下验证了轨道的自返回特性 \cite{PengQiBoXingLiMoXingXiaDiYueZiYouFanHuiQuanFeiXingGuoChengGuiDaoSheJi2023}。自由返回轨道也常作为其他任务设计的基础构件：从自由返回轨道出发经小机动可进入月球轨道，Jesick 与 Ocampo 研究了从自由返回轨道实施最优月球轨道插入的问题 \cite{jesick2012optimal}。基于地月自由返回轨道的远距离逆行轨道入轨策略见[远距离逆行轨道](/glossary/orbits/distant-retrograde-orbit-dro/)。
