# 日地系统（Sun-Earth System）

> 本文作者：天疆说
>
> 本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

日地系统指以太阳与地球为两个主天体的圆型限制性三体问题模型，是地月系统之外与深空任务关系最密切的三体系统。日地平动点 L1 与 L2 位于地球两侧约 150 万千米处，通信与测控条件良好，多颗太阳观测与天体物理卫星运行于其邻近的晕轨道与 Lissajous 轨道上。L3 位于太阳背面，因长期背地对通信极为不利而至今未被利用 \cite{tantardiniSpacecraftTrajectoriesL32010}。

## 轨道与任务

- Genesis 任务：在日地 L1 邻近的晕轨道上采集太阳风样本并返回地球，其任务修正机动可由动力系统理论与最优控制相结合系统计算 \cite{serbanHaloOrbitMission2002}。Genesis 轨迹还展示了晕轨道之间经异宿连接实现低代价转移的可能性 \cite{koonGenesisTrajectoryHeteroclinic1999}。
- L2 邻近的保持研究：面向 TPF 任务的平动点轨道保持研究给出了日地 L2 附近 Lissajous 类轨道的保持策略 \cite{gomezStudyStationKeeping2006}。
- 与地月系统的自然连接：日地与地月 Lissajous 轨道之间存在自然转移通道，把两个三体问题的流形在适当历元拼接并精化至星历模型，可得到低代价连接轨道 \cite{canaliasComputingNaturalTransfers2008}。

## 与地月低能转移的联系

日地 L1 与 L2 平动点轨道的不变流形构成从地球附近通向月球低能转移的动力学通道，弱稳定边界方法正是利用了这类结构，经异宿连接把日地流形与地月流形衔接起来 \cite{fantinoNoteLibrationPoint2010}。日地月系统的探测任务设计进一步把日地段转移与地月段转移统一考虑，形成四体框架下的任务轨道体系 \cite{renk2010exploration}。
