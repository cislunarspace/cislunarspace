# Danuri月球轨道器

>来源：KASA官方资料及公开报告
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 概况

Danuri是韩国首个月球轨道器，于2022年8月4日由SpaceX猎鹰9号火箭发射升空。"Danuri"是韩国语"感谢"和"月球"的组合，表达了对月球探索的美好愿望。Danuri的成功发射使韩国正式成为月球探测国家之一。

## 任务目标

Danuri的主要任务目标包括：

- **月球资源勘探**：利用科学载荷对月球表面资源进行探测分析
- **月表环境观测**：研究月球表面的环境特性
- **空间通信技术验证**：验证地月空间远距离通信技术
- **国际合作**：参与国际月球探测合作项目

## 科学载荷

Danuri搭载了多项科学载荷：

| 载荷名称 | 功能 | 说明 |
| --------- | ------ | ----- |
| 地形成像仪 | 月表高分辨率成像 | 用于月面地形测绘 |
| 月球磁场计 | 月球磁场测量 | 研究月球磁场特性 |
| 伽马射线谱仪 | 月表元素成分分析 | 探测月球表面元素分布 |
| 通信实验载荷 | 地月激光通信 | 验证高速激光通信技术 |

## 技术特点

### 轨道设计

Danuri采用弹道式转移轨道（Balletistic Lunar Transfer，BLT），利用太阳引力辅助到达月球，降低燃料消耗：

- 转移时间约4个月
- 燃料效率高
- 对发射窗口要求相对宽松

### 通信系统

- 配置Ka频段通信系统
- 搭载激光通信终端，验证地月空间高速通信

## 任务历程

| 时间 | 事件 |
| ----- | ------ |
| 2022年8月4日 | 发射升空 |
| 2022年12月 | 进入月球轨道 |
| 2023年至今 | 持续执行科学探测任务 |

## 后续计划

KASA在Danuri成功的基础上，继续推进月球探测计划第二阶段：

- **月球着陆器**：计划2032年实现月球软着陆
- **月球基地**：计划2040年建立月球基地
- **国际合作**：积极参与阿尔忒弥斯计划

## 意义

Danuri的成功对韩国航天发展具有重要意义：

- 验证了韩国深空探测能力
- 积累了月球任务工程经验
- 培养了月球探测专业人才
- 为后续月球任务奠定基础
