# 极地轨道卫星运载火箭（PSLV）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 来源：丰松江等(2021)《印度航天力量发展与战略重点探析》
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

极地轨道卫星运载火箭（Polar Satellite Launch Vehicle，简称 PSLV）是印度空间研究组织（ISRO）研发的大型运载火箭，于 1994 年成功首飞。PSLV 是印度目前使用最广泛的运载火箭之一，具有一箭多星发射能力，可将卫星送入近地轨道（LEO）、极地轨道、地球同步转移轨道（GTO）和月球轨道。

## 技术参数

| 参数 | 数值 |
| ------ | ------ |
| 近地轨道运载能力 | 约 3500 千克（400 km 高度） |
| 太阳同步轨道能力 | 约 1700 千克 |
| 地球同步转移轨道能力 | 约 1420 千克 |
| 月球轨道能力 | 约 590 千克 |
| 首次发射 | 1994 年 |

## 发射能力

PSLV 以其可靠性著称，截至目前已完成多次发射任务：

- **近地轨道发射**：可向约 400 千米高度的近地轨道运送约 3500 千克载荷
- **极地轨道发射**：适用于太阳同步轨道任务
- **一箭多星**：2017 年印度通过 PSLV 实现"一箭 104 星"发射，创下当时的世界纪录
- **深空探测**：具备向月球轨道发射探测器的能
