# 边值问题（Boundary Value Problem）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：[地月空间入门指南](https://cislunarspace.cn)

## 定义

同时给定初始和终端状态条件，求满足这些条件的轨道的问题，是轨道设计的基本问题之一。

## 应用价值

边值问题是指定始末状态求中间轨道的问题，轨道设计师通过求解边值问题获得精确的转移轨道。
