# 可达集问题（Reachability Set Problem, RSP）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

在给定初始位置和速度的一定范围下，确定卫星所有可能最终位置的集合问题。

## 应用价值

该问题或方程描述了航天器运动的基本规律。通过求解和分析，可以获得轨道设计的解析或数值解，为任务规划提供理论指导。
