# 切换函数（Switching Function）

切换函数是燃料最优控制中的一个标量函数，用于确定推力方向的切换时刻。在 Bang-Bang 控制策略中，当切换函数为正时推力开启，为负时推力关闭，过零点即为切换时刻。
