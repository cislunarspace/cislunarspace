# 流函数法（Stream Function Method）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

通过调整雅可比常数连续追踪周期轨道族的数值方法。以雅可比常数为连续参数，对一族周期轨道逐点计算，得到不同轨道参数（如共振比）对应的远距离逆行轨道。

## 应用价值

在周期轨道设计中，该指标用于评估轨道的有界性和长期稳定性，指导轨道维持策略的制定。

## 相关概念

- 稳定特征向量（Stable Eigenvector）
- 月球飞越法（Lunar Fly-by Method）
- 可达集（Reachability Set）
