# 显式状态变换（Explicit State Transformation）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

可直接由前一段末端状态计算后一段初始状态的解析表达式。

## 应用价值

显式状态变换是将状态变量显式表达为其他变量的函数关系的数学变换。在轨道动力学中，恰当的状态变换可以简化运动方程、揭示物理本质，或将高阶系统化为标准型，是系统分析和控制器设计的重要工具。
