# 机动执行误差（Maneuver Execution Error）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：[地月空间入门指南](https://cislunarspace.cn)

## 定义

修正机动执行时的大小和方向偏差，可建模为固定大小的随机方向误差。

## 应用价值

机动执行误差表现为固定大小的随机方向误差，轨道设计师在规划轨道保持机动时将这一误差作为不确定性因素纳入分析，确保任务可靠性。
