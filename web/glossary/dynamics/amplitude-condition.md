# 幅值条件（Amplitude Condition）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：学术论文与专业资料整理
>
> 站长地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

圆型限制性三体问题中，面内振幅Ax与面外振幅Az之间的非线性耦合约束关系，由Richardson解析框架中的固定系数l₁、l₂和Δ确定，表达式为l₁Ax² + l₂Az² + Δ = 0。此条件确保Halo轨道三阶近似解保持周期性，Ax与Az并非独立参数，而是必须满足该二次型约束。当振幅组合偏离幅值条件时，轨道退化为Lissajous型非闭合轨迹。

## 应用价值

幅值条件 l₁Ax² + l₂Az² + Δ = 0 确保 Halo 轨道三阶近似解保持周期性。当振幅组合偏离幅值条件时，轨道退化为非闭合的 Lissajous 型轨迹。
