# 蒙特卡洛树搜索（Monte Carlo Tree Search, MCTS）

## 定义

蒙特卡洛树搜索（Monte Carlo Tree Search, MCTS）是一种基于随机采样的启发式搜索算法，通过反复模拟来构建和优化决策树，逐步收敛到最优决策。在航天领域，MCTS 被应用于轨道机动规划、自主避碰决策和多航天器协同操作等场景，尤其适用于决策空间庞大、难以穷举的复杂规划问题。
