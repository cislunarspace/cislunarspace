# 月球最优回归时间（optimal lunar return time）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

伪状态理论中使伪球近似精度达到最高的月球引力辅助回归时间，约为整个飞行时间的65%。论文以此作为摄动引力辅助模型的关键参数，用于确定伪球的边界半径，进而划分精确动力学计算区域与圆锥曲线近似计算区域。

## 应用价值

在轨道设计和控制中，该概念对理解航天器在地月空间中的运动特性和任务设计具有重要作用。
