# 地心天体参考框架（Geocentric Celestial Reference Frame）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

地球的当前标准惯性坐标系统，以ICRF为参考，1997年正式采用，有效替代了IAU-76/FK5 J2000系统。

## 应用价值

在轨道计算和任务分析中，正确的坐标参考框架是保证计算结果一致性的基础。不同参考框架之间的转换需要考虑该定义，以确保多源数据的统一处理。
