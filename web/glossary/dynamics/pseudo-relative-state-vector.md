# 伪相对状态向量（Pseudo-Relative State Vector, ρ*）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

为满足截锥约束而定义的修正相对位置向量，通过偏移使锥面约束转化为线性约束。

## 应用价值

在相对运动分析中引入的虚拟状态向量，用于简化相对轨道动力学的分析和设计。
