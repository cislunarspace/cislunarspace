# 航迹角（The angle between the spacecraft velocity vector and the local horizontal plane. A flight path angle of zero indicates the velocity is tangent to the local horizontal, corresponding to the periapsis (or apoapsis) characteristic. The paper uses flight path angle as the differential correction termination condition: integration halts when the angle reaches zero with a negative derivative, identifying the perilune point for constraint evaluation.）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

航天器速度矢量与当地水平面之间的夹角。在转移轨道设计中，航迹角为零表示航天器速度方向恰好沿当地水平方向切向，对应近月点（或远月点）的特征。文中将航迹角作为微分修正的终止条件：积分至航迹角为零且导数为负时，判定到达近月点，从而提取该时刻的月心距用于约束修正。

## 应用价值

在航迹角的分析中，可用于轨道传播和机动设计，帮助工程师评估航天器在不同动力学环境下的运动特性。
该概念为地月空间任务设计提供了理论基础，尤其在平动点轨道设计和低能转移分析中具有重要应用价值。
利用航迹角进行轨迹优化，可以有效降低任务燃料消耗，提高任务经济效益。
在任务设计中，航迹角的分析有助于理解航天器在复杂引力场中的行为，指导轨道保持策略的制定。
