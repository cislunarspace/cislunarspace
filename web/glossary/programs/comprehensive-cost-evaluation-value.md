# 综合代价评估值（comprehensive cost evaluation value）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

通过综合代价评估准则模型计算得出的单一数值，用于量化不同候选着陆区的综合任务代价。论文通过加权求和效能评价指标和工程约束指标的归一化值得到该值，值越小表示综合代价越低、着陆区越优。

## 应用价值

该技术是月球采样返回和载人登月任务的关键环节。通过精确的轨道控制和多阶段机动协同，可以实现探测器在预定时刻和位置的安全着陆或起飞。
