# 大气减速制动返回（Atmospheric Braking Return）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：学术论文与专业资料整理
>
> 站长地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

飞行器返回近地轨道时利用地球大气阻力进行减速的返回技术。与推进制动返回相比，无需额外消耗推进剂，但飞行器需具备防热结构承受气动加热，存在烧蚀损耗。论文将此作为地月转移级返回空间站的两种制动方式之一，与推进制动方案进行对比评估。

## 应用价值

利用地球大气阻力减速无需消耗推进剂，但需要防热结构承受气动加热。在可重复使用运载器的设计中，大气减速制动是一种经济高效的返回方案。
