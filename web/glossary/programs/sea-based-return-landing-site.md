# 返回海上着陆场（sea-based return landing site）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

位于海面上的载人飞船返回着陆地点。相比陆上着陆场，海上着陆场因纬度范围更广，可提供更多的补充发射窗口，在中高纬度着陆区的任务评估中可作为增加窗口备份能力的重要补充方案。

## 应用价值

该任务是地月空间探索体系的重要组成部分，其成功实施将为未来月球资源开发和深空探测奠定基础。
