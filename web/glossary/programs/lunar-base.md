# 月球基地（Lunar Base）

月球基地是指在月球表面或月球轨道上建立的长期驻留设施，用于开展科学研究、资源原位利用和深空探测中转。以NASA Artemis计划为代表的国际合作项目正在推动月球南极区域基地建设，为未来火星任务奠定基础。
