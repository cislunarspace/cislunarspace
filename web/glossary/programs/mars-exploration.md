# 火星探测（Mars Exploration）

火星探测是指对火星及其周围空间进行的无人或载人科学探索活动，涵盖轨道器、着陆器、巡视器等多种任务形式。中国的天问系列、美国的Perseverance火星车以及未来的载人火星任务，共同推动着人类对火星环境、地质和潜在生命迹象的认知。
