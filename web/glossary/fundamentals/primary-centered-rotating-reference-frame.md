# 主星中心旋转坐标系（Primary-Centered Rotating Reference Frame）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

以两个主天体之一为原点、随系统旋转的参考系。单位向量由两天体连线方向和系统角速度方向定义，用于分析三体系统中航天器的运动。

## 应用价值

在航天器动力学分析与设计中，该坐标系用于描述航天器位置和姿态，是导航计算的基础参考系。
