# 飞行路径角（Flight Path Angle, FPA）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

速度矢量与当地水平面之间的夹角。在月面着陆场景中，飞行路径角决定了着陆轨迹的陡峭程度：垂直撞击对应90度，掠射对应接近0度。该参数直接影响着陆器的热防护和制导需求。

## 应用价值

基于该术语的定义，速度矢量与当地水平面之间的夹角。在月面着陆场景中，飞行路径角决定了着陆轨迹的陡峭程度：垂直撞击对应9。
