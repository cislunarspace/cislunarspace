# 合成孔径雷达（SAR）

合成孔径雷达（Synthetic Aperture Radar, SAR）是一种主动式微波遥感技术，通过雷达平台的运动合成等效大孔径天线，从而在方位向上实现高分辨率成像。SAR具有全天时、全天候的观测能力，广泛应用于地形测绘、海洋监测和灾害评估等领域。
