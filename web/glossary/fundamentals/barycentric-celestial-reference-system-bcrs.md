# 质心天球参考系（Barycentric Celestial Reference System, BCRS）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

以太阳系质心为原点的相对论时空参考系，度规张量由IAU决议给出，时间坐标采用质心坐标时（TCB）或质心力学时（TDB）。在地月空间高精度定轨和星间单向链路数据处理中，BCRS比GCRS更为适宜。

## 应用价值

质心天球参考系是分析地月空间动力学问题的理论基础，为航天器轨道设计、任务规划和控制策略制定提供数学支撑。
针对质心天球参考系的深入研究有助于理解地月空间复杂动力学环境，为未来任务设计提供理论支撑和工程参考。
在实际任务中，需要结合数值仿真和解析方法对质心天球参考系进行分析验证，确保设计方案满足任务约束和性能指标。
