# 同步旋转坐标系（Synodic Reference Frame）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

以两个主天体的质心为原点、随两体连线旋转的非惯性坐标系。在此坐标系中，两个主天体的位置固定，CR3BP 的运动方程中出现科氏力和离心力项。论文在各卫星的同步旋转坐标系中计算流形，再通过坐标变换统一到天王星-天卫四参考系下构建巡游轨迹。

## 应用价值

该概念是地月空间坐标系统与参考系定义的基础，是轨道力学与导航计算的基准。
