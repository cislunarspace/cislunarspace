# 边界值问题（Boundary Value Problem）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：学术论文与专业资料整理
>
> 站长地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

在微分方程的求解中，已知变量在定义域边界上的值（而非初始值），求解域内变量分布的问题。与初值问题相对。本文提出的方法核心创新在于：将碎片云演化从蒙特卡洛初值问题转化为地月空间边界值问题，已知碎片出发位置r1和到达位置r2，求解所需的转移速度，从而直接获得特定位置处的碎片概率密度。

## 应用价值

边界值问题已知变量在边界上的值求域内分布，是轨道设计中性问题转化的核心工具。将碎片云演化从蒙特卡洛初值问题转化为边界值问题是本文的创新点。
