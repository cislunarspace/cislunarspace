# 平流层飞艇（Stratospheric Airship）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

平流层飞艇是指在平流层高度（约 18-50 km）执行长航时飞行任务的轻于空气（LTA）浮空平台。相比传统飞艇，平流层飞艇需要在极端低温、低气压、强紫外线辐射环境中维持稳定运行，并实现数天至数月的连续驻留能力。

## 结构特征

### 主体结构

| 组件 | 功能描述 |
|:---|:---|
| 蒙皮（Envelope） | 充氦气密结构，外表面涂覆防辐射涂层 |
| 副气囊（Ballonet） | 内部充气气囊，用于调节浮力和姿态 |
| 囊体（Crew/Gondola） | 承载有效载荷、动力系统和控制设备 |
| 尾翼/翼面 | 提供气动稳定性和操稳控制 |

### 技术特点

- **轻于空气设计**：依靠氦气静升力维持飞行，无需持续推进
- **长航时能力**：利用太阳能和储能系统实现数周至数月连续运行
- **高驻留高度**：运行于云层之上，不受天气影响
- **区域驻留**：通过主动控制维持相对地面的指定区域位置

## 关键技术挑战

1. **浮重平衡**：氦气泄漏和昼夜温差导致浮力变化，需要主动调控氦气量和配重
2. **结构疲劳**：蒙皮材料在紫外的长期照射下老化
3. **能源供给**：高功率载荷的持续供能问题
4. **风场扰动**：平流层强风环境的姿态和位置控制

## 应用场景

- **通信中继**：为偏远地区提供宽带通信覆盖
- **对地观测**：高分辨率地球观测和气象监测
- **导航增强**：辅助卫星导航系统
- **临近空间研究**：大气科学和空间物理研究平台
