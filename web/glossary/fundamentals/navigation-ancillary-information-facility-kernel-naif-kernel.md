# NAIF星历内核（Navigation Ancillary Information Facility Kernel, NAIF Kernel）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

NASA提供的天体历文件格式，包含行星和航天器的位置速度信息，用于高保真动力学模型。

## 应用价值

该参考坐标系是进行轨道力学分析和任务设计的基础，在实际应用中需根据任务需求选择合适的坐标系。
