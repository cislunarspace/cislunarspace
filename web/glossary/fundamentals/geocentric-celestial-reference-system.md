# 地心天球参考系（Geocentric Celestial Reference System）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

以地心为原点的参考系，现行地球卫星星历在其中描述，时间引数为地心坐标时(TCG)或地球力学时(TDB)。当地球卫星与地月空间探测器进行星间建链时，需要进行GCRS与BCRS之间的坐标转换。

## 应用价值

地心天球参考系是分析地月空间动力学问题的理论基础，为航天器轨道设计、任务规划和控制策略制定提供数学支撑。
针对地心天球参考系的深入研究有助于理解地月空间复杂动力学环境，为未来任务设计提供理论支撑和工程参考。
在实际任务中，需要结合数值仿真和解析方法对地心天球参考系进行分析验证，确保设计方案满足任务约束和性能指标。
