# 再入航迹角（Reentry Flight Path Angle）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

飞行器再入地球大气时速度矢量与当地水平面之间的夹角。自由返回轨道设计中需满足再入航迹角约束（如 -6 度），以确保飞行器沿正确的弹道进入大气层。

## 应用价值

在轨道力学分析和任务设计中，该概念为轨道特性评估和方案比选提供理论依据，有助于优化轨道设计参数，提高任务经济性。
