# 勇号（Nuri，KSLV-II）

勇号（Nuri，官方名称KSLV-II）是韩国自主研制的运载火箭，由韩国航空宇宙研究院（KARI）主导开发，是韩国首个完全自主研发的轨道级运载火箭。该火箭具备将1.5吨级有效载荷送入低地球轨道的能力，标志着韩国正式迈入自主航天发射国家行列。
