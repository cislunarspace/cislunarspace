# 伪势能函数（Pseudo-Potential Function）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：学术论文与专业资料整理
>
> 站长地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

圆型限制性三体问题中，将引力势能与旋转坐标系离心势能合并后得到的等效势能函数。在归一化单位下，U = (x^2 + y^2)/2 + (1-μ)/r_1 + μ/r_2，其中r_1、r_2为小天体到两大天体的距离，μ为质量比。该函数的梯度决定了小天体所受的惯性力（引力加离心力），零梯度点即为平动点。科里奥利力不出现在伪势能中，需在运动方程中单独处理。

## 应用价值

伪势能函数将引力势能与离心势能合并，零梯度点即为平动点。在圆型限制性三体问题的定性分析中，伪势能函数是理解轨道拓扑结构的重要工具。
