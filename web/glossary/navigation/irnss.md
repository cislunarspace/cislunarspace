# 印度区域导航卫星系统（IRNSS）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 来源：丰松江等(2021)《印度航天力量发展与战略重点探析》
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

印度区域导航卫星系统（Indian Regional Navigation Satellite System，简称 IRNSS）是印度研发的独立区域卫星导航系统，也被称为 NavIC（Navigation with Indian Constellation）。首颗卫星于 2013 年发射，目前共有 8 颗导航卫星在轨工作。IRNSS 可为印度本土及周边 1500\~2000 千米范围内的用户提供全天候全天时的定位、导航和授时服务。

## 技术参数

| 参数 | 数值 |
|------|------|
| 卫星数量 | 8 颗（3 颗地球静止轨道 + 5 颗倾斜地球同步轨道） |
| 覆盖范围 | 1500\~2000 千米（南亚及印度洋地区） |
| 定位精度（印度本土） | 小于 10 米 |
| 定位精度（印度洋区域） | 小于 20 米 |
| 服务类型 | 民用标准定位服务 + 军用授权服务 |
| 首次发射 | 2013 年 |

## 系统组成

IRNSS 星座包括：

- **3 颗地球静止轨道卫星**（GEO）：位于印度上空特定经度
- **5 颗倾斜地球同步轨道卫星**（IGSO）：覆盖印度全境

## 服务能力

IRNSS 提供两类服务：

- **标准定位服务（SPS）**：面向民用用户，提供开放服务
- **精密服务（PPS）**：面向授权军事用户，提供更高精度服务

## 战略意义

IRNSS 的建立使印度摆脱了对美国 GPS 系统完全依赖的状况，具有重要战略意义：

- **独立自主**：拥有独立的卫星导航能力，不受他国控制
- **国家安全**：为军事行动提供独立的导航支持
- **区域影响**：增强印度在南亚及印度洋地区的战略影响力

## 与 GAGAN 的关系

GAGAN 是 GPS 增强系统，依赖 GPS 信号；IRNSS 是独立系统。两者的区别在于：

- GAGAN：增强 GPS，不具备独立导航能力
- IRNSS：独立自主的导航系统，不依赖外部系统
