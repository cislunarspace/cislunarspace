# 状态噪声补偿矩阵（State Noise Compensation Matrix）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

扩展卡尔曼滤波中用于补偿未建模动力学误差的噪声矩阵，对角矩阵，其元素大小取决于未建模误差的量级，用于防止状态协方差矩阵过快收缩。

## 应用价值

该术语在地月空间任务的设计、分析和控制中具有重要应用价值，为相关技术领域的研究和工程实践提供理论支撑。
