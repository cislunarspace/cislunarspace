# GPS辅助地球增强导航系统（GAGAN）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 来源：丰松江等(2021)《印度航天力量发展与战略重点探析》
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

GPS辅助地球增强导航系统（GPS Aided GEO Augmented Navigation，简称 GAGAN）是印度研发的星基增强系统（SBAS），用于修正并增强美国 GPS 导航卫星的民用信号。GAGAN 可将 GPS 的定位精度由原来的 10\~15 米提高到约 1 米，显著提升印度及周边地区的导航定位性能。

## 技术特点

| 指标 | 数值 |
|------|------|
| GPS 原始精度 | 10\~15 米 |
| GAGAN 增强精度 | 约 1 米 |
| 覆盖范围 | 印度本土及周边地区 |
| 系统类型 | 星基增强系统（SBAS） |

## 系统组成

GAGAN 系统由以下部分组成：

- **地面参考站网络**：收集 GPS 信号并计算误差校正数据
- **地面主控站**：处理误差数据并生成增强信息
- **地球同步卫星**：向用户转发增强信号
- **用户设备**：接收增强信号并提供高精度定位

## 应用场景

GAGAN 主要应用于：

- **民用航空**：为飞机起降和航路飞行提供精密进近支持
- **地面交通**：提高车辆导航和交通管理精度
- **精确农业**：支持农机自动驾驶和精准作业
- **测绘地理信息**：提供高精度定位基准

## 与 IRNSS 的关系

GAGAN 依赖 GPS 系统，不具备独立导航能力。印度建立的本土独立导航系统是印度区域导航卫星系统（IRNSS），两者共同构成印度的卫星导航体系。
