# 权重网格点（Weighted Grid Point）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

根据服务优先级赋予不同权值的网格点。在多目标优化中，通过提高关键区域的权值（如将地月转移关键区域权值设为10而其他区域默认为1），确保优化结果优先满足高优先级区域的服务质量需求。

## 应用价值

该概念在地月空间导航与轨道确定中具有应用价值，可提高任务执行的精确性与可靠性。
