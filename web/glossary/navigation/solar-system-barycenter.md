# 太阳系质心（Solar System Barycenter）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

太阳系质量中心，作为脉冲星观测和深空导航的惯性参考点。

## 应用价值

在航天器导航与定轨中，该概念对理解航天器在地月空间中的运动特性和任务设计具有重要作用。
