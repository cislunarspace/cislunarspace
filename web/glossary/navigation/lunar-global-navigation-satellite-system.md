# 月球全球导航卫星系统（Lunar Global Navigation Satellite System）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

为月球表面及近月空间用户提供全域定位、导航与授时服务的卫星星座系统。设计思路承袭地球GNSS星座架构，通过在月球轨道部署导航卫星实现全月面覆盖。典型方案融合远距离逆行轨道、L1和L2点Halo轨道卫星，兼顾月球极区与赤道覆盖，且轨道稳定、维持成本较低。

## 应用价值

在轨道设计阶段，可利用该轨道类型构建候选轨道池，为星座部署和任务轨道选择提供参考。在轨运行时，该轨道特性可用于轨道维持策略设计，降低推进剂消耗。在轨道转移规划中，其稳定流形结构可指导低能量转移走廊的搜索。
