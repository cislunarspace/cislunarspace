# 用户测距误差（User Range Error）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

包含卫星钟差、大气延迟、多径效应等误差源在内的等效测距误差。导航定位误差等于几何精度衰减因子（GDOP）乘以用户测距误差。

## 应用价值

在导航系统设计中，该技术可用于实现航天器自主导航定位，减少对地面测控的依赖。通过优化观测几何和算法精度，可提高导航定位的准确性和可靠性。
