# 作差线性组合（Difference Linear Combination）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

双向单程测量中，将两条对向链路的码伪距取半差的操作。该组合消除了大部分几何距离信息，保留了星间相对钟差、钟漂和频漂信息，专用于时间同步中的相对时钟参数估计。信号传播时间短时，几何距离修正项较小。

## 应用价值

该方法可用于提高地月空间导航精度和任务安全性。
