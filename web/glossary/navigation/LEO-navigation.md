# 低轨导航增强（LEO Navigation Augmentation）

低轨导航增强是指利用低地球轨道（LEO）卫星搭载的导航信号发射器，增强现有中轨GNSS（如GPS、北斗）的定位精度、信号强度和收敛速度。由于LEO卫星轨道高度低（200–2000千米），信号路径损耗小，能够显著改善城市峡谷和室内等弱信号环境下的导航性能，是下一代PNT体系的重要发展方向。
