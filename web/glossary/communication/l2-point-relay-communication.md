# L2点中继通信（L2 Point Relay Communication）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
> 本文来源：[地月空间入门指南](https://cislunarspace.cn)

## 定义

利用地月L2点附近轨道上的中继卫星，实现地球与月球背面之间的连续通信。L2点Halo轨道卫星不被月球遮挡，可保持对地和对月背面的双向通信，是支持月球背面着陆任务的关键通信架构。

## 应用价值

在月球背面着陆任务中，L2点Halo轨道中继卫星可保持对地和对月背面的连续通信，是嫦娥四号等月背探测任务的关键基础设施。任务设计师利用L2点中继通信架构规划着陆序列，确保月背探测器始终保持与地面控制中心的联络。
