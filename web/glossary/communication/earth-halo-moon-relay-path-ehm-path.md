# 地月Halo中继路径（Earth-Halo-Moon Relay Path, EHM Path）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

信号从地球经L3 Halo轨道卫星转发至月球的通信路径总长。路径长度直接影响链路预算，是L3轨道选型的关键约束。当轨道近地点靠近地球时，地-弧段缩短但弧-月段增长，反之亦然，需在两者之间折中。

## 应用价值

该类轨道在地月空间任务中可用作通信中继和载人登月转移轨道。该通信技术为地月空间链路设计提供理论依据和性能评估基础。
