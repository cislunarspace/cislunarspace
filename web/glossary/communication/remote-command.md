# 遥控指令（Remote Command）

> 本文作者：[天疆说](https://blog.csdn.net/qq_33254264)
>
>本站地址：[https://cislunarspace.cn](https://cislunarspace.cn)

## 定义

空间飞舌（Space Tongue）指用于测控通信领域的专业术语和技术表达。

## 应用价值

该术语在地月空间任务中具有重要应用价值，支撑航天器设计、轨道机动、交会对接等关键技术环节。通过标准化术语体系，可提高设计效率、降低任务风险、促进技术交流与传承。
