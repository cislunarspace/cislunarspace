# 神舟二十三号船箭组合体转运至发射区 计划近日择机实施发射

**摘要：** 北京时间2026年5月16日，神舟二十三号载人飞船与长征二号F遥二十三运载火箭组合体已转运至发射区。发射场设施设备状态良好，后续将按计划开展发射前的各项功能检查、联合测试等工作，计划近日择机实施发射。

## 任务概况

| 项目 | 内容 |
|------|------|
| 任务名称 | 神舟二十三号载人飞行任务 |
| 航天器 | 神舟二十三号载人飞船 |
| 火箭 | 长征二号F遥二十三运载火箭 |
| 发射场 | 酒泉卫星发射中心 |
| 组合体转运日期 | 2026年5月16日 |
| 状态 | 已转运至发射区，计划近日择机发射 |

## 任务背景

神舟二十三号载人飞行任务是中国载人航天工程的重要一环，也是2026年中国空间站任务序列中的关键任务之一。此次任务是神舟系列飞船的后续研制任务，将进一步验证中国载人航天系统的可靠性和任务执行能力。

目前，中国空间站天和核心舱、问天实验舱、梦天实验舱均在轨稳定运行，神舟二十二号乘组已在轨执行任务。神舟二十三号的发射将进一步推进中国空间站的常态化运营，为后续更大规模的载人航天活动奠定基础。

## 发射前流程

根据中国载人航天工程惯例，组合体转运至发射区后，还需完成以下关键步骤：

1. **功能检查**：对船箭组合体各系统进行全面检测，确保状态正常
2. **联合测试**：组织多系统联调联试，验证接口匹配性
3. **气象保障**：持续监测发射窗口气象条件，确保安全发射
4. **加注准备**：推进剂加注及泄漏检测
5. **发射演练**：发射日全流程模拟演练
