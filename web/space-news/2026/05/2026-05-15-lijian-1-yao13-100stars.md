# 力箭一号遥十三「一箭五星」发射成功，力箭系列率先达成百星里程碑

**摘要：** 2026年5月15日12时33分，中科宇航力箭一号遥十三运载火箭（又称「中国有戏号」）在东风商业航天创新试验区点火升空，以「一箭五星」方式将泰景三号05A/05B星、天仪50星、天雁27星、吉林一号高分03D55星及「有戏号」等共5颗卫星精准送入预定轨道，发射任务取得圆满成功。此次任务是力箭一号运载火箭第13次飞行，也是力箭系列运载火箭第14次发射——力箭系列迄今累计将100颗卫星成功送入太空，入轨载荷总质量突破18吨，在我国民商火箭发射服务市场中市占率稳居首位。

## 任务概况

| 项目 | 内容 |
| ------ | ------ |
| 火箭 | 力箭一号遥十三（Li Jian-1 Yao-13） |
| 别名 | 中国有戏号 |
| 发射时间 | 2026年5月15日 12:33 BJT（04:33 UTC） |
| 发射地点 | 东风商业航天创新试验区 |
| 载荷 | 泰景三号05A/05B星、天仪50星、天雁27星、吉林一号高分03D55星、「有戏号」卫星（含「蓉城一号」01/02双星）、「电建一号」 |
| 轨道 | 预定轨道 |
| 任务编号 | 力箭一号第13次飞行，力箭系列第14次发射 |
| 里程碑 | 力箭系列累计100星入轨，载荷总质量突破18吨 |

力箭一号总设计师史晓宁表示，「百星入轨」是里程碑式的突破，标志着中科宇航已完成从科研型组织向专业化、成熟化商业发射服务商的根本性跨越，并沉淀形成了一套成熟完备、高效严谨的项目管控与全流程质量保障体系。

「有戏号」卫星为全球首颗空地一体互动文化传播卫星，其成功入轨将进一步推动我国商业航天在文化传播领域的应用创新。

## 载荷详情

此次「一箭五星」任务将以下卫星送入轨道：

- **泰景三号05A/05B星**：光学遥感卫星
- **天仪50星**：商业遥感卫星
- **天雁27星**：商业通信/遥感卫星
- **吉林一号高分03D55星**：高分辨率光学遥感卫星
- **「有戏号」卫星**（含「蓉城一号」01/02双星）：全球首颗空地一体互动文化传播卫星
- **「电建一号」**：专业应用卫星

## 力箭系列里程碑

力箭一号运载火箭由中科宇航研制，固体推进剂，具备快速响应优势。自首飞以来，力箭系列已成功完成14次发射，累计将100颗卫星送入太空，入轨载荷总质量突破18吨，在我国民商火箭发射服务市场中市占率稳居首位。2026年被视为我国民商火箭「量产元年」，力箭系列的百星里程碑标志着商业火箭从单一任务试验验证向高密度、低成本、快响应、规模化批量交付的关键跃升。
