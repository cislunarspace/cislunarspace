# 星火空间官宣进化一号电循环液体运载火箭

**摘要：** 国内首家专注于电循环液体运载火箭的科技公司星火空间近日宣布，正在研发我国第一款电循环液体运载火箭"进化一号"。该箭全箭总长27.5米，起飞推力90吨，LEO运载能力1.5吨，是目前全球运载能力最大的电循环液体运载火箭，计划为卫星发射、小型星座组网及大型星座补网客户提供"太空特惠快车"发射服务。

## "进化一号"主要参数

| 参数 | 数值 |
| ------ | ------ |
| 全箭总长 | 27.5 米 |
| 箭体直径 | 2.25 米 |
| 起飞推力 | 90 吨 |
| LEO 运载能力 | 1.5 吨 |
| SSO 运载能力 | 1 吨 |
| 发动机数量 | 9+1（9台主机+1台游机） |
| 发动机型号 | 烈焰二号（LY-2），10吨级电循环 |

## 电循环技术突破

传统液体火箭发动机采用燃气发生器循环、分级燃烧循环等方案，利用高温燃气驱动涡轮泵将推进剂压入燃烧室，系统复杂、成本高昂。电循环方案则用电池驱动电动泵替代涡轮泵，省去了燃气发生器、涡轮等复杂部件，大幅简化发动机结构，降低制造成本和系统故障率，同时电气系统易于精确控制，有利于实现发动机推力调节和多次启停。

支撑"进化一号"的关键是星火空间自主研制的10吨级电循环液体火箭发动机"烈焰二号"（LY-2）。今年3月，"烈焰二号"发动机完成首次全系统试车并取得圆满成功，验证了电动泵循环技术路线的可行性，并刷新了世界最大的电循环火箭发动机推力纪录。

## 公司背景

星火空间成立于2024年5月，是国内首家专注于电循环液体运载火箭航天运输系统创建及运营的科技公司，创始团队主要来自北京航空航天大学校友。2025年12月10日，星火空间合肥新站高新区生产基地开工，"进化一号"同步重磅发布。

2026年5月30日，酒泉市领导带队莅临合肥星火空间科技有限公司考察调研，重点推进商业火箭发射工位建设等合作事宜，同日星火空间正式对外官宣"进化一号"的研发进展。
