方案对比

A

同色系灰阶渐变（推荐）

4 级目录用从深到浅的灰色系区分：L1 深灰加粗 → L2 中灰半粗 → L3 浅灰中字 → L4 最浅小字。配合递减的左侧色条宽度（3px → 2.5px → 2px）和递减的动画速度（0.35s → 0.25s → 0.2s → 0.18s）。

优点

  • 优雅克制，不破坏现有科技蓝风格
  • 层次感强但不花哨
  • 深色/浅色主题都好适配

缺点

  • 灰阶差异需要仔细调参
B

左侧色条 + 微妙背景渐变

不依赖文字颜色差异，而是通过左侧色条的粗细和背景色块的透明度来区分层级。L1 有明显的浅色背景块 + 粗色条，逐级递减到 L4 几乎无背景。

优点

  • 视觉区分非常明确
  • 文字颜色保持统一，不影响可读性

缺点

  • 背景色块可能让侧边栏显得"重"
  • 在词汇表（50+扁平项）可能视觉噪声大
