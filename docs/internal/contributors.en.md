## 🤝 How to join the list

Your name is added to the contributors list when you make any of these contributions:

1. **Submit a valid pull request** that gets merged
2. **Report an important issue** that gets confirmed and fixed
3. **Propose a valuable suggestion** that gets adopted
4. **Help translate or proofread** important content
5. **Promote the project** with notable impact
