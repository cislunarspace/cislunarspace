# 贡献者名单

感谢所有为地月空间入门指南做出贡献的开发者、研究者和爱好者。

贡献者列表以 [GitHub 仓库的贡献者页面](https://github.com/cislunarspace/cislunarspace/graphs/contributors) 为准。该页面按提交记录自动统计，不需要手工维护。

## 贡献形式

以下工作都计入贡献：

1. 提交有效的 Pull Request 并被合并。
2. 报告重要问题，并得到确认和修复。
3. 提出有价值的建议并被采纳实施。
4. 帮助审校知识内容，核对概念准确性与参考文献。
5. 推广项目并带来显著影响。

## 参与方式

请阅读 [CONTRIBUTING.md](../../CONTRIBUTING.md) 了解提案、提交与评审流程。

## 致谢

每一位贡献者都是地月空间知识传播的重要推动者。感谢你们的智慧、时间和热情。
