# 内容资源与受众分析

- **Status:** Proposed（受众与 glossary 定位已由站长确认，其余供评审）
- **Date:** 2026-08-19
- **输入:** [ADR-0003](adr/0003-content-module.md)（内容操作模块）、[ADR-0004](adr/0004-asset-layering.md)（资产分层）之前的内容层判断；本文档是它们的输入，不是它们的替代。

## 一、受众：科普读者为主，学生为辅

已确认。这个定位下的读者画像：对航天好奇但没有专业背景，多被某条热点新闻或某个名词（NRHO、阿尔忒弥斯）带来；他们需要一条从已知走向未知的路径，也确实会查词。学生读者（航天相关专业）是第二梯队，用教程和仿真实验室往深处走。

定位不是宣传语，是资源分配的尺子：后面每一项"核心 / 辅助 / 收缩"的判断都从它推出。

## 二、资源全景：按服务对象分三类

回答"有哪些资源需要管理"。分类的钥匙是"给谁用"——不同服务对象的资源，管理方式完全不同。

## 三、现状的四个矛盾

**一、投入与价值倒挂。** 持续投入都给了机器面：新闻管线每小时跑、glossary 批量生成过三千词条、AI 问答引擎是全站最重的工程。而读者真正要读的东西——入门长文只有 2 页、轨道教程停在"骨架已成"、六个月没有实质更新。机器面越活跃，越掩盖"人的内容在停更"这个事实。

**二、首页没有观点。** 八张卡片无主次并列，视觉重心和唯一按钮指向 AI 问答，首屏第一句话却是"欢迎提交 PR"——那是写给贡献者的，不是写给读者的。读者打开首页，看不出"这个站最值得看的是什么"。

**三、名实不副。** "社区论坛"是单机留言板；首页卡片和导航都挂着"术语词典"入口，指向的 `/glossary/` 页面并未构建（`pagePatterns` 排除后没有任何渲染组件接管），读者点进去是空的。用词准确是写作的第一要求，也是站点的：入口叫什么，点进去就该是什么。

**四、新闻流是流水不是解读。** 对科普读者，新闻的价值是"这条动态和我有什么关系、背后的原理是什么"，不是逐条归档。单篇约 300 字、过半无原始链接的现状，服务不了这个价值。

## 四、资源优先级（由受众定位推出）

**核心——读者来的理由：**

1. 入门长文 + 轨道教程。这是"入门指南"的立身之本，也是 AI 问答的语料根基——内容停更，AI 回答质量随之封顶。扩充它们是第一优先级。
2. AI 问答作为 prominent 辅助入口（不是主入口）。已确认：首页以知识内容为主，AI 问答辅助。

**辅助——深化与留存：**

1. 航天动态：从"归档"转向"从新闻到知识"的入口（每条动态链接到站内相关教程/词条，把热点流量导入知识层）。
2. 词典（glossary 清洗后复活）：科普读者查词需求真实存在。
3. 轨道仿真实验室：学生读者的深化入口，维持现状。

**收缩 / 整改：**

1. 论坛：下线，或改名"留言板"并如实呈现其单机性质。
2. 史学思辨：保留在导航（探究工具组），不上首页；若长期不再演进，正式下线。
3. research-frontiers：要么按模板真正填实（每页有真文献、真综述），要么收缩为一张高质量索引页，不保留数十页模板填空。
4. resources-tools：补齐"待补充"，或收缩篇幅如实呈现已有的东西。

## 五、glossary：清洗后双定位（已确认）

站长的决策：**删掉所有短词条、价值低的词条；glossary 既是 AI 语料库，也是一个词典。**

现状是 2026-07-31 批量生成的 1539×2 个词条，其中多数是模板短定义（约 2/3 篇幅是 frontmatter，"相关概念"自动关联语义松散）。执行路径：

1. **清洗**：删短词条与低价值词条（标准：正文只有定义句 + 通用填充句的删；有真实解释、真实关联、真实文献的留）。批量删除应走 ADR-0003 内容操作模块的 `delete`（带回收站），不走裸脚本。
2. **语料定位**：保留词条继续作为 AI 问答语料与路由索引输入。
3. **词典呈现**：清洗后的词条量级（预计数百条）做一个客户端渲染的词典页（分类浏览 + 搜索 + 中英对照），单页 + 一份生成 JSON，成本可控。呈现按"用词准确"要求做：每个词条给出处，删掉的填充句不复活。

## 六、呈现原则：写作要求落到站点

写作十要求不是只管文章正文，同样约束站点的呈现。翻译成三个层面的决策：

**首页与导航（"善于总结材料""观点鲜明""动笔前想受众"）：**

- 首页要有观点：第一屏就分主次——先给"从哪里读起"的路径，再给辅助入口。八卡并列改为有层次的板块。
- 首页文案写给读者，不写给贡献者；"欢迎提 PR"移到页脚或关于页。
- 导航命名划清界限：navbar 的"探究工具"组与"资源与工具"章节概念重叠，合并或改名，二选一。

**内容页（"真懂才能写好""逻辑清晰""由小讲到大"）：**

- 内容组织按领域逻辑（概念 → 轨道 → 前沿 → 工具），不由生产方式组织。
- 每章有阅读路径（cislunar-orbits 已是范本），章与章之间有先后次序的交代。
- 从读者已知的事物引入：新闻里出现 NRHO，就从这个具体的任务讲起，再推到轨道力学。

**诚实性（"用词准确""与读者平等""废话除去"）：**

- 入口叫什么，点进去就是什么：死入口摘掉，名不符实的表面改名或下线。
- "待补充"、模板空页、无人维护的板块，宁可不做，不占着入口。
- 新闻标注来源，AI 问答承认回答边界——不装腔作势，读者才会回来。

## 七、整改清单

呈现层（速赢，配合 ADR-0004 阶段 0 执行）：

1. 首页重做：读者视角文案、主次分明的板块、阅读路径 CTA。
2. 摘掉词典死入口（首页卡片 + navbar，待词典复活后再上）。
3. 论坛下线或改名"留言板"。
4. 思辨表面按第四节收缩组第 2 条明确去留。
5. 导航"探究工具"与"资源与工具"合并或改名。

内容层（持续，按优先级）：

1. glossary 清洗（走内容操作模块，带回收站）→ 词典页复活。
2. 入门长文与轨道教程扩充——第一优先级的内容工作。
3. space-news 增加"从新闻到知识"的关联（模板加"相关阅读"字段，管线生成时链接站内教程/词条）。
4. research-frontiers、resources-tools 按第四节收缩或填实。

验证：百度统计与 GA4 均已就位。整改上线后用真实流量检验优先级判断——如果教程页停留远低于新闻页，回来修这个文档，不是修数据。
